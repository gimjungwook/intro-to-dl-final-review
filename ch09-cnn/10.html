Ch.09 · Sub 10 · 외우지 않고 그림으로

    출력 크기 공식
    (W-K+2P)/S+1의 의미

    시험에 단골로 나오는 식. 외워도 되지만, 외우면 응용이 안 된다. 한 번 그림으로 유도하면 valid·same·strided 합성곱이 한 식의 다른 모습이라는 게 보인다.

    합성곱 한 층의 출력 크기를 정하는 식은 다음 한 줄이다. 입력 한 변 크기 $W$, 커널 한 변 $K$, 패딩(padding) $P$, 스트라이드(stride) $S$를 사용한다.

    $$ O = \left\lfloor \frac{W - K + 2P}{S} \right\rfloor + 1 $$

    O는 출력 한 변 크기. W는 입력 한 변. K는 커널 한 변. P는 한쪽 패딩(상하좌우 동일 가정). S는 스트라이드. 바닥 함수 ⌊·⌋은 정수로 내림.

    이 식을 외운다고 끝이 아니다. 실전에서는 "동일 합성곱(same conv)을 만들려면 P를 얼마로 두어야 하나"처럼 식을 거꾸로 풀어야 하는 경우가 많다. 그래서 식을 한 번 손으로 유도하고, 각 항이 무엇을 세는지 분명히 잡아 두는 것이 좋다. 외우는 대신 추론할 수 있게.

    1D부터 — 가장 단순한 경우

    먼저 1D 합성곱으로 식을 유도하자. 입력이 $W = 8$, 커널이 $K = 3$, 패딩과 스트라이드 없다($P = 0, S = 1$).

    커널의 왼쪽 끝을 입력의 0번 자리에 두면 커널이 0, 1, 2번 자리를 덮는다. 다음 위치는 1번 자리부터 1, 2, 3번을 덮는다. 이런 식으로 커널의 왼쪽 끝이 0, 1, 2, ..., 5까지 갈 수 있다. 6번에서 시작하면 커널 오른쪽 끝이 8을 넘어가 입력 밖으로 벗어난다. 그래서 가능한 시작 위치는 0부터 5까지, 총 6개. 출력 크기는 6이다.

    일반화하면 가능한 시작 위치는 0부터 $W - K$까지, 총 $W - K + 1$개. 식으로 적으면

    $$ O = W - K + 1 \quad (P = 0,\ S = 1) $$

    패딩 없고 스트라이드 1인 가장 단순한 경우. 출력 크기는 입력에서 커널 길이만큼 빠진 뒤 1을 더한 값.

    패딩이 들어오면 — 입력을 가상으로 늘린다

    패딩이란, 입력 가장자리에 가짜 값을 덧붙이는 것이다. 보통 0으로 채운다(zero padding). 한쪽에 $P$만큼씩, 양쪽 합쳐서 $2P$만큼 입력이 더 길어진다. 그래서 패딩이 들어간 입력의 길이는 $W + 2P$다.

    패딩한 입력에 같은 유도를 적용하면, 출력 크기는 $W + 2P - K + 1$이다. 즉 위 식에서 $W$를 $W + 2P$로 바꾼 셈이다.

    $$ O = (W + 2P) - K + 1 = W - K + 2P + 1 \quad (S = 1) $$

    패딩 P가 양쪽으로 들어가면 입력이 2P만큼 길어진다. 출력 크기는 그만큼 늘어난다. K = 3, P = 1로 두면 W = O가 되어 same convolution.

    여기서 자주 쓰는 동일 합성곱(same convolution)의 패딩 값을 도출할 수 있다. $O = W$가 되게 하려면 $W - K + 2P + 1 = W$, 즉 $P = (K - 1)/2$. 커널이 홀수($K = 3, 5, 7, \dots$)이면 $P$가 정수다. 그래서 CNN 커널은 거의 항상 홀수다.

    스트라이드가 들어오면 — 한 칸씩이 아니라 S칸씩

    스트라이드란, 커널을 한 위치에서 다음 위치로 옮길 때 몇 칸을 건너뛰는지의 값이다. 기본 $S = 1$이면 한 칸씩, $S = 2$면 두 칸씩 건너뛴다.

    패딩한 입력에서 시작 위치 후보는 0, $S$, $2S$, ..., 즉 마지막 가능 시작 위치는 $W + 2P - K$다. 이 마지막 위치를 $S$로 나누면 마지막 시작 위치의 번호 $\lfloor (W + 2P - K) / S \rfloor$가 나온다. 0번 시작 위치까지 포함하면 총 시작 위치 수는

    $$ O = \left\lfloor \frac{W + 2P - K}{S} \right\rfloor + 1 $$

    최종 일반 공식. 스트라이드가 들어오면 가능한 시작 위치 수를 S로 나누고 바닥 함수로 정수로 만든 뒤 1을 더한다. S = 1, P = 0이면 처음 식 W - K + 1로 환원.

    바닥 함수가 들어가는 이유는, $(W + 2P - K)$가 $S$로 나누어떨어지지 않을 수 있기 때문이다. 예를 들어 $W = 8, K = 3, P = 0, S = 2$이면 $(8 - 3)/2 = 2.5$, 바닥은 2, 출력은 3. 시작 위치는 0, 2, 4 — 정확히 3개다. 6은 커널 오른쪽 끝이 9가 되어 입력 밖이라 불가능.

    세 가지 표준 — valid, same, strided

    이 공식이 만드는 세 가지 표준 모드를 정리하면 다음과 같다.

    모드PS출력 크기쓰임
    유효(valid)01$W - K + 1$입력보다 작아짐. 가장자리 정보 일부 손실. 옛 모델에서 흔함.
    동일(same)$(K-1)/2$1$W$입력과 출력 같음. 깊이 쌓을 때 크기 계산 편함. 현대 CNN 표준.
    스트라이드(strided)$(K-1)/2$2$W/2$ (대략)풀링 없이 다운샘플링. ResNet, EfficientNet 등 최근 표준.

    이 셋이 합성곱의 모든 표준이다. 다른 패딩 값(예: $P = K - 1$)을 쓰는 full convolution도 있지만, 분류 CNN에서는 거의 안 쓴다.

    가장 자주 등장하는 계산 예시 모음

    시험에서 빠르게 풀려면 자주 나오는 조합을 외워 두기보다, 위 공식으로 한 번씩 다시 풀어 보자. 예시 다섯 개를 적어 둔다.

    예시 1. $W = 32, K = 3, P = 1, S = 1$. $O = \lfloor (32 - 3 + 2)/1 \rfloor + 1 = 31 + 1 = 32$. same conv 확인.

    예시 2. $W = 32, K = 3, P = 0, S = 1$. $O = \lfloor (32 - 3)/1 \rfloor + 1 = 29 + 1 = 30$. valid conv, 2픽셀 손실.

    예시 3. $W = 32, K = 3, P = 1, S = 2$. $O = \lfloor (32 - 3 + 2)/2 \rfloor + 1 = \lfloor 15.5 \rfloor + 1 = 15 + 1 = 16$. strided same, 절반.

    예시 4. $W = 224, K = 11, P = 0, S = 4$. AlexNet 첫 층. $O = \lfloor (224 - 11)/4 \rfloor + 1 = \lfloor 53.25 \rfloor + 1 = 53 + 1 = 54$. 책 표기와 약간 다를 수 있는데, 일부 구현은 입력을 227로 가정한다.

    예시 5. $W = 224, K = 7, P = 3, S = 2$. ResNet 첫 층. $O = \lfloor (224 - 7 + 6)/2 \rfloor + 1 = \lfloor 111.5 \rfloor + 1 = 111 + 1 = 112$. 출력 절반 크기에 동일 패딩.

    출력 채널 수는 어떻게 결정되는가

    위 공식은 한 채널의 공간 크기만 다룬다. 채널(특징맵 종류) 수는 별개다. 합성곱 층의 출력 채널 수 $C_{\text{out}}$은 우리가 정하는 하이퍼파라미터다. 32, 64, 128, 256 등으로 깊이 가면서 두 배씩 늘리는 패턴이 표준이다. 그 이유는 풀링이나 strided conv로 공간 크기가 절반이 될 때마다 채널을 두 배로 늘려, 한 층의 전체 정보량(공간 × 채널)을 일정하게 유지하기 위함이다.

    커널 가중치 수는 다음과 같다.

    $$ N_{\text{weights}} = C_{\text{in}} \cdot K \cdot K \cdot C_{\text{out}} + C_{\text{out}} $$

    C_in 입력 채널, K x K 커널 공간 크기, C_out 출력 채널. 마지막 + C_out은 채널별 편향(bias).

    위 식을 보면, 공간 크기 $W$가 가중치 수에 등장하지 않는다 — 1번에서 말한 "합성곱의 파라미터 수는 공간 크기와 무관"이 여기서 다시 확인된다. 공간 크기에 비례하는 것은 곱셈 수($O \cdot O$만큼 같은 가중치를 반복 적용)이지 가중치 수가 아니다.

    아래 위젯에서 $W, K, P, S$ 네 슬라이더로 출력 크기가 어떻게 바뀌는지 직접 본다. 각 모드(valid, same, strided)를 슬라이더로 만들어 보고, 식의 각 항이 출력 크기를 어떻게 결정하는지 한눈에 확인한다.

    위젯 10W, K, P, S 슬라이더 — 출력 크기 한눈에
    출력 크기: —

    왼쪽은 패딩이 덧붙은 입력 격자. 노란 박스가 커널 한 자리(스트라이드 S로 건너뛰며 그림). 오른쪽은 출력 격자. valid·same·strided 각 모드를 P와 S 슬라이더로 만들어 보면 같은 식이 세 가지 동작을 다 만들어 낸다는 것이 확인된다.

    출력 크기 공식 한 줄 정리

    • 공식: $O = \lfloor (W - K + 2P) / S \rfloor + 1$.
    • 유도: 가능한 시작 위치 수를 S로 나눈 뒤 0번 시작 위치 포함을 위해 +1.
    • same conv 패딩: $P = (K-1)/2$. 그래서 커널 K는 거의 항상 홀수.
    • strided conv(S=2): 풀링 없이 절반 다운샘플링. 최근 아키텍처 표준.
    • 출력 채널 수 $C_{\text{out}}$은 별도 하이퍼파라미터, 보통 2배씩 증가.
    • 가중치 수 = $C_{\text{in}} K^2 C_{\text{out}} + C_{\text{out}}$. 공간 크기 W와 무관.
    • 외울 게 아니라 한 번 유도해 두고 거꾸로 풀 수 있어야 함.

    다음 11번에서는 같은 합성곱을 여러 층 쌓으면 깊은 층의 한 뉴런이 입력에서 얼마나 넓은 면적을 보는지 — 수용 영역(receptive field)을 본다. 한 층의 좁은 시야가 여러 층을 거치며 어떻게 전체 이미지를 덮는지를 직관화한다.
