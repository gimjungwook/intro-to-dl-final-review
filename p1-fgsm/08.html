Chapter 08 · 시험장 손계산

    2차원 로지스틱 회귀에서
    한 걸음 FGSM 끝까지 계산

    이 장은 시험을 보러 가는 사람을 위해 가장 작은 예를 끝까지 손으로 푼다. 입력 2차원, 가중치 2개의 로지스틱 회귀 모델 한 점에서 시그모이드 손실의 입력 기울기를 미분으로 구하고, 부호를 취해 ε을 곱한 뒤 원래 입력에 더한다. 모든 단계의 숫자가 명시적으로 나온다.

    설정 — 가장 작은 분류기

    이항 분류 로지스틱 회귀를 쓴다. 입력 차원 2, 가중치 w = (w₁, w₂) = (0.6, −0.8), 편향 b = 0.1. 모델 점수는 z = wᵀx + b = 0.6·x₁ − 0.8·x₂ + 0.1. 시그모이드를 통과시켜 확률을 만든다.

    $$ p(y=1 \mid x) \;=\; \sigma(z) \;=\; \frac{1}{1 + e^{-z}}, \qquad z = w^\top x + b $$

    시그모이드 σ는 [0,1] 사이로 점수를 압축한다. σ(0) = 0.5, σ가 1에 가까우면 클래스 1, 0에 가까우면 클래스 0.

    이 모델이 손실을 평가할 때 쓰는 함수는 이진 교차 엔트로피(binary cross-entropy)다. 정답 라벨 y ∈ {0, 1}에 대해

    $$ L(x, y) \;=\; -\,y \log \sigma(z) \;-\; (1-y) \log\!\bigl(1 - \sigma(z)\bigr) $$

    정답이 1이면 σ(z)가 1에 가깝길 원하므로 −log σ(z)에 페널티. 정답이 0이면 σ(z)가 0에 가깝길 원하므로 −log(1 − σ(z))에 페널티.

    한 데이터 점을 골라 보자. 입력 x = (1.0, 0.5), 정답 y = 1. ε = 0.1로 두자. 우리의 목표는 FGSM 공식 x̃ = x + ε · sign(∇x L)을 적용해 적대적 입력 x̃을 직접 계산하는 것이다.

    단계 1 — 점수와 확률 계산

    z = 0.6 · 1.0 + (−0.8) · 0.5 + 0.1 = 0.6 − 0.4 + 0.1 = 0.3. 시그모이드 σ(0.3) = 1 / (1 + e^(−0.3)) = 1 / (1 + 0.7408) ≈ 1 / 1.7408 ≈ 0.5744. 즉 모델은 이 입력을 클래스 1로 약 57.4%의 확신으로 분류한다. 정답이 1이므로 모델이 맞는 답을 내고 있다. 하지만 자신감이 그리 높지 않다.

    단계 2 — 손실 계산

    y = 1이므로 L = −log σ(z) = −log 0.5744 = −(−0.5547) = 0.5547. log는 자연로그. 손실이 약 0.55라는 것은 모델이 답을 맞췄지만 자신감이 부족하다는 신호다. 이상적으로는 σ(z) = 1.0일 때 L = 0이 되어야 한다.

    단계 3 — 손실의 입력에 대한 기울기 미분

    이제 핵심이다. ∇x L을 구해야 한다. 손실이 입력 x를 통해 z로, z를 통해 σ로, σ를 통해 L로 흘러간다. 연쇄법칙(chain rule)을 두 번 적용한다.

    $$ \frac{\partial L}{\partial x_i} \;=\; \frac{\partial L}{\partial z} \cdot \frac{\partial z}{\partial x_i} \;=\; \frac{\partial L}{\partial z} \cdot w_i $$

    ∂z/∂xᵢ = wᵢ는 z = wᵀx + b의 정의에서 즉시. 모든 기울기 계산이 ∂L/∂z로 환원된다.

    그러면 ∂L/∂z를 구하면 된다. 로지스틱 회귀의 표준 결과는 매우 깔끔하다.

    $$ \frac{\partial L}{\partial z} \;=\; \sigma(z) - y $$

    교차 엔트로피 + 시그모이드 조합의 도함수. 유도 과정: L = −y log σ − (1−y) log(1−σ), σ'(z) = σ(1−σ)를 합치면 σ − y가 깔끔하게 나온다.

    지금 우리 숫자에 대입한다. ∂L/∂z = σ(z) − y = 0.5744 − 1 = −0.4256. 그러므로

    ∂L/∂x₁ = −0.4256 · w₁ = −0.4256 · 0.6 = −0.2554.

    ∂L/∂x₂ = −0.4256 · w₂ = −0.4256 · (−0.8) = +0.3405.

    즉 ∇x L = (−0.2554, +0.3405). 이 벡터의 부호는 (−1, +1)이다.

    단계 4 — 부호 취하기와 ε 곱하기

    sign(∇x L) = (sign(−0.2554), sign(+0.3405)) = (−1, +1). ε = 0.1이므로 적대적 섭동은 δ = ε · sign(∇x L) = 0.1 · (−1, +1) = (−0.1, +0.1).

    단계 5 — 적대적 입력 x̃ 계산

    x̃ = x + δ = (1.0, 0.5) + (−0.1, +0.1) = (0.9, 0.6).

    단계 6 — 검증: 모델이 적대적 입력에 대해 무어라 하나

    마지막 단계로, 만들어진 x̃을 다시 모델에 넣어 본다. 새 점수 z̃ = 0.6 · 0.9 + (−0.8) · 0.6 + 0.1 = 0.54 − 0.48 + 0.1 = 0.16. 새 확률 σ(0.16) = 1 / (1 + e^(−0.16)) ≈ 1 / (1 + 0.8521) ≈ 0.5399. 새 손실 L = −log 0.5399 ≈ 0.6164.

    비교: 원본 손실 0.5547 → 적대적 손실 0.6164. 약 11% 증가했다. 원본 확률 0.5744 → 적대적 확률 0.5399. 모델의 클래스 1 자신감이 줄었다. ε = 0.1이라는 한 걸음으로 라벨을 뒤집기에는 부족했지만(아직 클래스 1로 분류), 손실이 커지고 자신감이 떨어졌다. ε을 더 키우면 결국 0.5 아래로 떨어져 라벨이 뒤집힌다. 시험에 비슷한 문제가 나오면 "ε이 0.1로는 부족했고 더 키워야 라벨이 뒤집힌다"고 답할 수 있다.

    위젯으로 같은 계산 반복

    아래 위젯은 위 손계산과 똑같은 설정을 슬라이더로 조작 가능하게 만든 것이다. x₁, x₂, w₁, w₂, ε을 바꿔 가며 각 단계의 숫자가 어떻게 변하는지 본다. 라벨이 뒤집히는 정확한 ε 값(약 σ(z) = 0.5가 되는 지점)을 찾아보는 연습도 가능하다.

    위젯 08로지스틱 회귀 한 점 — z, σ, ∇L, sign, ε·sign, x̃, 새 σ를 단계별로

    위 손계산의 모든 숫자가 그대로 표시된다. ε 슬라이더를 키워가며 라벨이 정확히 어디서 뒤집히는지 확인하자. w를 바꾸면 sign(∇x L)의 방향도 함께 바뀐다는 점을 눈으로 확인하면 7장의 정의가 실감난다.

    시험 함정 — 부호 실수와 라벨 0의 경우

    이 손계산에서 시험에 자주 나오는 함정을 두 가지 짚자.

    함정 1 — ∂L/∂z의 부호를 거꾸로. y = 1일 때 ∂L/∂z = σ(z) − y는 보통 음수(σ가 1보다 작으므로). 그러면 ∂L/∂x = (σ − y) · w도 부호가 w와 반대. 그리고 sign(∂L/∂x) = −sign(w). 즉 정답이 1인 경우 적대적 섭동은 −sign(w) 방향이다. 직관적으로 "정답 점수를 키우는 방향이 +w 방향이므로, 정답에서 멀어지려면 −w 방향으로 가야 한다"고 외워둔다. 그러나 항상 미분으로 부호를 검증할 것.

    함정 2 — 라벨 0의 경우. y = 0일 때 ∂L/∂z = σ(z) − 0 = σ(z)는 항상 양수. 그러면 sign(∂L/∂x) = +sign(w). 즉 적대적 섭동은 +sign(w) 방향이다. 정답이 0이면 점수 z를 더 작게 만들고 싶은데, FGSM은 손실을 키우는 방향, 즉 z를 더 키우는 방향으로 간다. y = 0과 y = 1에서 적대적 방향이 정확히 반대가 된다는 점을 외워두자.

    시험 문제가 "y = 0, w = (0.6, −0.8), x = (1.0, 0.5), ε = 0.1, FGSM 적대적 입력을 구하시오"라고 나오면, sign 방향만 부호 반대인 답이 나온다. δ = ε · sign(w) = 0.1 · (+1, −1) = (+0.1, −0.1), x̃ = (1.1, 0.4). 같은 단계지만 부호 한 번이 결과 전체를 바꾼다.

    왜 이 모델로 연습하나

    피아노를 배울 때 처음에는 한 손, 한 음씩 시작한다. 양손 협주를 처음부터 하면 무엇이 무엇인지 모른다. 적대적 머신러닝도 마찬가지다. 2차원 로지스틱 회귀는 신경망의 "한 음"이다. 차원이 작아서 모든 숫자를 손으로 따라갈 수 있고, 비선형이 시그모이드 하나뿐이라 미분이 간단하다. 여기서 ε · sign(∇x L)이 손에 익으면 임의의 차원, 임의의 손실, 임의의 모델로 일반화하기 쉽다. 신경망의 ∇x L은 역전파로 컴퓨터가 계산해 주지만, 그 결과를 손으로 검증할 수 있어야 시험에서 함정에 빠지지 않는다.

    한 걸음 더 — 다중 클래스 일반화

    실제 시험은 보통 이진 분류로 나오지만, 다중 클래스(multi-class) 일반화를 알아두면 손해는 없다. C개 클래스 소프트맥스 분류기에서 손실은 L = −log p_y, p_y = softmax(z)_y. 입력 기울기는 ∂L/∂xᵢ = Σ_c (p_c − [c = y]) · W_{c,i}. 여기서 W는 클래스별 가중치 행렬, [c = y]는 c가 정답이면 1 아니면 0. 부호 함수와 ε을 적용하는 단계는 이진 분류와 동일하다.

    왜 σ(z)−y가 이렇게 깔끔하게 나오는가

    위 손계산에서 가장 신기한 부분은 ∂L/∂z = σ(z) − y라는 한 줄짜리 결과다. 이 결과가 왜 그렇게 깔끔하게 나오는지 짚어두면 시험에서 헷갈리지 않는다. 시그모이드와 교차 엔트로피라는 두 함수가 한 쌍으로 묶인 데에는 우연이 아닌 수학적 이유가 있다.

    먼저 시그모이드의 도함수부터 보자. σ(z) = 1 / (1 + e^(−z))의 미분은 σ′(z) = σ(z)(1 − σ(z))이다. 즉 시그모이드의 기울기는 자기 자신의 값으로 표현된다. 이 성질이 신경망 학습에서 매우 편리하다 — 순방향에서 이미 계산한 σ(z)를 그대로 역전파에 재활용할 수 있기 때문이다.

    다음으로 교차 엔트로피의 도함수를 보자. y = 1인 경우 L = −log σ(z), 미분하면 ∂L/∂z = −σ′(z)/σ(z) = −(1 − σ(z)) = σ(z) − 1. y = 0인 경우 L = −log(1 − σ(z)), 미분하면 ∂L/∂z = σ′(z)/(1 − σ(z)) = σ(z). 두 경우를 합치면 ∂L/∂z = σ(z) − y라는 한 줄짜리 결과가 나온다. 시그모이드의 자기 회귀 도함수와 로그의 분모 분자가 정확히 상쇄되는 우아한 구조다.

    이 깔끔함은 우연이 아니라, 시그모이드가 베르누이 분포의 자연 매개변수(natural parameter)에 해당하기 때문이다. 이론적으로는 일반화 선형 모델(generalized linear model)의 한 사례에서 자동으로 따라 나오는 결과다. 시험에서는 이 깊은 배경까지는 묻지 않지만, "왜 σ−y인가"를 물으면 "교차 엔트로피의 미분이 시그모이드의 미분과 상쇄되어 그 단순한 형태가 나옴"이라고 답할 수 있다.

    또 다른 함정 — ε이 커서 시그모이드 포화에 도달

    위 손계산에서 우리는 ε = 0.1로 한 걸음 갔지만 라벨이 뒤집히지 않았다. 그러면 ε을 더 키우면 어떻게 되나? ε = 0.5라 하자. 그러면 δ = (−0.5, +0.5), x̃ = (0.5, 1.0). 새 점수 z̃ = 0.6 · 0.5 + (−0.8) · 1.0 + 0.1 = 0.3 − 0.8 + 0.1 = −0.4. 시그모이드 σ(−0.4) ≈ 0.401. 클래스 1 확률이 0.5 아래로 떨어졌으니 라벨이 클래스 0으로 뒤집혔다. ε = 0.5가 라벨을 뒤집기에 충분한 크기다.

    그러나 ε = 0.5는 픽셀 값 [0,1] 범위에서 매우 큰 변화다. 사람 눈에도 분명히 보일 정도의 차이다. 즉 이 작은 모델에서 "보이지 않는 적대적 입력"을 만들려면 ε이 매우 작아야 하는데, 같은 ε에서는 한 걸음 FGSM이 라벨을 못 뒤집을 수 있다. 이 작은 모델은 차원이 2뿐이라 6장의 nε 누적 효과가 거의 없기 때문이다. n = 2, ε = 0.1, ‖w‖₁ = 1.4에서 ε · ‖w‖₁ = 0.14만큼만 점수가 변한다. ImageNet 같은 고차원에서는 같은 픽셀당 ε으로도 훨씬 큰 점수 변화를 얻는다.

    이 사실을 거꾸로 보면, 작은 모델에서 FGSM 효과를 보려면 ε을 키워야 하고 큰 모델에서는 ε을 작게 유지해도 효과가 충분하다는 의미다. 시험에 "왜 ImageNet에서는 ε = 0.007로도 충분한가"라는 질문이 나오면 "n = 150,000이라는 큰 차원에서 nε 누적 효과 덕분"이라고 답한다.

    요약과 다음 장

    이 장에서 우리는 2차원 로지스틱 회귀 위에서 FGSM의 모든 단계를 직접 손으로 계산했다. 입력 (1.0, 0.5), 가중치 (0.6, −0.8), 편향 0.1, 정답 1, ε = 0.1에서 적대적 입력 x̃ = (0.9, 0.6)이 나왔다. 손실이 0.5547 → 0.6164로 11% 증가했고, 클래스 1 확률이 0.5744 → 0.5399로 떨어졌다. 이 한 예시가 시험 답안에 그대로 옮길 수 있는 형태다.

    다음 장(CHAPTER 09)에서는 FGSM을 공격 도구로만 쓰는 게 아니라, 학습 데이터에 섞어 넣어 모델 자체를 더 견고하게 만드는 적대적 훈련(adversarial training)을 본다. 똑같은 한 줄 공식이 공격과 방어 모두에 쓰인다는 점이 이 논문의 두 번째 큰 기여다.
