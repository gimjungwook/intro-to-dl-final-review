    FGSM 시험 대비 —
    정의·수식·15개 예상 질문

    이 장은 시험 1시간 전 한 번 더 훑을 수 있는 체크리스트다. 한 줄 정의, 핵심 수식 4개, 자주 묻는 15개 예상 질문, 그리고 가장 자주 범하는 5개 함정을 정리한다. 앞 11개 장의 내용을 시험 답안 형태로 압축한 한 페이지다.

    핵심 한 줄 — 외워야 할 사실

    $$ \begin{aligned} &\text{이 논문의 핵심 주장:} \\ &\quad \text{신경망이 적대적 예제에 약한 이유는 너무 비선형이라서가 아니라 너무 \textbf{선형}이기 때문이다.} \end{aligned} $$

    3장의 "비선형 + 과적합 가설"이 틀렸음을 4장의 "지역 선형 가설"이 대체한다. 이 한 줄이 논문 전체의 압축.

    핵심 수식 4개

    수식 1 — 선형 모델 점수 변화:

    $$ z' = w^\top(x + \delta) = w^\top x + w^\top \delta $$

    선형 모델에서 입력 변화의 점수 효과. ∞-노름 제약 아래 wᵀδ 최대화의 닫힌 해가 ε · sign(w).

    수식 2 — FGSM 정의 (가장 중요):

    $$ \tilde{x} = x + \epsilon \cdot \text{sign}\bigl(\nabla_x L(\theta, x, y)\bigr) $$

    x = 원본 입력, y = 정답, θ = 모델 가중치, L = 손실, ε = ∞-노름 예산. 한 번의 역전파로 ∇x L을 구하고 부호 취해 ε 곱해 더함.

    수식 3 — 선형 누적 효과:

    $$ w^\top \delta_{\text{adv}} = \epsilon \cdot \|w\|_1 \approx \epsilon \cdot n \cdot \overline{|w|} $$

    픽셀당 ε 변화가 점수에서 n에 비례하는 변화로 누적. ImageNet n = 150,000에서 ε = 0.007이 10.5 수준의 점수 변화 → 라벨 뒤집기에 충분.

    수식 4 — 적대적 훈련 손실:

    $$ L_{\text{adv}} = \alpha \, L(\theta, x, y) + (1-\alpha) \, L(\theta, \tilde{x}, y) $$

    정상 손실과 적대적 손실의 가중평균. 1차 근사로 ≈ L(x) + ε(1−α)‖∇x L‖₁ 즉 입력 기울기 L1 정칙화.

    15개 예상 질문과 한 줄 답

    Q1. 적대적 예제란 무엇인가? 원본 입력 x를 ε 이하로만 바꿔서 사람 눈으로는 같아 보이지만 모델이 다른 라벨을 자신 있게 내놓는 입력 x̃.

    Q2. 적대적 예제의 라벨이 더 자신 있는 오답이라는 것이 왜 중요한가? 일반 노이즈에 의한 분류 오류는 자신감이 낮지만, 적대적 예제는 자신감이 더 높은 오답. 모델이 자기가 무엇을 모르는지 모른다는 뜻.

    Q3. 논문의 핵심 주장은? 적대적 예제는 신경망이 너무 비선형이라서가 아니라 너무 선형(locally linear)이라서 생긴다.

    Q4. FGSM 공식을 쓰시오. x̃ = x + ε · sign(∇x L(θ, x, y)).

    Q5. FGSM이 왜 "Fast"인가? 한 번의 역전파만으로 적대적 입력을 만든다. 학습 한 스텝과 같은 비용. 매 미니배치에서 호출할 수 있을 정도로 빠름.

    Q6. 왜 sign이고 ∇x L 자체가 아닌가? ∞-노름 제약 ‖δ‖∞ ≤ ε 아래에서 wᵀδ를 최대화하는 닫힌 해가 정확히 ε · sign(w). 각 차원이 독립이라 양쪽 끝까지 가는 것이 최적.

    Q7. ε = 0.007이 왜 충격적인가? 픽셀 값 [0,1] 범위에서 0.7%에 불과한 작은 변화. JPEG 압축이나 카메라 노이즈에 묻힐 만한 크기. 그런데도 GoogLeNet의 라벨이 panda 57.7% → gibbon 99.3%로 뒤집힘.

    Q8. 고차원이 왜 공격자의 축복인가? 적대적 점수 변화는 nε에 비례, 무작위 노이즈는 √(nε²)에 비례. 둘의 비율 √n이 차원 클수록 벌어짐. ImageNet 150,000차원에서 적대적 공격이 무작위보다 약 387배 효과적.

    Q9. 전이성(transferability)이란? 모델 A에서 만든 적대적 예제가 다른 모델 B에서도 같은 방향으로 오류를 일으킴. 다른 아키텍처, 다른 학습 데이터로 학습한 모델 사이에서도 작동. 선형 가설의 자연스러운 결론 — 데이터 위에서 비슷한 선형 함수에 수렴하기 때문.

    Q10. 적대적 훈련의 핵심 식은? L_adv = α · L(x) + (1−α) · L(x̃). α는 정상 손실과 적대적 손실의 혼합 비율.

    Q11. 적대적 훈련이 일반 정확도도 개선하는 이유는? 1차 근사로 L(x̃) ≈ L(x) + ε‖∇x L‖₁. 즉 적대적 손실 = 정상 손실 + L1 입력 기울기 정칙화. 모델이 입력 변화에 덜 민감해져 일반 자연 노이즈에도 견고. MNIST에서 0.94% → 0.84%로 개선.

    Q12. RBF 네트워크는 왜 적대적 예제에 견고한가? 비선형이 강해서 1차 테일러 근사가 깨짐. 또한 입력이 학습 데이터 중심에서 멀어지면 활성이 0에 가까워져 "모름" 응답. 자신 있는 오답을 만들기 어려움.

    Q13. RBF의 단점은? 일반 정확도가 매우 낮음(MNIST에서 ~55%). 비선형이 강해 기울기 소실이 심하고 학습 자체가 어려움. 큰 데이터셋에서 사실상 불가능.

    Q14. FGSM 이후 등장한 더 강한 공격은? PGD(Projected Gradient Descent) — FGSM을 K번 반복하고 ε 공으로 투영. 매 걸음 새 기울기 계산. C&W(Carlini & Wagner) — ε 자체를 최소화하는 별개 최적화.

    Q15. 적대적 견고성과 일반 정확도가 같은 문제인가? 아니다. 일반 테스트 정확도 99%인 모델도 적대적 정확도는 5% 미만일 수 있다. 두 지표는 다른 코인. 일반 정규화(L2, dropout)는 일반 정확도를 개선하지만 적대적 견고성을 크게 늘리지 못함.

    가장 자주 범하는 5개 함정

    함정 1 — ∇x L vs ∇θ L 혼동. 일반 학습은 모델 가중치 θ에 대한 기울기를 쓰지만, FGSM은 입력 x에 대한 기울기를 쓴다. 같은 역전파지만 목적이 다르다. 시험에서 ∇θ L을 쓰면 자동으로 0점.

    함정 2 — sign(σ(z) − y)의 부호. y = 1일 때 σ(z) − y는 음수, 그래서 sign(∇x L) = −sign(w). y = 0일 때는 양수, sign(∇x L) = +sign(w). 부호가 정답에 따라 뒤집힌다. 미분으로 검증 필수.

    함정 3 — ε이 너무 작아 라벨이 안 뒤집힘. FGSM 한 걸음으로 ε이 너무 작으면 손실은 증가하지만 라벨이 안 뒤집힐 수 있다. 시험 문제가 "ε에서 라벨이 뒤집히는가"를 물으면 σ(새 z)가 0.5를 넘는지 확인. 안 넘으면 "ε이 부족하다"고 답.

    함정 4 — 표적 vs 비표적 공식 혼동. 비표적: x̃ = x + ε · sign(∇x L(θ, x, y)) (정답 손실 키움). 표적: x̃ = x − ε · sign(∇x L(θ, x, y′)) (표적 손실 줄임, 부호 반대). 시험에서 "표적 공격"이 명시되면 부호를 정확히.

    함정 5 — 클립(clipping) 잊기. 적대적 입력 x̃ = x + ε · sign(∇x L)이 픽셀 값 [0, 1] 범위를 벗어날 수 있다. 정확한 답은 x̃ = clip(x + ε · sign(∇x L), 0, 1). 시험에서 클립을 안 적어도 큰 감점은 없지만 명시하면 정확함.

    시험장에서 한 줄로 답하는 연습

    아래 5개 문제는 시험에서 그대로 나올 가능성이 가장 높은 질문이다. 30초 안에 한 줄로 답할 수 있는지 자신에게 묻자.

    연습 1. "FGSM 공식을 쓰고 각 기호를 한 줄로 설명하시오." → x̃ = x + ε · sign(∇x L(θ, x, y)). x = 입력, ε = ∞-노름 예산, sign = 부호 함수, ∇x L = 입력에 대한 손실 기울기, θ = 모델 가중치 (고정).

    연습 2. "이 논문이 제시하는 적대적 예제의 진짜 원인은?" → 신경망이 너무 비선형이라서가 아니라, 입력 공간에서 지역적으로 선형(piecewise linear)이라서. ReLU·LSTM·maxout이 모두 지역 선형이라는 공통 설계 원리 때문.

    연습 3. "적대적 훈련 손실 함수를 쓰고, 왜 일반 정확도가 좋아지는지 한 줄로 설명." → L_adv = αL(x) + (1−α)L(x̃). 1차 근사로 입력 기울기 L1 정칙화와 동치이므로 입력 노이즈 전반에 대한 견고성이 늘어남.

    연습 4. "FGSM에서 부호만 가져가는 수학적 이유는?" → ∞-노름 제약 ‖δ‖∞ ≤ ε 아래에서 wᵀδ를 최대화하는 닫힌 해가 정확히 ε · sign(w). 각 차원이 독립이라 양쪽 끝까지 가는 것이 최적.

    연습 5. "x = (1.0, 0.5), w = (0.6, −0.8), b = 0.1, y = 1, ε = 0.1에서 FGSM 적대적 입력은?" → z = 0.3, σ(z) ≈ 0.574, ∂L/∂z = σ−y ≈ −0.426. ∇x L = ∂L/∂z · w ≈ (−0.256, +0.341). sign = (−1, +1). δ = ε · sign = (−0.1, +0.1). x̃ = (0.9, 0.6).

    마지막 한 줄

    FGSM 시험에서 가장 중요한 한 줄은 이것이다. "x̃ = x + ε · sign(∇x L)이라는 한 줄짜리 공식이 ∞-노름 제약 아래 1차 손실 근사의 닫힌 해이고, 그것이 가능한 이유는 신경망이 입력 공간에서 지역적으로 선형이기 때문이다. 같은 공식을 학습에 거꾸로 섞으면 입력 기울기 정칙화 효과로 모델이 적대적 입력과 일반 노이즈 모두에 더 견고해진다." 이 한 줄을 외워두면 시험 70%는 답할 수 있다.
