    Sub 05 · 입력·라벨 공간에서의 정칙화

    데이터를 흔들면,
    결정경계가 부드러워진다

    데이터 증강은 가짜 데이터 복제가 아니다. "이 변형은 같은 의미"라는 사전지식을 모델에 주입하는 방법이다.

    지금까지 다룬 정칙화 — L2, L1, 드롭아웃, 조기 종료 — 는 모두 모델의 파라미터나 학습 동역학을 건드린다. 그런데 정칙화의 또 다른 큰 갈래는 입력 데이터 자체를 건드린다. 이번 장에서는 그 갈래 세 가지를 본다.

    1. 데이터 증강(Data Augmentation) — 같은 의미의 변형된 입력을 만들어 학습셋을 확장.
    2. 노이즈 주입(Noise Injection) — 입력·은닉표현·가중치에 작은 잡음을 더해 강건성을 학습.
    3. 라벨 스무딩(Label Smoothing) — 정답 라벨을 약간 흐려서 과확신을 막음.

    데이터 증강 — 가짜 데이터가 아니라 불변성 주입

    이미지에서 데이터 증강은 매우 자연스럽다. 고양이 사진을 좌우로 뒤집어도, 5도 회전해도, 약간 어둡게 해도 — 여전히 고양이다. 그러면 원본 한 장에서 여러 변형을 만들어 학습셋을 늘릴 수 있다.

    처음 보면 "데이터를 인위적으로 복제하는 꼼수"처럼 보일 수 있다. 하지만 본질은 그게 아니다. 데이터 증강의 핵심은 "이 변형은 라벨을 바꾸지 않는다"는 사전지식(prior knowledge)을 모델에 주입하는 것이다. 모델은 단순히 "이 픽셀 배열이면 고양이"가 아니라 "이 픽셀 배열의 회전·반전·밝기 변형까지 모두 고양이"라는 더 일반적인 규칙을 배우게 된다.

    학생에게 같은 수학 개념을 한 표현으로만 가르치면, 시험에서 문장이 살짝 바뀌면 무너진다. 같은 개념을 그림, 수식, 일상 비유, 다른 단어로 다섯 가지 방식으로 설명하면 학생은 개념 자체를 배운다. 데이터 증강은 모델에게 "이 라벨은 이런 표면적 변형들의 공통점을 본 결과여야 한다"는 추상화를 강제한다.

    도메인별로 흔히 쓰는 증강은 다음과 같다.

    • 이미지: 좌우 뒤집기(flip), 회전(rotation), 크롭(crop), 색상 지터(color jitter), CutMix, MixUp.
    • 음성: 시간 늘리기, 피치 변화, 잡음 추가, SpecAugment(스펙트로그램에서 시간·주파수 마스킹).
    • 텍스트: 동의어 치환, 역번역(back-translation), 토큰 삭제·삽입.

    중요한 건 도메인 지식에 맞는 증강을 골라야 한다는 점이다. 글자 인식(OCR)에서 좌우 뒤집기는 라벨을 바꾼다(b ↔ d). 의료 영상에서 색상 지터는 진단 정보를 왜곡할 수 있다. 무작정 증강을 늘리면 오히려 해롭다.

    위젯 — 증강이 결정경계를 어떻게 부드럽게 만드는가

    아래 위젯은 작은 2D 분류 문제에서, 같은 데이터에 회전·반전·노이즈 증강을 적용했을 때와 안 했을 때의 결정경계를 비교한다. 같은 망 구조, 같은 학습 epoch인데도 증강을 켜면 경계가 훨씬 부드럽고 일반화 성능이 좋아진다.

    위젯 05데이터 증강 ON/OFF · 결정경계 비교
    증강 OFF — 원본 데이터만
    증강 ON — 회전 + 반전 + 노이즈
    OFF 시험 정확도 = 0% ON 시험 정확도 = 0% 증강 배수 = 5×

    왼쪽: 원본 데이터만으로 학습한 망의 결정경계 — 종종 데이터 점 사이로 구불구불 새어 든다(과적합). 오른쪽: 같은 데이터를 회전·반전·노이즈로 5배 증강해 학습 — 경계가 더 매끄러워지고 시험 정확도가 올라간다.

    노이즈 주입 — 어디에 넣느냐가 의미를 바꾼다

    잡음(noise)을 모델 학습 중에 일부러 넣는 것은 정칙화의 또 다른 큰 갈래다. 어디에 넣느냐에 따라 의미가 달라진다.

    1. 입력 노이즈 — 데이터 증강의 일반화

    입력 $\mathbf{x}$에 작은 가우시안 잡음 $\boldsymbol{\eta}$를 더해 $\tilde{\mathbf{x}} = \mathbf{x} + \boldsymbol{\eta}$로 학습하면, 모델은 입력 근방에서 일관된 예측을 하도록 강제된다. 선형 회귀에서는 이것이 정확히 L2 정칙화와 동치다(공식 7.32 부근). 비선형 망에서는 정확한 동치는 깨지지만, 가중치를 작게 유지하는 압력이 비슷하게 작용한다.

    2. 가중치 노이즈 — 베이지안 신경망과 연결

    가중치 $\mathbf{W}$에 잡음 $\boldsymbol{\eta} \sim \mathcal{N}(0, \sigma^2 \mathbf{I})$를 더해 학습하면, 모델은 가중치의 작은 변화에도 일관된 예측을 하도록 학습한다. 이것은 손실 함수에 "기울기 노름의 제곱"이라는 추가 항을 더하는 것과 비슷하다.

    $$ \tilde{J}(\mathbf{W}) \approx J(\mathbf{W}) + \sigma^2 \mathbb{E}\big[\|\nabla_W \hat{y}\|^2\big] $$

    가중치 노이즈 ≈ 출력의 가중치에 대한 기울기 크기를 줄이는 효과.

    3. 출력 노이즈 (라벨 스무딩) — 과확신을 막는다

    이게 이번 장에서 가장 실용적이고 시험에 자주 나오는 기법이다. 분류 문제에서 정답은 보통 one-hot 인코딩이다 — 정답 클래스는 1, 나머지는 0. 그러면 softmax 출력은 정답에 대해 1에 도달하려고 가중치를 무한히 키운다(softmax는 절대 정확히 1을 출력할 수 없으므로). 이것은 가중치가 발산하는 한 형태의 과적합이다.

    라벨 스무딩(label smoothing)은 정답 라벨을 약간 흐린다. $K$개 클래스, 스무딩 강도 $\epsilon$이면,

    $$ y_k^{\text{smooth}} = \begin{cases} 1 - \epsilon + \epsilon/K & \text{if } k = \text{정답} \\ \epsilon/K & \text{otherwise} \end{cases} $$

    정답에 1 대신 0.9를, 나머지 9개 클래스에 0 대신 약 0.011씩을 부여 (K=10, ε=0.1일 때).

    왜 이렇게 하는가? 모델이 "정답은 무조건 100% 확신"이 아니라 "정답은 90% 확신, 나머지에도 약간의 가능성"이라는 더 겸손한 출력을 내도록 강제한다. 이게 정칙화가 되는 이유는, 가중치가 무한히 키울 동기를 잃기 때문이다. 또한 학습 동역학이 안정화되고, 모델 보정(calibration)이 좋아진다.

    위젯 — 가중치 노이즈가 결정경계를 어떻게 부드럽게 만드는가

    위젯 06가중치 노이즈 σ · 결정경계 변화
    σ = 0 (노이즈 없음)
    σ = 0.20 (학습 시 가중치 노이즈)

    왼쪽: 보통 학습. 결정경계가 데이터 점 사이를 따라가며 들쭉날쭉. 오른쪽: 매 학습 스텝마다 가중치에 작은 가우시안 노이즈를 더해 학습. 같은 데이터, 같은 망인데도 경계가 더 매끄러워진다 — 노이즈가 강한 곡률을 평탄하게 만든다.

    한 줄로 정리

    이 세 기법은 모두 "데이터·입력·라벨 공간에서 자유도를 통제한다"는 점에서 같은 정신이다. 차이는 어디를 흔드느냐다.

    데이터 증강입력의 의미보존 변형을 학습셋에 추가. 불변성 사전지식 주입. 입력 노이즈입력에 가우시안. 선형회귀에서 L2와 동치. 강건성 학습. 가중치 노이즈학습 시 가중치에 가우시안. 기울기 노름 페널티와 유사. 라벨 스무딩정답 라벨을 흐림. 가중치 발산을 막고 보정을 개선.

    다음 장에서는 정칙화의 가장 흥미로운 변종 — 적대적 훈련을 본다. 입력 근방에서 모델을 일부러 무너뜨리는 작은 교란을 찾아내고, 그것을 학습에 포함시켜 강건성을 키우는 방법이다. P1에서 다뤘던 FGSM과 직접 연결된다.
