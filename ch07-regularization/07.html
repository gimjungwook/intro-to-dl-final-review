    한 페이지 요약 — 6개 기법 한눈에

    기법어디서 작동왜 정칙화핵심 식·결과
    L2 (Weight Decay) 가중치 공간 (원형 제약) 가중치를 0 쪽으로 부드럽게 축소, 함수 매끄럽게 w̃_i = λ_i/(λ_i+α) · w*_i
    L1 (Lasso) 가중치 공간 (다이아몬드 제약) 꼭짓점에서 만나 sparsity 생성, 특징 선택 soft-thresholding; 작은 w*는 0으로
    드롭아웃 네트워크 구조 (활성화 마스크) 2ⁿ개 부분망 앙상블, 분산 표상 강제 추론: W ← p · W (가중치 스케일링)
    조기 종료 시간 (학습 epoch 제한) 가중치가 0에서 멀리 자라기 전에 멈춤 α ≈ 1/(ετ) — L2와 동치
    데이터 증강 입력 공간 (의미보존 변형) 불변성 사전지식 주입, 표면 패턴 외움 방지 flip, rotate, crop, mixup, color jitter…
    적대적 훈련 입력 근방 (ε-반경 최악 케이스) 결정경계를 데이터에서 멀리 밀어냄 x_adv = x + ε·sign(∇_x L), minimax

    D-day 우선순위 — 시간이 부족하다면

    최우선 (반드시 답할 수 있어야 함)

    1. L1 vs L2 기하학 — 다이아몬드 vs 원, 왜 L1이 sparsity를 만드는지 그림과 함께 설명.
    2. 조기 종료 ≈ L2 동치 — α = 1/(ετ) 관계, 유도의 2차 근사 조건.
    3. 드롭아웃의 앙상블 해석 — 2ⁿ개 부분망의 기하 평균, weight scaling 추론.
    4. 정칙화의 본질 — 훈련 오차를 늘리고 일반화 오차를 줄이는 편향-분산 교환.

    차우선 (여유가 있다면)

    1. L2의 방향별 선택적 축소 — 헤시안 고유값 분해와 w̃ = λ/(λ+α) · w*.
    2. 데이터 증강의 의미 — 가짜 데이터가 아니라 불변성 사전지식 주입.
    3. 적대적 훈련 vs 일반 정칙화 — 평균 케이스 vs 최악 케이스.
    4. L2 정칙화의 베이지안 해석 — 가우시안 사전, L1은 라플라스 사전.

    혼동하기 쉬운 함정

    1. 정칙화 ≠ 모델 작게 만들기: 큰 모델을 그대로 두고 자유도만 통제. 작게 만들면 표현력 자체를 잃는다.
    2. 정칙화는 훈련 오차를 줄이지 않는다: 오히려 약간 늘려서 일반화를 산다. "훈련 정확도 떨어졌으니 실패"는 잘못된 판단.
    3. 드롭아웃 ≠ 단순 랜덤 삭제: 의존성 분산과 부분망 앙상블이 핵심. "벌칙"으로 이해하면 틀림.
    4. 조기 종료 ≈ L2 동치는 가정에 민감: 2차 근사 + 단순 GD 조건 하에서만 엄밀. 모멘텀·Adam에선 정확한 동치 깨짐.
    5. L1과 L2 둘 다 패널티에 들어가는 α: L2는 (α/2)·||w||² 형태, L1은 α·||w||₁ 형태 (1/2 없음).
    6. 증강은 도메인 의존: OCR에서 좌우 뒤집기, 의료에서 색 변경 등은 라벨을 바꾸므로 금지.

    예상 서술형 질문 (회고에서 추출)

    1. L1과 L2 정칙화의 차이를 기하학적으로 설명하고, 각각 어떤 상황에 적합한지 서술하시오.
    2. 조기 종료가 왜 정칙화의 한 형태인지 수학적으로 설명하시오. (L2와의 동치성 유도)
    3. 드롭아웃이 앙상블 학습과 어떤 관계인지 설명하시오. (2ⁿ개 부분망, 기하 평균 근사)
    4. L2 정칙화가 최적화 과정에 미치는 영향을 헤시안의 고유값을 이용하여 설명하시오. (조건수 개선)
    5. 적대적 훈련이 일반 과적합 방지와 어떻게 다른지, 그리고 FGSM이 공격과 방어 양쪽에서 어떻게 쓰이는지 설명하시오.
    6. 데이터 증강이 단순한 데이터 복제가 아니라 어떤 사전지식을 모델에 넣는 것인지 설명하시오.
    7. 큰 모델 + 강한 정칙화가 작은 모델보다 자주 더 좋은 이유를 편향-분산 분해로 설명하시오.
