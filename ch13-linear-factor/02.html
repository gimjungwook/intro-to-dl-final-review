Sub-chapter 02 / 갈림길

    책의 후반부가 갈라지는 지점 —
    판별에서 생성으로

    1-12장의 분류기는 "이 사진이 고양이일 확률은?"이라는 한 가지 물음에만 답했다. 13장부터 모델은 한 단계 더 야심 찬 일을 한다 — "고양이 사진 자체를 처음부터 만들어 낼 수 있는가?" 이 한 줄의 차이가 책의 후반부 전부를 가른다.

    1장부터 12장까지 우리가 본 모든 신경망은 한 가족에 속한다. 판별 모델(discriminative model)이라는 가족이다. 이름이 어려워 보이지만 풀어 쓰면 단순하다. 입력 $x$가 들어왔을 때 라벨 $y$가 무엇인지를 골라내는(discriminate, 분간하다) 모델이라는 뜻이다. 합성곱 신경망(CNN)이 이미지를 받아 1000개 카테고리 중 하나를 고르는 일, 순환 신경망(RNN)이 단어 시퀀스를 받아 다음 단어를 예측하는 일, 둘 다 같은 형태다. 수식으로 적으면 우리가 학습한 것은 조건부 확률 $p(y \mid x)$ 하나다.

    13장이 새로 가르치는 것은 다른 가족이다. 생성 모델(generative model). 이름 그대로, 데이터를 분류하는 게 아니라 데이터를 만들어 내는 모델이다. 이 모델이 학습하는 것은 $p(y|x)$가 아니라 $p(x)$ 자체, 즉 "이 데이터 분포 전체가 어떻게 생겼는가"의 확률 밀도다. 라벨이 있는 경우라면 $p(x, y)$ 또는 $p(x \mid y)$를 학습한다. 어느 쪽이든 입력 $x$의 분포 자체를 안다는 뜻이고, 그 결과 새로운 가짜 $x$를 만들어 낼 수 있다.

    판별 모델은 위조지폐 감별사다. 지폐 한 장을 받아 보고 "진짜다, 가짜다"를 판단한다. 그 일을 잘 하려면 진짜 지폐의 특징을 어느 정도 알아야 하지만, 자기 손으로 새 지폐를 그릴 줄은 모른다. 생성 모델은 지폐를 그리는 사람이다. 진짜 지폐가 갖춰야 할 모든 패턴을 머릿속에 담고 있어서 새 지폐를 처음부터 그려낼 수 있다. 그릴 수 있는 사람은 감별도 잘 한다(자기가 만든 것과 비교하면 되니까). 거꾸로는 성립하지 않는다 — 감별만 할 줄 아는 사람이 그릴 수는 없다.

    왜 $p(x)$를 배우는 것이 본질적으로 더 어려운가

    $p(y|x)$만 배우면 되는 판별 학습이 왜 더 쉬운가. 한 줄로 답할 수 있다. "$x$가 어떤 모양이든 신경 쓰지 않아도 되기 때문"이다. 분류기는 $x$의 분포 자체에는 관심이 없다. 들어오는 $x$들이 모두 같은 분포에서 나왔다고 가정하고, 그 분포에서 라벨로 가는 매핑만 알면 된다. 학습 데이터에 있는 $x$만 잘 분류하면 평가에서 이긴다.

    $p(x)$를 배운다는 것은 다른 차원의 일이다. 사진 한 장은 보통 224×224×3 = 약 15만 개의 픽셀 숫자다. 가능한 모든 사진의 공간은 상상하기 힘들 만큼 크다. 그 거대한 공간에서 "실제로 의미 있는 사진"이 어디에 몰려 있는지를 알아내는 게 $p(x)$를 배우는 일이다. 새 픽셀 텐서가 들어왔을 때 "이건 풍경 사진처럼 보이는 진짜 같은 패턴이다"와 "이건 그냥 무작위 잡음이다"를 구분할 수 있어야 한다. 그 정도로 $p(x)$를 잡으려면 모델이 데이터의 구조를 깊이 이해해야 한다.

    13장이 다루는 선형 요소 모델은 가장 단순한 형태로 $p(x)$를 모델링한다. 어떻게? "관측 $x$는 몇 개의 잠재 $h$가 선형으로 섞이고 잡음이 더해진 결과"라는 단순한 생성 이야기 하나로. 이 이야기 위에서 $p(x)$가 자동으로 정의된다 — 모든 가능한 $h$에 대해 $p(x \mid h)$를 평균낸 적분 $p(x) = \int p(x \mid h) p(h) \, dh$가 곧 $p(x)$다. 가우시안 가정 아래에서는 이 적분이 해석적으로 계산되어 $p(x)$가 다시 가우시안이 된다. 선형 요소 모델이 단순한 이유, 그리고 한계가 있는 이유가 다 여기서 나온다.

    두 가족이 할 수 있는 일이 어떻게 다른가

    같은 데이터를 받아도 판별 모델과 생성 모델은 할 수 있는 일이 다르다. 이 차이를 구체적으로 보면 왜 책이 굳이 13장부터 생성 모델을 가르치는지가 보인다. 다음 표는 같은 데이터셋(예: MNIST 손글씨 숫자 6만 장)을 받아 두 가족이 각각 무엇을 할 수 있는지를 정리한 것이다.

    판별 모델 $p(y \mid x)$생성 모델 $p(x)$ 또는 $p(x, y)$
    분류주요 목적. 입력 받아 라벨 출력가능. $p(y \mid x) \propto p(x \mid y) p(y)$로 베이즈 적용
    새 데이터 생성불가. 라벨에서 입력으로 가는 경로 없음가능. $p(h)$에서 $h$ 뽑고 $x = Wh + b + \epsilon$
    이상치 탐지어려움. 분포 정보 없음자연. $p(x)$가 낮은 $x$가 이상치
    결측치 보완거의 불가. 보지 못한 입력 처리 모름가능. $p(x_{missing} \mid x_{visible})$로 조건부 추론
    표상 학습최종 분류기에 유용한 표상만 학습데이터 구조를 가장 잘 설명하는 표상 학습
    준지도 학습라벨 없는 데이터를 거의 활용 못함$p(x)$로 라벨 없는 데이터 적극 활용

    이 표가 보여 주는 것은 한 가지 큰 그림이다. 판별 모델은 "정해진 한 작업에서 가장 잘 하는 도구"이고, 생성 모델은 "데이터 자체를 이해하려는 시도"다. 생성 모델이 더 야심 차고, 그 야심을 채우려면 더 많은 데이터와 더 정교한 모델이 필요하다. 그래서 1-12장이 끝나야 비로소 13장이 시작되는 것이다 — 1-12장에서 만든 부품들 위에서야 비로소 생성 모델을 진지하게 다룰 수 있기 때문이다.

    위젯 02같은 두 클래스 데이터 · 두 모델의 시선이 어떻게 다른가
    판별 모델 — 경계선만 찾음

    두 클래스를 가르는 곡선 하나만 그린다. 빨강 영역과 파랑 영역 어디든 들어오는 점이라면 어느 쪽인지 즉시 답한다. 빨강 점이 어떻게 생겼는지는 모른다.

    생성 모델 — 분포 전체를 모델링

    각 클래스의 분포(타원)를 학습한다. 빨강이 어떤 모양인지, 파랑이 어떤 모양인지 둘 다 안다. 새 빨강 점을 만들 수도 있고, 분포에서 멀리 떨어진 점을 이상치로 잡아낼 수도 있다.

    같은 데이터를 받아도 판별 모델은 "경계만 정확히" 그리고, 생성 모델은 "각 클래스가 어디에 몰려 있는지" 전체를 그린다. 이상치 한 점을 추가하면 판별 모델은 여전히 그 점을 한쪽 클래스로 자신 있게 분류하지만, 생성 모델은 "두 분포 어디에도 속하지 않는다"고 정직하게 답한다.

    잠재 변수가 왜 생성 모델의 핵심 장치인가

    생성 모델이라고 해서 반드시 잠재 변수를 써야 하는 것은 아니다. 자기회귀 모델(autoregressive model)은 잠재 변수 없이 $p(x_1, x_2, \ldots, x_d) = p(x_1) p(x_2 \mid x_1) \cdots p(x_d \mid x_{1:d-1})$로 분해해서 픽셀 하나씩 차례로 예측한다. 그런데 책이 13장에서 굳이 잠재 변수 모델로 생성 모델 이야기를 시작한 데는 이유가 있다.

    이유는 "표상(representation)"이라는 단어로 요약된다. 잠재 변수 $h$는 단지 데이터를 만드는 도구가 아니다. 데이터를 더 짧고 더 의미 있게 요약한 표상이다. 224×224×3 = 15만 차원의 픽셀 텐서를 가지고 있다고 해 보자. 사람 얼굴 사진이라면 그 15만 숫자 뒤에 정말로 흔드는 다이얼은 몇 개 안 된다 — 성별, 나이, 표정, 조명 방향, 머리카락 색깔 등. 잘 학습된 잠재 변수 모델은 $h$가 바로 그런 의미 있는 다이얼이 되도록 한다. 그러면 $h$는 분류, 클러스터링, 검색, 시각화 등 거의 모든 다음 작업에서 픽셀 텐서보다 훨씬 유용한 입력이 된다.

    이게 13장이 책의 후반부 첫 장인 이유다. 후반부 전체(13장 선형 요소 → 14장 오토인코더 → 15장 표상학습 → 16-20장 확률 모델, GAN, VAE 등)가 결국 다음 한 가지 질문에 답하려 한다. "좋은 표상은 어떻게 학습하는가, 그리고 그 표상으로 어떤 일이 가능한가." 13장은 그 질문에 답하는 가장 단순한 도구를 먼저 제시한다 — 선형으로, 가우시안 가정으로, 잠재 변수 한 줌으로.

    분류기로도 쓸 수 있는데 왜 굳이 다른 모델인가

    실용 관점에서 자연스럽게 떠오르는 질문이 있다. "생성 모델로 베이즈 정리를 거치면 분류기로도 쓸 수 있다는데, 그러면 판별 모델보다 좋지 않은가?" 답은 둘 다 맞는데, 어느 쪽이 이기는지는 데이터 양과 모델의 가정이 맞는지에 달려 있다.

    이 비교의 고전적인 결과는 Ng와 Jordan(2002)이 정리했다. 그들이 보인 것은 두 가지다. 첫째, 데이터가 매우 적을 때는 생성 모델이 더 강하다. 모델이 데이터 구조에 강한 가정을 깔기 때문에 적은 데이터에서도 그 가정이 도움을 준다. 둘째, 데이터가 충분히 많아지면 판별 모델이 결국 더 낮은 오류로 수렴한다. 가정 없이 직접 $p(y \mid x)$를 학습하기 때문에 데이터가 많을수록 유연하게 적응한다. 다만 이건 모델의 생성 가정이 맞을 때 이야기이고, 가정이 틀리면 생성 모델은 적은 데이터에서도 잘못된 방향으로 빠진다.

    생성 모델과 판별 모델은 우열의 문제가 아니다. 다른 일을 하는 다른 도구다. 분류 정확도만 보면 판별 모델이 보통 이기지만, 새 데이터 생성, 이상치 탐지, 결측치 보완, 표상 학습 같은 작업에서는 생성 모델만이 답을 준다. 13장 이후를 읽을 때는 "분류 정확도가 얼마인가?"가 아니라 "이 모델이 데이터를 어떻게 이해했는가?"를 보아야 한다.

    이 장의 위치 — 가장 단순한 생성 모델부터

    13장이 다루는 선형 요소 모델은 생성 모델 가족 안에서도 가장 단순한 자리에 있다. 분포는 가우시안, 잠재에서 관측으로 가는 사상은 선형. 이 두 단순화 덕분에 모든 것이 손으로 계산되고, 모든 것이 기하적으로 직관 가능하다. 그래서 책이 생성 모델을 처음 가르치는 자리에 이 가족을 놓았다. 14장 오토인코더는 이 가족의 선형성을 비선형으로 풀고, 15장 표상학습은 학습된 잠재가 왜 좋은 표상인가를 정리하고, 16장 이후는 분포를 가우시안 너머로 확장한다. 그러니까 13장의 모든 모델은 후반부의 출발 베이스라인이다.

    다음 절부터는 이 가족 안에서 갈라지는 모델들을 하나씩 본다. 첫째로 보는 것은 요소 분석(Factor Analysis)이다 — 잠재가 가우시안이고 잡음이 차원마다 다른 가우시안인, "가장 표현력 있는 가우시안 가족"이다.
