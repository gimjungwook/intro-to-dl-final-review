관측의 뒤에는
몇 개의 숨은 다이얼이 있다

딥러닝 개론 기말고사 인터랙티브 복습 저자 Goodfellow, Bengio, Courville (2016) 읽는 시간 약 80분 D-day 2026-06-04

한 문장으로

Chapter 13은 책이 처음으로 생성 모델(generative model)이라는 큰 가족에 발을 들이는 장이다. 가장 단순한 형태인 선형 요소 모델(linear factor model)로 시작하는데, 한 줄로 요약하면 "관측된 데이터 x는 우리가 직접 못 보는 몇 개의 숨은 요소(latent factor) h를 선형으로 섞고 잡음을 더해서 만들어졌다"는 가정이다.

이 단순한 가정 하나에서 요소 분석(Factor Analysis), 확률적 PCA(Probabilistic PCA), PCA(Principal Component Analysis), ICA(Independent Component Analysis), 희소 코딩(sparse coding), 슬로우 피처 분석(Slow Feature Analysis)이 모두 갈라져 나온다. 갈라지는 분기점은 단 두 곳이다 — "숨은 요소 h에 어떤 분포를 가정하는가"와 "잡음을 어떻게 다루는가". 이 두 다이얼을 어떻게 돌리느냐가 모델의 성격을 결정한다.

잠재 (Latent · 못 보는 원인)

관측 뒤에서 데이터를 만들어 내는 몇 개의 숨은 다이얼. h라는 짧은 벡터로 표현된다. h에 어떤 사전 분포(prior)를 가정하느냐 — 가우시안, 비가우시안, 희소, 천천히 변함 — 가 모델을 가른다. 이 사이트에서 웜한 주홍으로 표시된다.

관측 (Observed · 우리가 본 결과)

실제로 우리 손에 들어오는 데이터 x. 픽셀, 음파, 평점, 신호. 모델은 "h가 어떻게 섞여서 x가 됐는가"라는 선형 사상 x = Wh + b + 잡음 을 가정한다. 이 사이트에서 차분한 파랑으로 표시된다.

권장 읽기 순서

이 해설은 Goodfellow, Bengio, Courville(2016) 13장 "Linear Factor Models"를 바탕으로 재구성한 시험 대비 자료다. 12개 sub-chapter로 나눠 잠재 변수의 직관에서 시작해 PCA, ICA, 희소 코딩, 슬로우 피처 분석, 매니폴드(manifold)까지 단계적으로 쌓는다. 각 절은 "왜 이 모델이 그런 모양인가"를 비유와 위젯으로 풀고, 시험 대비 마지막 절에 15-20개 자가점검 카드를 둔다. 위젯은 PCA 2D 투영, ICA-PCA 축 비교, 희소 코딩 사전 시각화, 요소 분석 잠재 to 관측 흐름, 매니폴드 평면 vs 곡면, 칵테일 파티 신호 분리 등으로 직접 만져 본다.
