Sub-chapter 11 / 마지막 한 시간

    시험 대비 —
    한 장으로 정리한 응용 챕터

    D-day 직전에 다시 펼쳐 보기 위한 페이지. 다섯 도메인의 한 줄 정답, 도메인 비교 표, 예상 문제 7개의 모범 답안, 그리고 시험장에서 꼭 끌어내야 할 키워드 체크리스트.

    다섯 도메인 — 카드 한 장 요약

    각 도메인의 “본체 + 핵심 트릭 + 시험 단골 키워드”를 한 카드에 담았다. 한 카드를 5초 안에 머릿속에 떠올릴 수 있어야 한다.

    Vision
    CNN + softmax + NLL. ImageNet 사전훈련 가중치 사용. 표준화·증강·국소 대비 정규화로 “외울 필요 없는 변이”를 미리 제거.
    사전학습 · 증강 · 정규화
    Speech
    스펙트로그램 + RNN/Transformer + CTC. 파형은 너무 길어 STFT로 압축. 정렬 문제를 CTC가 자동으로 학습.
    STFT · CTC · end-to-end
    NLP
    임베딩 + 인코더-디코더 + 어텐션. 차원의 저주를 분산 표상으로 해소. 큰 어휘 softmax는 hierarchical·NCE·sampling.
    임베딩 · 어텐션 · NCE
    RecSys
    행렬 분해 = 임베딩 내적. 관찰된 칸만 손실에 부과. 콜드 스타트 + 탐험-착취 충돌이 RL로 이어짐.
    잠재 인자 · 콜드 스타트
    RL
    정책/가치 신경망 + 누적 할인 보상. ε-greedy로 탐험-착취 균형. DQN(가치 기반) vs REINFORCE(정책 기반).
    벨만 · DQN · ε-greedy

    도메인 비교 표 — 같은 골격, 다른 옷

    응용 챕터의 모든 시험 문제는 결국 이 표로 환원된다. 도메인이 다르면 무엇이 바뀌고 무엇이 그대로인가.

    예상 문제 7개 — 클릭하면 모범 답안

    아래는 본 챕터의 LMS 질문 2개를 포함해, 응용 챕터에서 “출제자가 묻고 싶어할” 질문 7개의 모범 답안이다. 시험 직전 30분에 펼쳐서 답이 자동으로 나오는지 확인해 보면 된다.

    시험장에서 꼭 끌어내야 할 키워드 체크리스트

    답안에 다음 키워드들이 들어가면 점수가 안정된다. 답안을 한 줄 쓰고 “이 키워드 중 두 개가 들어갔는가?”를 자문하라.

    • 비전 분류 워크플로를 묻는 문제 → 표준화·증강·사전훈련(transfer learning)·softmax·음의 로그우도(NLL)·국소 대비 정규화
    • 음성 인식 진화를 묻는 문제 → GMM-HMM·DNN-HMM·CTC·end-to-end LSTM·2D conv on spectrogram·17.7%
    • 왜 임베딩이냐를 묻는 문제 → 차원의 저주·one-hot 등거리 문제·분포 가설·분산 표상·의미적 방향(king-man+woman)
    • 왜 어텐션이냐를 묻는 문제 → 고정 요약 벡터 한계·긴 시퀀스 정보 손실·soft alignment·미분 가능한 정렬 학습·NMT가 첫 등장 도메인
    • 큰 어휘 softmax를 묻는 문제 → hierarchical softmax·NCE·importance sampling·negative sampling·O(N) → O(log N)
    • 행렬 분해 추천을 묻는 문제 → 희소성·R ≈ UVᵀ·관찰값에만 손실·L2 정칙화·잠재 인자(latent factor)·콜드 스타트
    • RL의 본질적 어려움을 묻는 문제 → 탐험-착취 trade-off·지연 보상(credit assignment)·닫힌 루프 데이터·분포 이동·ε-greedy
    • 도메인 비교를 묻는 문제 → 입력 모양·본체(CNN/RNN/임베딩)·손실 함수(NLL/CTC/MSE/벨만)·도메인 고유 증강

    다음으로 — 13-15장과의 연결

    응용 챕터는 책의 Part II(현대적 실천)의 마지막 장이다. 여기서 보인 임베딩과 표상이라는 키워드는 곧장 Part III의 큰 주제로 이어진다.

    • 13장 선형 요소 모델 → PCA·ICA·희소 코딩. 비지도로 분산 표상을 잡는 가장 단순한 방법들. 추천 시스템의 행렬 분해가 PCA의 사촌.
    • 14장 자기부호화기 → 입력을 재구성하도록 학습하면 가운데 층에 “저차원 표상”이 자동으로 잡힌다. 단어 임베딩의 일반화.
    • 15장 표상 학습 → 사전훈련·전이학습·매니폴드 가정·인과 요소. 응용 챕터의 “사전학습”이 왜 작동하는지의 이론적 뼈대.

    시험 D-9에서 가장 시간 대비 효과가 좋은 복습 경로는 Ch.9(CNN) → Ch.10(RNN) → Ch.12(응용)의 삼각형이다. Ch.12는 단독으로 외울 게 많지 않다 — Ch.9·10의 부품이 어떻게 도메인별로 조립되는지의 카탈로그라는 점만 기억하면, 단답형이든 서술형이든 안정적으로 답이 나온다.
