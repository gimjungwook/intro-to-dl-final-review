📖 이 페이지의 사용법

교수님이 배포한 Problem Set for Final의 26문항을 주제별 여섯 갈래로 묶고, 각 문항을 “정의 → 왜 그런가 → 비유 → 시험 답안 골격”의 순서로 풀었다. 아래 카드를 누르면 해당 문항의 답안 위치로 곧장 이동한다.

모든 답은 15장 인터랙티브 복습 사이트와 같은 라이트 테마, 같은 위젯 문법을 쓴다. 수식은 KaTeX로, 비교는 카드로, 핵심 직관은 캔버스/SVG 위젯으로 직접 만져 볼 수 있다. 각 문항 끝의 “시험 답안 골격” 체크리스트는 시험장에서 1분 안에 적을 수 있는 최소 골자다.

🚀 D-6, 우선순위 추천 경로

  1. 1갈래 정칙화 · 2갈래 최적화 — 13문항(Q1-8, 15-16, 22-23)이 여기 몰려 있다. 출제 비중 1순위.
  2. 3갈래 CNN · 4갈래 RNN — 구조적 사전(prior)과 파라미터 공유라는 한 줄거리로 묶어 외운다(Q9-14).
  3. 6갈래 핵심 논문 — 스타일 전이 · Transformer · BERT/GPT(Q24-26). “한 문장 핵심”을 먼저 잡는다.
  4. 5갈래 비지도 · 표상 — SFA, 오토인코더, 분산 표상(Q17-21). 후반부 진도 직접 출제.
🛡️ 갈래 1 · 정칙화와 일반화

데이터가 모델보다 작을 때 과적합을 어떻게 막는가. 7장의 정칙화 전체와 적대적 예제, RBF 네트워크까지.

⚙️ 갈래 2 · 최적화와 하이퍼파라미터

손실 곡면 위에서 학습이 실제로 어떻게 움직이는가. 1차·2차 방법, 미니배치, 모멘텀, 절벽, 대칭성, 클리핑, 그리고 탐색 전략.

🖼️ 갈래 3 · 합성곱 신경망(CNN)

이미지의 구조를 네트워크에 새겨 넣는 세 가지 사전. 무한히 강한 사전이라는 9장의 핵심 관점.

🔁 갈래 4 · 순환 신경망과 시퀀스

시간을 펼친 그래프. RNN과 재귀 신경망의 관계, LSTM의 기억 보존, RNN과 CNN의 파라미터 공유 비교.

🧭 갈래 5 · 비지도 학습과 표상

라벨 없이 무엇을 배우는가. SFA, 오토인코더와 PCA, 정칙화된 오토인코더, 분산 표상의 위력.

📜 갈래 6 · 핵심 논문

강의에서 직접 다룬 세 논문의 단 하나의 핵심 — 신경 스타일 전이, Transformer, 그리고 BERT 대 GPT.

이 풀이는 교수님이 배포한 기말 문제은행(Problem Set for Final, 26문항)을 Goodfellow, Bengio, Courville(2016) 7-15장과 강의에서 다룬 세 논문에 비추어 직접 정리한 것이다. 15장 인터랙티브 복습 사이트(표지)의 디자인 시스템을 그대로 따른다.
