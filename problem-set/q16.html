🎰 Q16 · 그리드 탐색과 무작위 탐색

In hyperparameter search, what is grid search and random search?

📌 질문 해석

“hyperparameter search에서 grid search와 random search란?” 각 정의 + 왜 random이 종종 이기는지가 핵심 포인트.

🎰 Hyperparameter(learning rate, 층 수, 정칙화 계수 등)는 gradient descent로 학습되지 않으니 바깥에서 탐색해야 한다. 두 기본 전략:

🔲 Grid Search

  • 각 하이퍼파라미터마다 후보 값 몇 개를 정해 모든 조합(Cartesian product) 시도.
  • 예: lr 3값 × reg 3값 = 9회.
  • 하이퍼파라미터 수에 따라 시도가 지수 폭발(curse of dimensionality) 💣.

🎲 Random Search

  • 각 하이퍼파라미터를 분포에서 무작위 추출해 정해진 횟수만큼 시도.
  • 연속 범위를 자연스럽게 다루고, 시도 추가·병렬화가 쉽다.
  • 같은 예산에서 보통 grid보다 좋은 값을 찾음 🏆.

🔑 왜 random이 이기나? 핵심 관찰: 대개 소수의 하이퍼파라미터만 성능에 크게 영향을 준다. $3 \times 3$ grid는 9번을 쓰지만 각 파라미터의 서로 다른 값은 3개뿐 — 중요한 축의 해상도가 3에 묶인다. 같은 9번을 random으로 쓰면 두 점이 좌표를 공유할 일이 거의 없어 각 파라미터마다 9개의 서로 다른 값을 시험 → 중요한 축을 3배 촘촘히 훑는다 🔍.

🧠 더 똑똑한 후속은 Bayesian optimization — 지금까지 결과로 성능 곡면의 surrogate 모델을 세우고 다음 시도값을 영리하게 고른다. 하지만 단순함·병렬성·강건함 덕에 random search가 여전히 강력한 기본값이다 ✅.

📌 What the question asks

“What are grid search and random search?” Definitions plus why random often wins.

🎰 Hyperparameters (learning rate, depth, regularization strength) are not learned by gradient descent, so we search them externally. Two basic strategies:

🔲 Grid Search

  • Pick a few values per hyperparameter; try every combination (Cartesian product).
  • e.g. 3 lr × 3 reg = 9 trials.
  • Trials explode exponentially with the number of hyperparameters 💣.

🎲 Random Search

  • Sample each hyperparameter from a distribution for a fixed number of trials.
  • Handles continuous ranges; easy to add trials / parallelize.
  • Usually finds a better value for the same budget 🏆.

🔑 Why random wins: usually only a few hyperparameters matter. A 3×3 grid tests just 3 distinct values of each, whereas 9 random trials test 9 distinct values of the important one — exploring it 3× more finely for the same budget 🔍.

🧠 The smarter successor is Bayesian optimization (build a surrogate of the performance surface and pick the next point cleverly), but random search remains a strong, trivially parallel baseline ✅.

위젯 16같은 9회 예산 — 중요한 축을 몇 개의 값으로 훑는가

위쪽 곡선이 “중요한 하이퍼파라미터”의 진짜 성능, 옆 축은 “중요하지 않은 파라미터”다. 그리드(왼쪽)는 중요한 축을 sqrt(N) 개 값만 훑지만, 무작위(오른쪽)는 N개의 서로 다른 값을 훑어 봉우리를 맞힐 확률이 높다.

🎯 Model Answer (English)

Both search hyperparameters that gradient descent cannot tune. Grid search picks a few candidate values per hyperparameter and tries every combination (the Cartesian product), so the number of trials grows exponentially with the number of hyperparameters. Random search instead samples each hyperparameter from a distribution for a fixed number of trials. Random usually wins because typically only a few hyperparameters matter: a 3-by-3 grid tests only 3 distinct values of each parameter, whereas 9 random trials test 9 distinct values of the important one — exploring it three times more finely for the same budget. Bayesian optimisation is the smarter successor, but random search remains a strong, trivially parallelisable baseline.

📝 시험 답안 골격

  • 그리드 = 후보값들의 모든 조합. 무작위 = 분포에서 N번 추출.
  • 그리드는 차원에 지수 폭발 + 각 축을 적은 값만 시험. 무작위는 각 축을 N개 서로 다른 값으로.
  • 이유 — 소수 파라미터만 중요. 무작위가 중요 축을 더 촘촘히. (베이지안 최적화는 더 똑똑한 후속.)
