🧭 비지도 학습과 표상 · 22 / 26

🧭 Q20 · 비지도 학습이 다운스트림 과제를 돕는 이유

Why is unsupervised learning helpful for the downstream tasks like classification?

📌 질문 해석

“비지도 학습이 왜 분류 같은 다운스트림 과제에 도움이 되나?” 핵심은 입력 분포의 구조가 라벨 예측에 대한 정보를 담는다는 가정.

🧭 비지도 학습은 라벨이 전혀 없는 데이터로부터 의미 있는 표현을 학습하는 방식이다. 직관적으로는 "라벨이 없는데 어떻게 분류 같은 라벨 기반 task에 도움이 될 수 있나?"가 의문이지만, 답은 데이터 분포의 구조에 있다.

💡 핵심 가정

비지도 학습이 분류 같은 다운스트림(downstream) task에 도움이 되는 이유는 한 가지 가정에 기반한다 — 입력 데이터의 분포 구조가 우리가 예측하고자 하는 라벨에 대한 정보를 담고 있다는 것이다.

더 풀어서 설명하면, 입력 데이터를 만들어내는 변동 인자(factors of variation)와 우리가 예측하려는 라벨을 만들어내는 인자가 상당 부분 겹친다는 가정이다. 예를 들어 "이 이미지가 강아지인가 고양이인가"를 결정하는 인자는, "이미지가 어떻게 생겼는가"를 결정하는 인자와 깊이 연관되어 있다 — 종 자체가 외모를 결정하니까.

🪐 구체적으로: Cluster와 Manifold

이 가정을 구체화하면 두 가지 관찰로 이어진다.

1) 같은 클래스의 예제들은 입력 공간에서 군집(cluster)을 이룬다. 강아지 이미지들끼리는 픽셀 공간에서 서로 가까이 모여 있고, 고양이 이미지들도 따로 모여 있다. 두 군집 사이는 비교적 비어 있다.

2) 같은 클래스의 예제들은 같은 곡면(manifold) 위에 놓인다. 강아지 이미지의 변동(자세, 색깔, 각도 등)은 픽셀 공간에서 어떤 부드러운 곡면 위를 움직이며 만들어진다. 그 곡면 자체가 "강아지다움"의 본질을 담는다.

비지도 학습은 라벨 없이 이 cluster, manifold, 그리고 그 안의 변동 인자들을 발견한다. 그 결과 입력 공간에서의 "좋은 표현"이 만들어진다 — 같은 클래스끼리는 표현 공간에서도 가깝고, 다른 클래스는 멀어진다.

이 표현 공간 위에서 분류기를 학습하면 일이 훨씬 쉬워진다. 같은 클래스끼리 이미 잘 모여 있으니 분류 경계(decision boundary)가 단순한 형태가 된다. 더 적은 라벨로도 학습 가능하고, 새 데이터에 더 잘 일반화된다.

🔧 실무에서의 두 가지 활용 방식

1) Pretraining / Initialization (사전훈련 / 초기화)

대량의 비라벨 데이터로 먼저 비지도 학습을 시켜 좋은 표현을 만든다. 이 모델의 가중치가 다운스트림 task를 위한 "좋은 초기값" 역할을 한다. 그 후 작은 양의 라벨 데이터로 fine-tuning하면 처음부터 학습하는 것보다 훨씬 빠르고 잘 수렴한다.

이 효과는 두 가지 측면에서 작동한다. 첫째, 초기값 자체가 가치 있는 정보를 담고 있어 학습이 좋은 영역에서 시작한다. 둘째, 그 초기값이 일종의 정칙화 역할을 해서 모델이 작은 라벨 데이터에 과적합하는 걸 막아준다.

2) Semi-supervised (반지도 학습)

지도 학습과 비지도 학습이 같은 표현을 공유하면서 동시에 학습된다. 한 쪽은 라벨을 예측하고 다른 한 쪽은 입력 자체의 구조를 학습하는데, 두 과제가 표현을 공유하니 비지도 신호가 지도 학습을 지속적으로 돕는다.

📌 대표 예시

이 원리가 실제로 잘 작동하는 예가 많다.

NLP 분야: BERT, GPT 같은 대규모 언어 모델은 인터넷의 비라벨 텍스트로 "다음 단어 예측" 같은 비지도 task로 사전훈련된다. 이렇게 학습된 단어와 문장 표현이 감정 분류, 질문 응답, 번역 등 모든 다운스트림 NLP task에 압도적으로 도움이 된다. ChatGPT 시대의 핵심이 바로 이 접근이다.

컴퓨터 비전: Autoencoder나 SimCLR 같은 self-supervised 방법으로 비라벨 이미지로 학습한 모델은 edge, texture, object parts 같은 일반 시각 특징을 학습하고, 이게 의료 영상 분류 같은 작은 데이터셋 task에 큰 도움이 된다.

⚠️ 만능은 아니다: 한계와 조건

이 접근이 항상 도움이 되는 건 아니다. 핵심 조건은 비지도 학습으로 발견한 특징이 실제로 우리가 예측하려는 라벨과 관련이 있어야 한다는 것이다.

예를 들어 라벨이 입력의 매우 사소한 측면에만 의존하는 경우(예: 이미지의 한 모서리 픽셀 값으로 분류 라벨이 결정되는 인위적 task), 비지도 학습이 그 사소한 측면을 발견할 가능성이 낮다. 비지도 학습은 데이터의 주요 변동 인자를 찾는 데 집중하니, 그 변동 인자와 라벨이 무관하면 도움이 안 되거나 오히려 해로울 수 있다.

다행히 자연 데이터(이미지, 텍스트, 음성)의 경우 이 조건이 거의 항상 만족된다. 그래서 현대 딥러닝에서 비지도/self-supervised 사전훈련은 사실상 표준이 되었다.

🎯 정리

"비지도 학습이 왜 분류 같은 다운스트림 task에 도움이 되나?"에 대한 답은 다음과 같다. 입력 분포의 구조가 라벨에 대한 정보를 담기 때문이다. 비지도 학습은 라벨 없이 이 구조(cluster, manifold, 변동 인자)를 발견해 좋은 표현을 만들고, 그 표현 위에서 분류 같은 task가 훨씬 적은 라벨로도 잘 학습된다. 단 비지도 특징과 라벨이 실제로 관련 있을 때만 효과가 있다.

📌 What the question asks

“Why does unsupervised learning help downstream tasks like classification?” The key assumption: $p(x)$'s structure informs $p(y\mid x)$.

🧭 Core assumption: the structure of the input distribution $p(x)$ carries information about $p(y\mid x)$. The factors of variation that shape $p(x)$ overlap with what we want to predict 🔗.

🪐 Examples of one class form clusters or lie on a shared manifold. Unsupervised learning discovers these without labels, producing a good representation of $x$ in which the decision boundary is simple — so the classifier needs fewer labels and generalizes better 📈.

🔧 Two uses: ① pretraining / initialization — learn from abundant unlabeled data, then fine-tune; ② semi-supervised shared representations — e.g. 🗣️ word embeddings from a language model help downstream NLP, and autoencoder edges/textures help vision.

⚠️ Not magic — it helps only when the unsupervised features are actually relevant to $y$. If $p(x)$ and $p(y\mid x)$ are unrelated, pretraining may not help, or may hurt.

🎯 Model Answer (English)

The core assumption is that the structure of the input distribution carries information about the label distribution: the factors of variation that shape the inputs overlap substantially with the factors we want to predict. Examples of one class cluster together or lie on a shared manifold, and unsupervised learning discovers these clusters, manifolds and factors without labels, producing a good representation of the input in which the decision boundary becomes simple — so the downstream classifier needs fewer labels and generalises better. In practice it is used as pre-training/initialisation (learn from abundant unlabelled data, then fine-tune) or as semi-supervised shared representations, e.g. word embeddings from a language model or edges and textures from an autoencoder. The caveat: it helps only when the unsupervised features are actually relevant to the label — if the input distribution structure and the label predictor are unrelated, it may not help.

📝 시험 답안 골격

  • 핵심 — 입력 분포 구조가 라벨에 대한 정보를 담음. 군집/매니폴드/변동 인자가 라벨과 겹침.
  • 비지도 학습이 좋은 표현을 발견 → 그 표현 공간에서 분류 단순화, 적은 라벨로 일반화.
  • 실무 — 사전훈련/초기화 + 반지도 학습. 예: BERT 단어 임베딩, autoencoder 시각 특징. 단 비지도 특징이 라벨과 관련될 때만 효과.
