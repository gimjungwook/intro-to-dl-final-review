갈래 1 / 정칙화와 일반화 · Q1·2·3·22·23

    일반화 격차를 줄이는
    다섯 개의 손잡이

    정칙화(regularization)는 “훈련 오차를 늘리더라도 일반화 오차를 줄이는 모든 수정”이다. 7장은 그 손잡이를 모아 둔 서랍이다. 데이터가 모델보다 작을 때, 데이터로 거는 트릭, 그리고 그 모든 것을 시험하는 적대적 예제까지 한자리에 둔다.

    📉 Q1 · 작은 데이터셋의 정칙화 전략

    When the dataset is small compared to the model size, what kind of regularization approaches can we take?

    이 질문의 뿌리는 편향-분산 트레이드오프다. 모델의 표현 용량(capacity)이 데이터 양에 비해 크면, 모델은 데이터의 신호뿐 아니라 잡음까지 외워 버린다. 훈련 오차는 0에 가까워지지만 새 데이터에서는 크게 틀린다 — 전형적인 고분산(high variance) 과적합이다. 정칙화의 본질은 “우리가 미리 알고 있는 사전 지식(prior)을 모델에 주입해, 잡음을 외우는 자유를 빼앗는 것”이다. 데이터가 적을수록 이 사전의 비중을 키워야 한다.

    데이터가 적은 상황은 “점 세 개만 주고 곡선을 그려 보라”는 것과 같다. 점 세 개를 정확히 지나는 곡선은 무한히 많다. 아무 제약이 없으면 출제자는 가장 구불구불한 괴물 곡선을 그린다. 정칙화는 “되도록 매끄럽게 그려라”, “좌우 대칭일 것이다”, “비슷한 문제의 답을 참고하라” 같은 사전 믿음을 더해 답의 후보를 좁히는 일이다.

    작은 데이터셋에서 동원할 수 있는 접근들을 “무엇을 제약하는가”로 분류하면 다음과 같다.

    1. 가중치 자체를 제약 — 파라미터 노름 벌점

    비용 함수에 가중치 크기 벌점을 더한다. $\tilde{J}(\theta) = J(\theta) + \alpha\,\Omega(\theta)$. L2(가중치 감쇠, weight decay)는 $\Omega = \tfrac{1}{2}\lVert w\rVert_2^2$로 큰 가중치에 이차 비용을 매겨 해를 원점 쪽으로 당기고, L1은 $\Omega = \lVert w\rVert_1$로 일부 가중치를 정확히 0으로 만들어 희소성과 자동 특징 선택을 유도한다. 베이지안 관점에서 L2는 가중치에 가우시안 사전을, L1은 라플라스 사전을 건 MAP 추정과 같다.

    2. 자유 파라미터 수를 줄임 — 공유와 묶기

    같은 파라미터를 여러 위치에서 재사용하면 학습할 자유도가 줄어 데이터가 적어도 견딘다. CNN의 커널 공유, RNN의 시간축 공유가 대표적이다(Q2에서 상세). 다중 과제 학습(multi-task learning)도 공유 표현을 통해 각 과제에 효과적으로 더 많은 데이터를 주는 효과를 낸다.

    3. 데이터를 늘리거나 흔듦 — 증강과 노이즈

    적은 데이터를 라벨 보존 변환으로 부풀리는 데이터 증강, 입력·은닉·가중치·라벨에 잡음을 주입하는 기법이 여기 속한다(Q3에서 상세). 드롭아웃은 은닉 유닛에 곱셈 잡음을 주는 동시에 지수적으로 많은 부분망의 앙상블(bagging) 근사로 작동한다.

    4. 학습 과정을 일찍 멈춤 — 조기 종료

    검증 오차가 더 이상 줄지 않으면 학습을 멈춘다(early stopping). 사실상 가장 흔히 쓰는 정칙화이며, 이차 근사 아래에서 L2 정칙화와 동등함이 알려져 있다 — 학습 스텝 수가 유효 가중치 크기를 제한하기 때문이다. 추가 비용이 거의 없고 검증 데이터만 있으면 된다.

    5. 외부 지식을 끌어옴 — 사전훈련과 전이

    라벨이 풍부한 다른 과제나 대량의 비라벨 데이터에서 표현을 먼저 배운 뒤(전이학습, 비지도 사전훈련) 우리의 작은 데이터로 미세조정한다. 작은 데이터로는 결코 배울 수 없는 일반적 특징(에지, 단어 의미 등)을 외부에서 가져오는 것이라, 데이터가 적을수록 효과가 크다.

    L2 / L1가중치 크기에 벌점 — 매끄럽고 단순한 해 선호. 공유 · 묶기자유 파라미터 수를 구조적으로 축소. 증강 · 노이즈유효 데이터 양 증가, 불변성 주입, 앙상블 근사(드롭아웃). 조기 종료학습 스텝으로 유효 용량 제한 (≈ L2). 사전훈련 · 전이외부 데이터의 사전 지식을 초기값으로 주입.
    🎯 Model Answer (English)

    When the model has far more capacity than the small dataset can constrain, it overfits by memorising noise, so the cure is to inject prior knowledge that shrinks the hypothesis space. The main approaches are: (1) parameter-norm penalties — $L_2$ weight decay and $L_1$ sparsity; (2) parameter sharing or tying to reduce the number of free parameters; (3) data augmentation and noise injection (on inputs, weights, hidden units via dropout, and labels via label smoothing); (4) early stopping, which is equivalent to $L_2$ under a quadratic approximation; and (5) transfer learning or unsupervised pre-training, which import knowledge learned from external data. The smaller the dataset, the more weight these priors should carry, and transfer learning becomes especially valuable.

    📝 시험 답안 골격

    • 핵심 한 줄 — 데이터 부족 = 고분산 과적합. 정칙화 = 사전 지식 주입으로 가설 공간 축소.
    • 벌점(L2/L1) · 파라미터 공유 · 데이터 증강과 노이즈 · 드롭아웃 · 조기 종료 · 비지도 사전훈련/전이를 나열.
    • 데이터가 적을수록 사전의 비중을 키운다, 특히 전이학습의 효과가 커진다고 마무리.

    🔗 Q2 · 파라미터 묶기(tying)와 파라미터 공유(sharing)

    Explain the parameter tying and parameter sharing.

    둘 다 “어떤 파라미터들이 서로 관계가 있을 것”이라는 사전 지식을 거는 방법이지만, 그 강제의 세기가 다르다.

    파라미터 묶기 (tying)

    • 두 파라미터 집합이 가깝도록 부드럽게 벌점을 준다.
    • $\Omega(w_A, w_B) = \lVert w_A - w_B\rVert_2^2$ 를 비용에 더함.
    • 파라미터는 여전히 별개로 존재하되 서로 끌어당겨짐.
    • 예: 같은 입력에 대한 지도 모델 $A$와 비지도 모델 $B$, 도메인 적응에서 원본/대상 모델.

    파라미터 공유 (sharing)

    • 여러 위치의 파라미터를 정확히 같게 강제한다 — 같은 메모리를 가리킴.
    • 벌점이 아니라 하드 제약. 위반 자체가 불가능.
    • 메모리와 자유 파라미터 수가 실제로 줄어든다.
    • 예: CNN 커널(공간 전체), RNN 가중치(시간 전체).

    핵심 관계는 이것이다. 공유는 묶기의 극단적 특수 경우다 — 거리 벌점의 가중치를 무한대로 키워 두 파라미터의 차이를 0으로 강제한 것이 공유다. 그래서 묶기는 “비슷해야 한다”는 약한 사전, 공유는 “같아야 한다”는 무한히 강한 사전이다.

    묶기는 “두 학생이 비슷한 답을 쓰도록 같은 조로 묶는 것”이다. 답이 비슷해질 뿐 각자 다른 답안지를 낸다. 공유는 “두 학생이 답안지 한 장을 함께 쓰는 것”이다. 물리적으로 같은 답이 강제되고, 채점할 답안지도 한 장으로 줄어든다.

    실용적으로 공유가 더 자주 쓰인다. 메모리 절감이라는 부수 효과가 크고, CNN처럼 “같은 패턴은 어디에 있든 같다”는 강한 가정이 자연 데이터에 잘 맞기 때문이다. 공유는 또 변환 등가성(Q9)이라는 공짜 보너스를 준다. 반면 두 모델이 “완전히 같지는 않지만 관련 있다”를 표현해야 할 때(예: 약간 다른 두 과제)는 묶기가 적합하다.

    🎯 Model Answer (English)

    Both encode the prior that certain parameters are related; they differ in how hard that constraint is. Parameter tying adds a soft penalty such as $\lVert w_A - w_B\rVert^2$ that pulls two separate parameter sets close together, used when two related models or tasks should resemble each other. Parameter sharing forces parameters to be exactly identical — they are literally the same memory — as in CNN kernels reused across spatial positions or RNN weights reused across time steps. Sharing is the limiting case of tying with an infinite penalty, so it acts as an infinitely strong prior; it additionally saves memory and grants translation equivariance for free.

    📝 시험 답안 골격

    • 묶기 = 부드러운 벌점 $\lVert w_A-w_B\rVert^2$로 가깝게. 공유 = 정확히 같은 파라미터(하드 제약, 같은 메모리).
    • 공유는 묶기의 극단(거리 벌점 무한대) = 무한히 강한 사전.
    • 공유 예 CNN·RNN, 묶기 예 지도/비지도 결합·도메인 적응. 공유는 메모리 절감 + 등가성 보너스.

    🧪 Q3 · 데이터 측면의 정칙화 트릭

    As regularization, what kind of tricks can we take regarding data? (pretraining with unlabeled data, data augmentation, noise injection, etc.)

    “데이터로 거는 정칙화”의 공통 원리는 “모델이 학습 분포를 더 넓고 더 현실적으로 보게 만들어, 좁은 훈련 표본을 통째로 외우지 못하게 한다”이다. 세 갈래로 정리한다.

    1. 데이터 증강 (data augmentation)

    라벨을 보존하는 변환으로 한 표본에서 여러 표본을 만든다. 이미지라면 평행이동, 회전, 크기 변경, 자르기, 좌우 반전, 색·밝기 흔들기. 이는 “이런 변환을 가해도 라벨은 그대로다”라는 불변성 사전을 데이터로 가르치는 것이다. 가장 효과가 큰 곳은 물체 인식 같은 분류 과제다. 단, 변환이 의미를 바꾸면 안 된다 — 손글씨 숫자에 좌우 반전을 쓰면 6과 9, b와 d가 뒤바뀌어 오히려 해롭다.

    2. 노이즈 주입 (noise injection)

    잡음을 어디에 넣느냐로 나뉜다.

    입력에입력에 작은 잡음 추가. 일부 모델에서는 가중치에 거는 $L^2$ 벌점(Tikhonov)과 수학적으로 동등. 데이터 증강의 한 형태로도 볼 수 있다. 은닉 유닛에드롭아웃 — 유닛을 무작위로 끈다. 곱셈 잡음이자, 지수적으로 많은 부분망의 앙상블 근사. 가중치에가중치에 잡음을 주면 손실이 평평한 최소점(작은 변동에 둔감한 해)을 선호하게 된다 — 더 강건한 해. 라벨에라벨 평활(label smoothing). 정답 확률을 1 대신 $1-\epsilon$로 둬, 라벨에도 잡음이 있음을 인정하고 소프트맥스의 과신을 막는다.

    3. 비라벨 데이터로 사전훈련 (semi-supervised / unsupervised pretraining)

    라벨은 비싸지만 비라벨 데이터는 흔하다. 오토인코더나 언어모델처럼 라벨 없이 입력의 구조를 먼저 배운 표현을 초기값으로 삼고, 작은 라벨 데이터로 미세조정한다. 이는 입력 분포 $p(x)$에 대한 지식을 $p(y\mid x)$ 학습의 사전으로 옮기는 것이다(왜 이것이 통하는지는 Q20에서 깊이 다룬다).

    세 트릭은 모두 “시험 범위를 넓게 공부시키는 방법”이다. 증강은 같은 문제를 여러 각도로 변형해 풀게 하고, 노이즈는 일부러 흐린 문제로도 풀게 하며, 사전훈련은 시험 과목 이전에 기초 교양을 먼저 쌓게 한다. 셋 다 “좁은 기출만 외우는” 과적합을 막는다.
    🎯 Model Answer (English)

    These tricks regularise by making the model see a broader, more realistic input distribution so it cannot simply memorise the small training set. (1) Data augmentation generates new labelled examples through label-preserving transforms — translation, rotation, scaling, cropping, flips, colour jitter — which teaches the model known invariances, but the transform must never change the meaning (a horizontal flip ruins digit recognition by swapping 6 and 9). (2) Noise injection adds noise to inputs (mathematically close to an $L_2$ penalty), to hidden units (dropout), to weights (favouring flat, robust minima), or to labels (label smoothing, which prevents an over-confident softmax). (3) Unsupervised or semi-supervised pre-training learns structure from abundant unlabelled data and transfers it as a prior or initialisation for the supervised task.

    📝 시험 답안 골격

    • 공통 원리 — 모델이 학습 분포를 더 넓게 보게 해 표본 암기를 막음.
    • 증강(라벨 보존 변환, 불변성 주입) · 노이즈(입력·은닉=드롭아웃·가중치·라벨=평활) · 비라벨 사전훈련/전이.
    • 증강은 의미를 바꾸지 않는 변환만, 입력 노이즈 ≈ L2, 사전훈련은 p(x) 지식을 p(y|x)로 전이.

    👾 Q22 · 적대적 예제(adversarial examples)의 핵심

    What is the main point of the adversarial examples?

    적대적 예제란, 사람 눈에는 원본과 구별되지 않을 만큼 작지만 의도적으로 설계된 섭동 $\eta$를 더했을 때 높은 정확도의 네트워크가 엉뚱한 클래스로 높은 확신을 가지고 오분류하게 만드는 입력이다. 대표적 생성법이 FGSM이다.

    $$ \tilde{x} = x + \epsilon\,\operatorname{sign}\!\big(\nabla_x J(\theta, x, y)\big) $$

    손실을 가장 빨리 키우는 방향(기울기 부호)으로 각 픽셀을 $\epsilon$만큼만 민다. $\lVert\eta\rVert_\infty=\epsilon$로 작게 유지된다.

    핵심은 이 현상의 원인이 “모델이 너무 복잡하고 비선형이라 생긴 기현상”이 아니라, 오히려 정반대로 “모델이 고차원에서 지나치게 선형적이기 때문”이라는 Goodfellow의 선형성 가설(linear explanation)이다. 선형 함수 $w^\top x$를 생각하자. 섭동 $\eta=\epsilon\,\operatorname{sign}(w)$를 더하면 출력 변화는

    $$ w^\top(x+\eta) - w^\top x = \epsilon\, w^\top \operatorname{sign}(w) = \epsilon \lVert w\rVert_1 = \epsilon \sum_{i=1}^{n} |w_i| $$

    픽셀 하나당 변화는 $\epsilon$로 미미하지만, 차원 $n$에 걸쳐 모두 같은 방향으로 더해져 출력 변화는 $n$에 비례해 커진다.

    즉 각 차원의 변화는 사람이 못 느낄 만큼 작아도, 차원이 수만 개면 그 작은 변화들이 전부 같은 방향으로 합쳐져 활성값을 크게 흔든다. ReLU·LSTM 등 현대 구성요소가 의도적으로 거의 선형(piecewise linear)이라 최적화가 쉬운데, 바로 그 선형성이 적대적 취약성의 대가다.

    위젯 22선형 누적 — 작은 섭동이 차원 수만큼 쌓인다

    픽셀당 섭동 크기 $\epsilon$은 그대로 두고 입력 차원 $n$만 키워 보라. 픽셀 하나의 변화(왼쪽 막대)는 늘 작지만, 출력 활성값의 총 변화 $\epsilon\lVert w\rVert_1$(오른쪽)는 차원에 비례해 폭증한다. 고차원이 적대적 예제를 가능케 하는 메커니즘이다.

    함의는 두 가지다. 첫째, 보안 — 분류기를 속이는 입력을 값싸게 만들 수 있다. 둘째, 흥미롭게도 정칙화 — 적대적 예제를 훈련 데이터에 섞는 적대적 훈련은 결정 경계를 데이터에서 멀어지게 밀어 강건성과 일반화를 동시에 높인다. 적대적 예제는 “모델이 의미를 이해한 게 아니라 표면적 선형 통계를 학습했다”는 사실을 드러내는 진단 도구이기도 하다. FGSM과 선형 가설의 단계별 해설은 P1 FGSM 사이트에 따로 있다.

    🎯 Model Answer (English)

    An adversarial example is an input carrying a tiny, deliberately crafted perturbation — imperceptible to a human — that makes a high-accuracy network misclassify with high confidence (e.g. FGSM: $\tilde{x} = x + \epsilon\,\operatorname{sign}(\nabla_x J)$). The main point is its cause: not excessive non-linearity, but excessive linearity in high dimensions. For a linear response $w^\top x$, the perturbation $\eta = \epsilon\,\operatorname{sign}(w)$ shifts the output by $\epsilon\lVert w\rVert_1$, which grows with the input dimension $n$ — each component changes by a negligible $\epsilon$, yet thousands of aligned changes sum to a large shift. This is both a security threat and, usefully, a regulariser: adversarial training pushes decision boundaries away from the data and improves generalisation.

    📝 시험 답안 골격

    • 정의 — 미세하고 의도적인 섭동으로 고정확도 모델을 고확신 오분류시키는 입력(FGSM: $x+\epsilon\,\mathrm{sign}(\nabla_x J)$).
    • 핵심 원인은 비선형이 아니라 고차원에서의 선형성: 출력 변화 $=\epsilon\lVert w\rVert_1$가 차원 $n$에 비례.
    • 함의 — 보안 위협이자, 적대적 훈련이라는 정칙화 기회. 모델이 의미가 아닌 선형 통계를 학습했음을 폭로.

    🎯 Q23 · RBF 네트워크와 적대적 예제 면역

    Describe radial basis function networks. And discuss why it does not have the adversarial example issue.

    방사 기저 함수(Radial Basis Function, RBF) 네트워크는 은닉 유닛이 입력과 원형(radial) 거리에 반응하는 네트워크다. 각 유닛은 프로토타입(중심) $\mu_i$를 가지며, 입력이 그 중심에 가까울 때만 강하게 켜진다.

    $$ h_i(x) = \exp\!\Big(-\beta_i \,\lVert x - \mu_i\rVert_2^2\Big), \qquad \hat{y} = \sum_i w_i\, h_i(x) $$

    $\mu_i$ 근처에서 1에 가깝게 켜지고, 멀어지면 가우시안으로 빠르게 0으로 꺼진다.

    이것이 ReLU 같은 보통 유닛과 결정적으로 다른 점은, 활성 함수가 선형이 아니라 거리에 따라 빠르게 포화(0으로 꺼짐)한다는 것이다. 보통 유닛 $w^\top x$는 입력이 어느 방향으로 가든 같은 방향으로 끝없이 반응하므로(Q22의 선형 누적), 작은 섭동이 차원에 걸쳐 쌓여 활성값을 크게 흔들 수 있다. 반면 RBF 유닛은 “중심에서 멀어졌다”는 사실에 의해 곧장 꺼져 버린다. 섭동을 차원에 걸쳐 쌓아도 그 결과가 중심에서 더 멀어지게 만들 뿐이라 응답은 오히려 줄어든다. 누적이 작동할 선형 경로가 없는 것이다.

    보통 유닛은 “어느 방향에서 와도 반응하는 무지향성 마이크”라, 사방에서 들어온 작은 잡음이 합쳐져 큰 소리가 된다. RBF 유닛은 “특정 지점만 듣는 지향성 마이크”라, 그 지점을 벗어난 잡음은 아무리 더해도 들리지 않는다.

    그 결과 RBF 네트워크는 훈련 데이터 근처에서만 높은 확신을 갖고, 데이터에서 먼 입력에는 모든 클래스에 낮은 확신을 보인다 — 사실상 “나는 모른다”라고 답한다. 적대적 예제는 데이터에서 멀리 밀어내는 입력이므로, RBF는 자연스럽게 낮은 확신으로 거부한다. 적대적 예제에 잘 속지 않는 이유다.

    대가도 분명하다. RBF 유닛은 좁은 영역에서만 켜지므로 입력 공간을 덮으려면 많은 유닛이 필요하고, 학습이 어렵고, 보지 못한 영역으로의 일반화가 약하다. Goodfellow는 RBF 네트워크가 적대적 예제에 강건하지만 그 대가로 정확도가 낮다고 지적한다. 강건성과 정확도 사이의 트레이드오프를 보여 주는 교과서적 예다.

    🎯 Model Answer (English)

    A radial basis function (RBF) network has hidden units that respond to the distance from a prototype centre $\mu_i$: $h_i(x) = \exp(-\beta_i\lVert x - \mu_i\rVert^2)$. Each unit fires only near its centre and saturates to zero far away. It resists adversarial examples precisely because it is not linear: there is no linear path along which tiny per-dimension perturbations can accumulate into a large response — moving the input in any direction merely takes it further from the centre and lowers the activation. As a result the network is confident only near the training data and effectively reports "I don't know" elsewhere, so adversarial inputs are rejected with low confidence. The cost is lower accuracy and harder training — a clear robustness–accuracy trade-off.

    📝 시험 답안 골격

    • RBF 유닛 — 중심 $\mu_i$로부터의 거리에 가우시안으로 반응, 멀면 0으로 포화.
    • 적대적 면역 이유 — 선형 누적 경로가 없음. 섭동은 입력을 중심에서 멀어지게 해 응답을 오히려 줄임. 데이터 근처에서만 고확신.
    • 트레이드오프 — 강건하지만 학습 어렵고 정확도/일반화가 낮음.
