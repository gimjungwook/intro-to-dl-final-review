🌳 Q12 · RNN은 재귀 신경망(recursive NN)의 특수 경우

Why is RNN a special case of recursive neural network?

📌 질문 해석

“RNN이 왜 recursive NN의 특수 경우인가?” 두 모델의 공통점 + 구조의 차이(chain vs tree)를 짚으면 된다.

🌳 이 질문은 RNN과 recursive neural network(재귀 신경망)의 관계를 정확히 이해하는 것을 요구한다. 결론부터 말하면 둘은 같은 가족인데, RNN은 그중 가장 단순한 형태에 해당한다.

🧬 두 모델의 공통점

Recursive NN과 RNN은 한 가지 핵심 원리를 공유한다 — 같은 파라미터를 구조의 모든 노드에 반복 적용해서 자식 표현을 부모 표현으로 합친다는 것이다.

"같은 파라미터를 반복 적용"한다는 점이 핵심이다. 구조가 어떻게 생겼든, 그 구조 안의 모든 노드는 동일한 합성 함수(같은 가중치)를 사용한다. 이게 파라미터 공유의 한 형태이며, 두 모델 모두 이 공유를 통해 가변 크기의 구조를 처리할 수 있다.

🌲 Recursive Neural Network (재귀 신경망)

일반적인 트리(혹은 DAG, 방향 비순환 그래프) 구조 위에서 작동한다. 대표 예가 문장의 parse tree(구문 분석 트리)다. 한 문장을 단어들의 단순 나열로 보지 않고, "단어 → 구 → 절 → 문장"의 계층적 트리로 본 다음, 같은 합성 함수를 트리 전체에 재귀적으로 적용한다.

예를 들어 "the cat sat on the mat"이라는 문장이 있다면, 먼저 "the cat"이라는 명사구를 두 단어를 합성해서 만든다. 동시에 "on the mat"이라는 전치사구도 비슷한 방식으로 만든다. 그 다음 "the cat" + "sat on the mat"을 다시 합성해 전체 문장 표현을 만든다. 각 합성 단계에서 같은 가중치의 합성 함수가 쓰인다.

🎍 RNN (Recurrent Neural Network)

RNN은 그 구조가 사슬(chain), 즉 가지가 없는 한 줄짜리 "퇴화된 트리"인 특수 경우다. 매 시점의 노드는 자식이 단 하나뿐이다 — 바로 직전 timestep의 hidden state다. 거기에 현재 입력을 더해 다음 상태를 만든다.

즉 시퀀스 길이가 100이면 한 줄로 100개 노드가 일렬로 늘어선 매우 좁고 긴 "트리"가 된다. 같은 가중치를 시점마다 반복 적용한다는 원리는 일반 recursive NN과 동일하지만, 구조가 분기 없는 사슬 형태로 좁혀져 있을 뿐이다.

🎋 Recursive NN을 자유롭게 가지를 뻗어 나가는 나무에 비유하면, RNN은 가지 없이 곧게 자란 대나무와 같다. 둘 다 같은 마디(파라미터)를 반복해서 자라지만, 대나무는 트리의 모든 분기 가능성을 한 줄로 좁혀버린 특수한 형태의 나무다. 대나무는 단순하지만 한계가 명확하다.

📏 깊이 차이가 주는 실용적 함의

이 관점이 단순한 분류 문제를 넘어 실제 학습에 영향을 미치는 이유는 모델의 깊이(depth)가 달라지기 때문이다.

RNN은 시퀀스 길이가 n이면 깊이도 n에 비례해 선형으로 깊어진다. 시퀀스 길이가 100이면 사실상 100층 깊이의 신경망이다. 반면 잘 균형 잡힌 binary tree 형태의 recursive NN이라면 같은 100개 입력에 대해 깊이가 log(100) ≈ 7 정도에 그친다.

깊이가 얕을수록 gradient가 입력에서 출력까지 통과해야 할 곱셈 단계가 적다. 그래서 같은 길이의 의존성도 tree 구조에서는 더 잘 학습된다. 특히 멀리 떨어진 두 단어 사이의 관계(long-range dependency)를 잡는 데 tree가 사슬보다 유리할 수 있다.

이게 RNN이 긴 시퀀스에서 vanishing/exploding gradient 문제에 시달리는 한 이유다. 사슬이 너무 길어서 양 끝을 연결하는 정보가 그 100층을 통과하며 약해지거나 폭발한다. Recursive tree는 같은 정보를 훨씬 적은 단계로 연결할 수 있다.

📌 정리

"왜 RNN이 recursive NN의 특수 경우인가?"에 대한 답은 다음과 같다. 두 모델은 "같은 파라미터를 구조 전체에 반복 적용한다"는 핵심 원리를 공유한다. 그 구조가 일반적인 트리이면 recursive NN이고, 사슬 형태로 좁혀지면 RNN이다. 따라서 RNN은 recursive NN의 특수 한 경우이며, 그 사슬 구조는 단순함의 대가로 학습의 어려움(긴 시퀀스에서의 gradient 문제)을 함께 떠안는다.

🎯 Model Answer (English)

Both apply the same parameters repeatedly across the nodes of a structure, combining children into a parent representation. A recursive neural network operates on a general tree (or DAG) structure — for example a sentence's parse tree, where one composition function merges two child phrases into a parent. An RNN is the special case in which that structure is a chain — a degenerate, linear tree: each step's node has a single child (the previous state) plus the current input. So an RNN is a recursive network whose topology has been narrowed to a path. A practical consequence is that an RNN's depth grows linearly with the sequence length $n$, whereas a balanced recursive tree grows only as $\log n$, so trees can be gentler on gradients over long dependencies.

📝 시험 답안 골격

  • 공통 — 같은 파라미터를 구조의 모든 노드에 반복 적용해 자식→부모로 합침.
  • 재귀망 = 일반 트리/DAG 구조. RNN = 그 구조가 사슬(퇴화 트리)인 특수 경우.
  • 결과 — RNN 깊이는 시퀀스 길이 n에 비례, 균형 트리는 log n에 그침. 트리가 긴 의존성·기울기 보존에 유리할 수 있음.
