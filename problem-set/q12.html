🌳 Q12 · RNN은 재귀 신경망(recursive NN)의 특수 경우

Why is RNN a special case of recursive neural network?

두 모델의 공통점부터 보자. 둘 다 같은 파라미터를 구조의 모든 노드에서 반복 적용해, 자식 표현들을 부모 표현으로 합친다. 차이는 그 “구조”의 모양이다.

재귀 신경망은 일반적인 트리(또는 DAG) 구조 위에서 작동한다. 예컨대 문장의 구문 분석 트리에서, 같은 합성 함수가 두 자식 구를 한 부모 구로 합치는 일을 트리 전체에 재귀적으로 적용한다. 순환 신경망(RNN)은 이 구조가 사슬(chain), 즉 한 줄로 늘어선 퇴화한 트리인 특수 경우다. 매 시점의 노드는 자식이 하나(직전 상태)뿐이고, 거기에 현재 입력을 더해 다음 상태를 만든다.

재귀 신경망이 “가지를 자유롭게 뻗는 나무”라면, RNN은 “가지 없이 곧게 자란 대나무”다. 둘 다 같은 마디(파라미터)를 반복해 자라지만, 대나무는 트리의 모든 분기 가능성을 한 줄로 좁힌 특수한 나무다.

이 관점이 알려 주는 실용적 사실이 있다. RNN은 사슬이라 깊이가 시퀀스 길이 $n$에 비례해 선형으로 깊어진다. 반면 균형 잡힌 이진 트리 재귀망은 깊이가 $\log n$에 그친다. 깊이가 얕을수록 기울기가 통과해야 할 곱셈 단계가 적어, 일반 재귀망은 긴 의존성에서 기울기 소실(Q13)에 더 강할 수 있다. 즉 RNN을 “재귀망의 사슬 특수 경우”로 보면, 그 장단점이 구조의 깊이에서 따라 나옴을 한눈에 이해할 수 있다.

🎯 Model Answer (English)

Both apply the same parameters repeatedly across the nodes of a structure, combining children into a parent representation. A recursive neural network operates on a general tree (or DAG) structure — for example a sentence's parse tree, where one composition function merges two child phrases into a parent. An RNN is the special case in which that structure is a chain — a degenerate, linear tree: each step's node has a single child (the previous state) plus the current input. So an RNN is a recursive network whose topology has been narrowed to a path. A practical consequence is that an RNN's depth grows linearly with the sequence length $n$, whereas a balanced recursive tree grows only as $\log n$, so trees can be gentler on gradients over long dependencies.

📝 시험 답안 골격

  • 공통 — 같은 파라미터를 구조의 모든 노드에 반복 적용해 자식→부모로 합침.
  • 재귀망 = 일반 트리/DAG 구조. RNN = 그 구조가 사슬(퇴화 트리)인 특수 경우.
  • 결과 — RNN 깊이 $\propto n$, 균형 트리 $\propto\log n$ → 트리가 긴 의존성·기울기에 유리할 수 있음.
