🧠 Q13 · LSTM의 ‘기억 소실(memory-fade-away)’ 극복

How does LSTM overcome the ‘memory-fade-away’ issue?

📌 질문 해석

“LSTM이 memory-fade-away를 어떻게 극복하나?” 먼저 왜 사라지는지(vanishing gradient), 그다음 해법(cell state + gate) 순서로.

😶‍🌫️ LSTM을 제대로 이해하려면 먼저 "memory fade-away" 즉 기억 소실이 왜 일어나는지부터 봐야 한다. 그러면 LSTM이 어떤 문제를 풀려고 만들어진 모델인지 명확해진다.

🌫️ 왜 바닐라 RNN의 기억이 사라지는가

바닐라 RNN의 hidden state는 매 timestep에서 같은 순환 가중치 행렬과 곱해지면서 다음 시점으로 전달된다. 즉 시점 t에서의 hidden state는 시점 t-1의 hidden state에 가중치 행렬을 곱한 것이고, 시점 t-1은 또 시점 t-2의 hidden state에 가중치 행렬을 곱한 것이다.

이 과정을 거슬러 올라가 보면, k 시점 전의 입력이 현재 시점에 미치는 영향은 같은 가중치 행렬을 k번 곱한 것에 비례한다. 100 timestep 전이라면 같은 행렬이 100번 곱해진다.

여기서 문제가 발생한다. 가중치 행렬의 "확대 비율"(eigenvalue 중 가장 큰 값)이 1보다 작으면, 그 행렬을 100번 곱한 결과는 0에 매우 가까워진다 — vanishing gradient(기울기 소실). 결과적으로 100 timestep 전 정보는 현재에 거의 영향을 미치지 못한다. 반대로 1보다 크면 폭발한다.

설상가상으로 RNN의 활성함수로 흔히 쓰는 tanh의 도함수도 항상 1보다 작아, 기울기가 더 빠르게 사라진다. 결과적으로 RNN은 수십 timestep 이상 떨어진 의존성(long-range dependency)을 사실상 학습할 수 없다. 이게 "memory fade-away"의 본질이다 — 옛 정보가 시간을 거슬러 도달하기 전에 자연스럽게 사라져버린다.

🧠 LSTM의 해법: Cell State와 Gate

LSTM은 이 문제를 두 가지 핵심 장치로 해결한다 — cell state(셀 상태)라는 별도의 정보 통로와, 그 통로를 제어하는 gate(게이트)들이다.

일반 RNN과 가장 큰 차이는 cell state의 갱신 방식이다. 일반 RNN은 매 시점 hidden state에 가중치 행렬을 "곱한다" → 그게 기울기 소실의 근본 원인이다. LSTM의 cell state는 곱셈이 아니라 덧셈으로 갱신된다.

구체적으로, 현재 시점의 cell state는 (이전 cell state) + (새로 들어올 정보)의 형태로 만들어진다. forget gate가 이전 cell state 중 얼마나 유지할지를 결정하고, input gate가 새로 들어올 정보를 얼마나 받아들일지를 결정한다.

🚪 세 가지 Gate의 역할

LSTM은 세 개의 gate를 가지며, 각 gate는 0~1 사이의 값을 데이터로부터 학습한다 (즉 상황에 따라 다르게 작동한다).

  • Forget gate — "이전 cell state 중 무엇을 잊을지" 결정. 1에 가까우면 정보 그대로 유지, 0에 가까우면 잊는다.
  • Input gate — "새로 들어온 정보 중 무엇을 받아들일지" 결정. 중요한 입력은 강하게 받고, 불필요한 입력은 무시한다.
  • Output gate — "현재 cell state 중 무엇을 다음 layer로 내보낼지" 결정.

이 세 gate가 "언제 기억하고 언제 잊을지를 네트워크가 스스로 학습해 조절"하게 한다. 사람의 손으로 "100 timestep 전 정보를 보존해라"라고 가르치지 않고, 데이터를 보고 자동으로 결정한다.

🎠 Constant Error Carousel (CEC)

LSTM의 핵심 메커니즘에 붙은 이름이다. 의미는 다음과 같다. Forget gate가 1에 가깝고 입력이 작으면, cell state는 거의 변하지 않은 채 다음 시점으로 흘러간다 — 곱셈이 아닌 단순 덧셈이라 정보가 그대로 보존된다.

이 cell state를 따라 흐르는 기울기는 가중치 행렬의 반복 곱 없이 약 1에 가까운 비율로 유지된다. 100 timestep을 지나도 기울기가 지수적으로 줄지 않는다. 마치 "오차(error)가 회전목마(carousel)처럼 일정하게 도는" 것 같다고 해서 Constant Error Carousel이라 부른다.

이게 LSTM이 vanishing gradient 문제를 해결하는 핵심 원리다. 곱셈을 덧셈으로 바꾼 단순한 발상이 수십 timestep 떨어진 의존성도 학습 가능하게 만들었다.

📚 바닐라 RNN의 hidden state를 "수업 시간에 매번 다시 쓰는 칠판"에 비유할 수 있다 — 매 timestep마다 같은 변환이 일어나니, 처음에 쓴 내용은 점점 흐려지다 결국 사라진다. LSTM의 cell state는 "별도의 노트북"이다. 매 timestep마다 forget gate가 "이 페이지 지울까?"를 결정하고, input gate가 "이 내용 새로 적을까?"를 결정한다. 노트북에 한 번 적힌 중요한 내용은 forget gate가 그대로 두는 한 영원히 보존된다.

🌟 결과

이 메커니즘 덕분에 LSTM은 100 timestep 이상 떨어진 정보도 안정적으로 학습할 수 있다. 긴 문장의 앞부분과 뒷부분 사이 의존성, 수백 frame의 비디오에서 초반과 후반의 관계, 긴 음성 시퀀스의 장기 맥락 등을 잡아낸다. 바닐라 RNN으로는 사실상 불가능하던 task들이 LSTM으로 풀린 이유다.

현대에는 LSTM의 단순화 버전인 GRU(Gated Recurrent Unit)나, 시퀀스 처리에서 RNN 계열을 대체한 Transformer 같은 모델들이 있지만, "곱셈을 덧셈으로 바꾸고 gate로 조절"한다는 LSTM의 핵심 아이디어는 이후 모든 시퀀스 모델 설계에 깊은 영향을 끼쳤다.

위젯 1320 스텝 뒤에도 남는 신호 — 바닐라 RNN vs LSTM
바닐라 RNN(고정 감쇠)LSTM(f 조절)

바닐라 RNN(파랑)은 가중치·활성에 묶인 고정 감쇠율로 신호가 지수적으로 사라진다. LSTM(빨강)은 망각 게이트 f를 1에 가깝게 학습하면 신호를 수십 스텝 보존한다 (f를 t번 곱해도 1에 가까움). f를 낮추면 LSTM도 의도적으로 잊을 수 있음을 본다.

🎯 Model Answer (English)

In a vanilla RNN the hidden state is multiplied by the same recurrent weight matrix at every step, so the influence of an input k steps back scales like the matrix multiplied k times; if the largest eigenvalue is below 1 the gradient vanishes exponentially (and the tanh derivative, being below 1, worsens it), so long-range dependencies are lost. The LSTM fixes this with a cell state that is updated additively and gated: the new cell state is the previous cell state weighted by a forget gate plus a new candidate weighted by an input gate. This additive self-loop is the Constant Error Carousel — when the forget gate is close to 1 the cell state is preserved and the gradient flows along it at roughly 1, with no repeated matrix multiplication, so it does not vanish. The forget, input, and output gates let the network learn when to keep, write, and expose information.

📝 시험 답안 골격

  • 원인 — 바닐라 RNN은 순환 가중치 행렬이 반복 곱해짐. 가장 큰 확대 비율(eigenvalue)이 1보다 작으면 기울기가 지수적으로 소실. tanh 도함수가 항상 1보다 작아 더 악화.
  • 해법 — cell state를 곱셈이 아닌 덧셈으로 갱신 + forget/input/output gate로 정보 흐름 제어. CEC(Constant Error Carousel)로 기울기가 약 1로 유지되어 소실되지 않음.
  • 게이트(망각·입력·출력)로 언제 기억/망각할지 학습. 행렬 반복 곱이 없어 소실 제거.
