🤖 Q26 · BERT vs GPT

Compare BERT and GPT in terms of the Transformer architecture. And when can we use BERT or GPT?

📌 질문 해석

“BERT와 GPT를 Transformer 구조 관점에서 비교하고, 언제 무엇을 쓰는지.” encoder/decoder·양방향/단방향 대비가 핵심.

🤖 BERT와 GPT는 둘 다 Transformer(Q25)에서 출발한 모델이지만 서로 매우 다른 방식으로 활용한다. 같은 부품을 어떻게 조립하느냐가 두 모델의 성격을 결정한다.

📐 공통 출발점: Transformer

먼저 Transformer 자체를 떠올려보자. 원래 Transformer는 encoder와 decoder 두 부분으로 이루어진 모델이었다 — 입력 시퀀스(예: 영어 문장)를 encoder가 받아 표현으로 만들고, decoder가 그 표현을 보면서 출력 시퀀스(예: 한국어 번역)를 한 단어씩 생성한다.

BERT와 GPT는 이 Transformer를 다르게 활용한다. BERT는 encoder 부분만 사용하고, GPT는 decoder 부분만 사용한다. 그리고 각각 다른 방식으로 학습한다.

📖 BERT — Encoder, 양방향 (Bidirectional Encoder Representations from Transformers)

구조: Transformer encoder를 여러 층 쌓은 것이다. Encoder의 self-attention은 한 가지 특성을 갖는데 — 각 위치가 시퀀스의 모든 위치를 볼 수 있다는 점이다. 즉 한 단어가 자기 왼쪽 단어들뿐 아니라 오른쪽 단어들까지 동시에 참조한다. 이걸 "양방향(bidirectional)" attention이라고 한다.

학습 방식 1: Masked Language Modeling (MLM)

BERT의 핵심 학습 방식이다. 입력 문장에서 일부 단어(보통 15%)를 무작위로 [MASK] 토큰으로 가리고, 모델이 그 가려진 단어가 무엇이었는지 맞히도록 학습시킨다.

예를 들어 "강아지가 [MASK] 위에서 잠을 자고 있다"가 입력되면, 모델은 [MASK] 자리가 "소파"였는지 "침대"였는지 "방석"이었는지 맞춰야 한다. 이를 위해 모델은 가려진 위치의 양쪽 문맥(왼쪽의 "강아지가"와 오른쪽의 "위에서 잠을 자고 있다")을 모두 활용한다.

학습 방식 2: Next Sentence Prediction (NSP)

두 문장이 주어졌을 때 두 번째 문장이 첫 번째 문장의 자연스러운 연속인지를 맞히는 task다. 문서 수준의 맥락을 학습하도록 한다.

BERT의 특징: 양방향 attention과 MLM 학습 덕분에 BERT는 텍스트의 이해(understanding)에 매우 강하다. 한 단어의 의미를 그 단어 양쪽 문맥을 모두 고려해 파악할 수 있다.

다만 텍스트 생성(generation)에는 부적합하다. 왜냐하면 생성은 본질적으로 "이전 단어들로부터 다음 단어를 만드는" 작업인데, BERT는 양방향으로 학습되어 "다음에 올 단어를 예측"하도록 훈련되지 않았기 때문이다.

✍️ GPT — Decoder, 단방향 (Generative Pre-trained Transformer)

구조: Transformer decoder를 여러 층 쌓은 것이다. Decoder의 self-attention은 BERT와 정반대 특성을 갖는다 — 각 위치가 자기 자신과 그 앞쪽 위치들만 볼 수 있다. 뒤쪽 위치는 볼 수 없도록 attention 자체에 차단막(causal mask)이 적용된다. 이걸 "단방향(unidirectional)" 또는 "causal" attention이라고 한다.

왜 이런 제약을 거는가? 생성 task의 본질 때문이다. 모델이 "다음 단어"를 예측할 때 이미 그 다음 단어를 보고 있다면 학습이 의미가 없다 (답을 보고 답을 맞히는 것과 같다). 그래서 학습 중에도 모델이 미래 단어를 보지 못하도록 강제하는 것이다.

학습 방식: Autoregressive Language Modeling

입력 시퀀스의 매 위치에서 "이 위치까지 본 단어들로 다음 단어를 예측"하도록 학습한다. "강아지가 소파 위에서" 다음에 무엇이 올 확률이 가장 높은지 — 예를 들어 "잠을 자고 있다"의 "잠" — 를 맞추는 식이다.

학습이 끝나면 모델은 어떤 시작 텍스트가 주어졌을 때 그 뒤를 자연스럽게 이어 쓸 수 있다. 한 단어를 생성하고, 그 단어를 입력에 추가한 뒤 다음 단어를 생성하고, 이걸 반복한다. 이게 ChatGPT 같은 대화 모델의 기본 작동 방식이다.

GPT의 특징: 단방향 attention과 autoregressive 학습 덕분에 GPT는 텍스트 생성(generation)에 매우 강하다. 글쓰기, 대화, 코드 생성, 창작 등 새로운 텍스트를 만들어내는 작업에 자연스럽다.

📝 BERT를 빈칸 채우기 시험을 푸는 독해가에 비유할 수 있다. 빈칸 정답을 맞히려면 빈칸 앞뒤를 모두 읽어야 하니, BERT는 자연스럽게 양방향 문맥을 다 활용한다. 반면 GPT는 "다음 문장을 계속 써 내려가는 이야기꾼"이다. 지금까지 쓴 것만 보고 다음 단어를 결정하니 단방향이 자연스럽다. 시험과 글쓰기는 서로 다른 방식의 사고를 요구하듯, 이해와 생성도 다른 모델 구조에서 잘 작동한다.

🧭 언제 무엇을 쓰는가

BERT를 쓰는 경우 — 이해 task

  • 문장 분류: 감정 분석, 스팸 분류, 주제 분류 등 — 텍스트 전체를 받아 하나의 라벨을 예측
  • Named Entity Recognition (NER, 개체명 인식): 문장에서 사람 이름, 지명, 조직명 등을 찾기 — 각 단어의 분류라 양방향 문맥이 중요
  • 추출형 질문 응답: 본문에서 답이 되는 구간을 찾기 — 본문 전체 이해 필요
  • 문장 임베딩과 검색: 문장을 벡터로 만들어 유사한 문서 검색 — 의미 이해가 핵심

GPT를 쓰는 경우 — 생성 task

  • 텍스트 이어쓰기: 시작 부분을 주면 자연스럽게 계속 작성
  • 대화 시스템: ChatGPT 같은 대화형 AI
  • 창작: 소설, 시, 마케팅 카피 생성
  • 코드 생성: GitHub Copilot 같은 코드 작성 도구
  • Few-shot learning: 몇 개 예시만 주고 새 task를 즉시 수행 — GPT의 in-context learning 능력 활용
  • 개방형 응답: 자유 형식의 질문에 답하기

📌 정리

BERT와 GPT의 차이는 "같은 Transformer 부품을 어떻게 활용하느냐"로 정리된다. BERT는 encoder + 양방향 attention + MLM 학습으로 이해 task에 강하고, GPT는 decoder + 단방향 attention + autoregressive 학습으로 생성 task에 강하다. 입력 전체를 받아 분류·추출·검색하는 이해가 목적이면 BERT, 새 텍스트를 만들어내는 생성이 목적이면 GPT를 선택하면 된다. 현대 LLM의 두 큰 흐름이 이 두 모델 계열에서 출발한다.

📌 What the question asks

“Compare BERT and GPT in terms of the Transformer, and when to use each.” Encoder/decoder and bidirectional/unidirectional are the core contrast.

🤖 Both are built from the Transformer, differing in which half and which training objective.

📖 BERT — Encoder, bidirectional

  • Transformer encoder stack.
  • Bidirectional self-attention — each token sees both sides.
  • Trained by Masked LM + Next Sentence Prediction.
  • Not naturally generative.

✍️ GPT — Decoder, unidirectional

  • Transformer decoder stack.
  • Unidirectional (causal mask) — each token sees only previous tokens.
  • Trained as an autoregressive LM (next-token).
  • Strong at left-to-right generation.

🔑 The core contrast is bidirectional encoder vs unidirectional decoder. BERT uses full context, so it excels at understanding — classification, NER, extractive QA, sentence embeddings 🔍. GPT predicts the next token, so it excels at generation — completion, dialogue, open-ended and few-shot ✨.

📝 BERT is a reader doing fill-in-the-blank — it must see both sides to answer. GPT is a storyteller continuing the text — it decides the next word from what's written so far.

🧭 When: understanding/encoding (classify, extract, retrieve) → BERT; generating text → GPT. Same Transformer parts, used in different directions.

🎯 Model Answer (English)

Both are built from the Transformer but use different halves and objectives. BERT is a Transformer encoder with bidirectional self-attention (each token sees both left and right context), trained by masked language modelling (predict masked tokens) plus next-sentence prediction; it excels at understanding tasks that need full context — classification, named-entity recognition, extractive question answering, sentence embeddings — but is not naturally generative. GPT is a Transformer decoder with unidirectional (causally masked) self-attention (each token sees only previous tokens), trained as an autoregressive language model (predict the next token); it excels at generation — completion, dialogue, open-ended and few-shot tasks. In short: use BERT for understanding/encoding tasks and GPT for generation.

🇰🇷 모범답안 (한국어)

둘 다 트랜스포머로 만들어졌지만 다른 절반과 목표를 쓴다. BERT는 양방향 셀프 어텐션을 가진 트랜스포머 인코더로(각 토큰이 좌우 문맥을 모두 봄), 마스크 언어모델링(가려진 토큰 예측)과 다음 문장 예측으로 학습한다; 전체 문맥이 필요한 이해 과제 — 분류, 개체명 인식, 추출형 질의응답, 문장 임베딩 — 에 강하지만 본질적으로 생성형은 아니다. GPT는 단방향(인과 마스크) 셀프 어텐션을 가진 트랜스포머 디코더로(각 토큰이 이전 토큰만 봄), 자기회귀 언어모델(다음 토큰 예측)로 학습한다; 생성 — 완성, 대화, 개방형 및 퓨샷 과제 — 에 강하다. 요약하면, 이해/인코딩 과제엔 BERT, 생성엔 GPT를 쓴다.

📝 시험 답안 골격

  • 공통 Transformer. BERT = 인코더·양방향·마스크LM, GPT = 디코더·단방향(인과)·자기회귀LM.
  • BERT는 전체 문맥 이해(분류·NER·QA·임베딩), GPT는 생성(이어쓰기·대화·few-shot).
  • 고르는 기준 — 이해 과제면 BERT, 생성 과제면 GPT.
