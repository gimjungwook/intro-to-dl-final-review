갈래 4 / 순환 신경망과 시퀀스 · Q12·13·14

    시간을 펼치면
    깊은 그래프가 된다

    RNN은 같은 변환을 시간 위에 반복 적용해 만든 그래프다. 그 그래프가 일반 트리의 특수 경우라는 것, 깊어질수록 기억이 사라지는 문제와 LSTM의 해법, 그리고 CNN과의 공유·연결 방식 차이를 본다.

    🌳 Q12 · RNN은 재귀 신경망(recursive NN)의 특수 경우

    Why is RNN a special case of recursive neural network?

    두 모델의 공통점부터 보자. 둘 다 같은 파라미터를 구조의 모든 노드에서 반복 적용해, 자식 표현들을 부모 표현으로 합친다. 차이는 그 “구조”의 모양이다.

    재귀 신경망은 일반적인 트리(또는 DAG) 구조 위에서 작동한다. 예컨대 문장의 구문 분석 트리에서, 같은 합성 함수가 두 자식 구를 한 부모 구로 합치는 일을 트리 전체에 재귀적으로 적용한다. 순환 신경망(RNN)은 이 구조가 사슬(chain), 즉 한 줄로 늘어선 퇴화한 트리인 특수 경우다. 매 시점의 노드는 자식이 하나(직전 상태)뿐이고, 거기에 현재 입력을 더해 다음 상태를 만든다.

    재귀 신경망이 “가지를 자유롭게 뻗는 나무”라면, RNN은 “가지 없이 곧게 자란 대나무”다. 둘 다 같은 마디(파라미터)를 반복해 자라지만, 대나무는 트리의 모든 분기 가능성을 한 줄로 좁힌 특수한 나무다.

    이 관점이 알려 주는 실용적 사실이 있다. RNN은 사슬이라 깊이가 시퀀스 길이 $n$에 비례해 선형으로 깊어진다. 반면 균형 잡힌 이진 트리 재귀망은 깊이가 $\log n$에 그친다. 깊이가 얕을수록 기울기가 통과해야 할 곱셈 단계가 적어, 일반 재귀망은 긴 의존성에서 기울기 소실(Q13)에 더 강할 수 있다. 즉 RNN을 “재귀망의 사슬 특수 경우”로 보면, 그 장단점이 구조의 깊이에서 따라 나옴을 한눈에 이해할 수 있다.

    🎯 Model Answer (English)

    Both apply the same parameters repeatedly across the nodes of a structure, combining children into a parent representation. A recursive neural network operates on a general tree (or DAG) structure — for example a sentence's parse tree, where one composition function merges two child phrases into a parent. An RNN is the special case in which that structure is a chain — a degenerate, linear tree: each step's node has a single child (the previous state) plus the current input. So an RNN is a recursive network whose topology has been narrowed to a path. A practical consequence is that an RNN's depth grows linearly with the sequence length $n$, whereas a balanced recursive tree grows only as $\log n$, so trees can be gentler on gradients over long dependencies.

    📝 시험 답안 골격

    • 공통 — 같은 파라미터를 구조의 모든 노드에 반복 적용해 자식→부모로 합침.
    • 재귀망 = 일반 트리/DAG 구조. RNN = 그 구조가 사슬(퇴화 트리)인 특수 경우.
    • 결과 — RNN 깊이 $\propto n$, 균형 트리 $\propto\log n$ → 트리가 긴 의존성·기울기에 유리할 수 있음.

    🧠 Q13 · LSTM의 ‘기억 소실(memory-fade-away)’ 극복

    How does LSTM overcome the ‘memory-fade-away’ issue?

    왜 기억이 사라지는가? 바닐라 RNN에서 은닉 상태는 매 시점 같은 순환 가중치 행렬과 곱해진다. 그래서 $t$ 스텝 전의 정보가 현재에 주는 영향(기울기)은 대략 그 행렬을 $t$번 곱한 것에 비례한다.

    $$ \frac{\partial h_t}{\partial h_{t-k}} \;\propto\; \prod_{i} W \;\sim\; W^{k} $$

    최대 고윳값이 1보다 작으면 $W^k\to 0$ — 기억이 지수적으로 소실. 1보다 크면 폭발(Q7).

    탄젠트 활성의 도함수도 1보다 작아 이 소실을 부추긴다. 결국 수십 스텝 전의 정보는 현재에 거의 영향을 주지 못한다 — 긴 의존성을 못 배우는 “기억 소실”이다.

    LSTM의 해법은 셀 상태(cell state) $c_t$와 게이트(gate)다. 셀 상태는 행렬 곱이 아니라 덧셈으로 갱신되며, 거의 1에 가까운 자기 순환(self-loop)을 가진다.

    $$ c_t = f_t \odot c_{t-1} + i_t \odot g_t $$

    $f_t$ 망각 게이트, $i_t$ 입력 게이트, $g_t$ 새 후보. 망각 게이트가 1에 가까우면 $c_t\approx c_{t-1}$로 정보가 그대로 보존된다.

    이 덧셈형 자기 순환을 상수 오류 회전목마(Constant Error Carousel, CEC)라 부른다. 망각 게이트 $f_t\approx 1$이고 입력이 작으면 셀 상태가 거의 변하지 않고, 그 경로를 따라 흐르는 기울기도 행렬 반복 곱 없이 $\approx 1$로 유지된다 — 지수적 소실이 사라진다. 세 게이트는 각각 “무엇을 지울지(망각)”, “무엇을 새로 쓸지(입력)”, “무엇을 밖으로 내보낼지(출력)”를 데이터로부터 학습한다. 즉 네트워크가 언제 기억하고 언제 잊을지를 스스로 조절한다.

    위젯 1320 스텝 뒤에도 남는 신호 — 바닐라 RNN vs LSTM
    바닐라 RNN(고정 감쇠)LSTM(f 조절)

    바닐라 RNN(파랑)은 가중치·활성에 묶인 고정 감쇠율로 신호가 지수적으로 사라진다. LSTM(빨강)은 망각 게이트 f를 1에 가깝게 학습하면 $f^t\approx1$로 신호를 수십 스텝 보존한다. f를 낮추면 LSTM도 의도적으로 잊을 수 있음을 본다.

    🎯 Model Answer (English)

    In a vanilla RNN the hidden state is multiplied by the same recurrent weight matrix at every step, so the influence of an input $k$ steps back scales like $W^k$; if the largest eigenvalue is below 1 the gradient vanishes exponentially (and the $\tanh$ derivative, being below 1, worsens it), so long-range dependencies are lost. The LSTM fixes this with a cell state that is updated additively and gated: $c_t = f_t \odot c_{t-1} + i_t \odot g_t$. This additive self-loop is the Constant Error Carousel — when the forget gate $f_t \approx 1$ the cell state is preserved and the gradient flows along it at roughly 1, with no repeated matrix multiplication, so it does not vanish. The forget, input, and output gates let the network learn when to keep, write, and expose information.

    📝 시험 답안 골격

    • 원인 — 바닐라 RNN은 순환행렬 반복 곱 $\sim W^k$ → 고윳값<1이면 지수 소실(+tanh 도함수<1).
    • 해법 — 셀 상태의 덧셈형 갱신 $c_t=f_t\odot c_{t-1}+i_t\odot g_t$ + 게이트. CEC로 기울기 $\approx1$ 보존.
    • 게이트(망각·입력·출력)로 언제 기억/망각할지 학습. 행렬 반복 곱이 없어 소실 제거.

    ⚖️ Q14 · RNN vs CNN — 파라미터 공유와 측면 연결

    Compare RNN and CNN in terms of parameter sharing and lateral connection.

    파라미터 공유 — 무엇의 축으로 공유하는가

    둘 다 파라미터를 공유하지만 공유하는 축이 다르다. CNN은 공간(space) 축으로 공유한다 — 같은 커널이 이미지의 모든 위치에 적용된다. RNN은 시간(time) 축으로 공유한다 — 같은 전이 가중치가 모든 시점에 적용된다. 목적은 같다: 자유 파라미터를 줄이고, 한 위치/시점에서 배운 것을 다른 위치/시점에 일반화하며, 각각 공간 등가성과 시간 등가성을 얻는다.

    측면 연결(lateral connection) — 멀리 떨어진 입력에 어떻게 닿는가

    결정적 차이가 여기 있다. RNN은 측면(순환) 연결을 가진다 — 같은 층의 유닛이 시간축을 따라 서로 연결되어, $t$ 시점의 상태가 $t{+}1$ 시점으로 전달된다. 정보가 상태(state)에 실려 시퀀스를 따라 옆으로 흐른다. CNN은 한 층 안에 측면 연결이 없다 — 각 출력은 자기 수용 영역만 보고 독립적으로 계산된다. 멀리 떨어진 입력들을 통합하려면 층을 더 쌓아 수용 영역을 키우는 수밖에 없다.

    CNN

    • 공유 축 = 공간.
    • 측면 연결 없음. 먼 입력엔 깊이로 닿음(수용 영역 확장).
    • 위치별 출력이 독립 → 병렬화 쉬움.

    RNN

    • 공유 축 = 시간.
    • 측면(순환) 연결 있음. 먼 시점엔 상태 전달로 닿음.
    • 순차 계산 → 병렬화 어려움, 기울기 소실 위험.
    CNN이 “각자 자기 구역만 보는 여러 감시원을 층층이 쌓아 점점 넓은 시야를 만드는 조직”이라면, RNN은 “한 명의 전령이 메모(상태)를 들고 줄을 따라 차례로 전달하는 방식”이다. 전자는 동시에 일하지만 멀리 보려면 층이 필요하고, 후자는 한 줄로 멀리까지 전하지만 순서대로여서 느리고 메모가 흐려질 수 있다.

    요약하면, 공유 축(공간 대 시간)과 먼 의존성에 닿는 방식(깊이 대 측면 순환)이 두 모델의 성격을 가른다. RNN의 측면 연결은 원리상 무한한 문맥을 주지만 순차성과 소실의 대가가 따르고, CNN의 무측면-깊이 방식은 병렬성을 주지만 수용 영역이 깊이에 묶인다. (이 둘의 한계를 함께 넘은 것이 self-attention이다 — Q25.)

    🎯 Model Answer (English)

    Both share parameters, but along different axes. A CNN shares across space — the same kernel is applied at every spatial position — whereas an RNN shares across time — the same transition weights are applied at every time step; both cut the number of free parameters, generalise what is learned across positions or times, and grant a form of equivariance. The decisive difference is the lateral connection: an RNN has lateral (recurrent) connections, so the unit at step $t$ feeds the unit at step $t{+}1$ and information flows sideways along the sequence through the hidden state; a CNN has no lateral connections within a layer — each output is computed independently from its local receptive field, and distant inputs are reached only by stacking layers to enlarge that field. Thus a CNN parallelises easily but its context is bounded by depth, while an RNN reaches arbitrarily far through recurrence but is sequential and prone to vanishing gradients (self-attention later overcomes both — Q25).

    📝 시험 답안 골격

    • 공유 축 — CNN=공간, RNN=시간. 둘 다 파라미터 절감 + 위치/시점 일반화 + 등가성.
    • 측면 연결 — RNN 있음(순환, 상태가 옆으로 흐름), CNN 없음(먼 입력엔 깊이로 닿음).
    • 대가 — CNN 병렬·수용영역 한계, RNN 무한문맥이나 순차·소실. (→ self-attention이 절충, Q25.)
