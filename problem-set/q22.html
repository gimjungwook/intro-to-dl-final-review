👾 Q22 · 적대적 예제(adversarial examples)의 핵심

What is the main point of the adversarial examples?

📌 질문 해석

“adversarial example의 main point는?” 단순 정의를 넘어, 왜 생기는지(고차원에서의 선형성)라는 핵심을 짚는 게 포인트.

👾 Adversarial example이란, 사람 눈엔 원본과 똑같아 보이지만 의도적으로 설계된 미세 섭동 $\eta$를 더해 높은 정확도의 네트워크가 엉뚱한 클래스로 high confidence 오분류하게 만드는 입력이다. 대표 생성법이 FGSM 🎯.

$$ \tilde{x} = x + \epsilon\,\operatorname{sign}\!\big(\nabla_x J(\theta,x,y)\big) $$

손실을 가장 빨리 키우는 방향(gradient 부호)으로 각 픽셀을 $\epsilon$만큼만 민다. $\lVert\eta\rVert_\infty=\epsilon$로 작게 유지.

💥 핵심은 원인이다. “모델이 너무 복잡·비선형이라”가 아니라 정반대로 “고차원에서 너무 linear(선형)하기 때문”이라는 linear explanation(선형성 가설). 선형 반응 $w^\top x$에 섭동 $\eta=\epsilon\,\operatorname{sign}(w)$를 더하면 출력 변화는:

$$ w^\top(x+\eta)-w^\top x = \epsilon\,\lVert w\rVert_1 = \epsilon\sum_{i=1}^{n}|w_i| $$

픽셀당 변화는 $\epsilon$로 미미하지만, 차원 $n$에 걸쳐 같은 방향으로 모두 더해져 출력 변화는 $n$에 비례해 폭증.

🧩 즉 각 차원 변화는 사람이 못 느낄 만큼 작아도 차원이 수만 개면 전부 같은 방향으로 합쳐져 활성값을 크게 흔든다. ReLU·LSTM 등 현대 부품이 일부러 거의 piecewise-linear라 최적화가 쉬운데, 그 선형성이 곧 취약성의 대가 ⚔️.

🛡️ 함의 둘: ① security — 분류기를 값싸게 속일 수 있다. ② 흥미롭게도 regularization — adversarial example을 훈련에 섞는 adversarial training은 decision boundary를 데이터에서 멀리 밀어 robustness와 generalization을 함께 높인다. 적대적 예제는 “모델이 의미가 아니라 표면적 선형 통계를 배웠다”는 진단 도구이기도 하다 🔬.

📌 What the question asks

“What is the main point of adversarial examples?” Go beyond the definition to the core cause — high-dimensional linearity.

👾 An adversarial example adds a tiny, deliberately crafted perturbation $\eta$ — invisible to humans — that makes a high-accuracy network misclassify with high confidence. The classic recipe is FGSM 🎯.

$$ \tilde{x} = x + \epsilon\,\operatorname{sign}\!\big(\nabla_x J(\theta,x,y)\big) $$

Push each pixel by $\epsilon$ along the loss-increasing direction; $\lVert\eta\rVert_\infty=\epsilon$ stays small.

💥 The point is the cause: not too much non-linearity, but the opposite — networks are too linear in high dimensions (linear explanation). For a linear response $w^\top x$, the shift is $\epsilon\lVert w\rVert_1=\epsilon\sum_i|w_i|$.

$$ w^\top(x+\eta)-w^\top x = \epsilon\,\lVert w\rVert_1 $$

🧩 Each per-pixel change is negligible, but across thousands of dimensions they add up in one direction. ReLU/LSTM are deliberately near piecewise-linear (easy to optimize) — that linearity is the price ⚔️.

🛡️ Two implications: ① security — cheap to fool a classifier. ② regularization — adversarial training pushes decision boundaries away from data, improving robustness and generalization. Adversarial examples also reveal that models learned surface linear statistics, not meaning 🔬.

위젯 22선형 누적 — 작은 섭동이 차원 수만큼 쌓인다

픽셀당 섭동 크기는 그대로 두고 입력 차원 n만 키워 보라. 픽셀 하나의 변화(왼쪽 막대)는 늘 작지만, 출력 활성값의 총 변화(오른쪽)는 차원에 비례해 폭증한다. 고차원이 적대적 예제를 가능케 하는 메커니즘이다.

🎯 Model Answer (English)

An adversarial example is an input carrying a tiny, deliberately crafted perturbation — imperceptible to a human — that makes a high-accuracy network misclassify with high confidence (e.g. FGSM, which nudges each pixel slightly in the direction that increases the loss). The main point is its cause: not excessive non-linearity, but excessive linearity in high dimensions. For a linear response, moving each input dimension by a tiny amount in the gradient's direction shifts the output by an amount that grows with the input dimension — each component changes negligibly, yet thousands of aligned changes sum to a large shift. This is both a security threat and, usefully, a regulariser: adversarial training pushes decision boundaries away from the data and improves generalisation.

📝 시험 답안 골격

  • 정의 — 사람 눈에 안 보이는 의도적 미세 섭동으로 고정확도 모델을 고확신 오분류시키는 입력. 대표 생성법 FGSM (손실 증가 방향으로 각 픽셀 살짝 이동).
  • 핵심 원인은 비선형성이 아니라 고차원에서의 선형성. 픽셀당 변화는 작지만 수만 차원에 걸쳐 같은 방향으로 합산되어 출력 변화가 폭증. ReLU/LSTM 같은 부품의 piecewise-linearity가 원인.
  • 함의 — (1) 보안 위협 (값싸게 속일 수 있음), (2) 정칙화 기회 (adversarial training이 decision boundary를 멀리 밀어 일반화 향상), (3) 진단 도구 (모델이 진짜 의미가 아닌 표면적 통계를 학습했음을 폭로).
