👾 Q22 · 적대적 예제(adversarial examples)의 핵심

What is the main point of the adversarial examples?

📌 질문 해석

“adversarial example의 main point는?” 단순 정의를 넘어, 왜 생기는지(고차원에서의 선형성)라는 핵심을 짚는 게 포인트.

👾 적대적 예제(adversarial example)는 딥러닝의 안전성과 신뢰성에 중요한 함의를 갖는 흥미로운 현상이다. 이 질문의 핵심은 단순히 적대적 예제가 무엇인지가 아니라, 왜 생기는지의 본질적 원인을 파악하는 것이다.

📖 정의: 무엇인가

적대적 예제란 다음과 같은 입력을 말한다.

  • 원본 입력에 매우 작은 의도적 변동(섭동, perturbation)이 더해진 것
  • 그 변동이 너무 작아서 사람 눈에는 원본과 거의 구별되지 않는다
  • 그런데 높은 정확도를 자랑하던 신경망이 이 변형된 입력을 완전히 다른 클래스로, 그것도 매우 높은 확신으로 오분류한다

대표적인 사례로, 판다 이미지에 사람 눈에 안 보이는 미세한 노이즈를 추가했더니 분류기가 "긴팔원숭이"라고 99% 확신으로 답했다는 실험이 유명하다. 자율주행차의 도로 표지판 인식, 얼굴 인식 시스템 등 실제 안전이 중요한 영역에서 심각한 위협이 된다.

대표적인 생성 방법인 FGSM(Fast Gradient Sign Method)은 다음과 같이 작동한다. 모델의 손실 함수를 입력에 대해 미분해서 "어느 방향으로 입력을 흔들면 손실이 가장 빠르게 커지는가"를 알아낸다. 그 방향으로 각 픽셀을 아주 작은 양만큼 민다 — 그 양이 매우 작아 사람 눈에 안 보이지만, 모델의 손실 함수는 크게 증가하니 분류가 틀어진다.

💥 핵심 원인: 비선형성이 아니라 "선형성"이다

적대적 예제의 가장 놀라운 사실은 그 원인에 있다. 직관적으로 생각하면 "신경망이 너무 복잡하고 비선형적이라 작은 입력 변화에도 출력이 격렬하게 흔들리는 것"이라고 추측할 수 있다. 그런데 실제 원인은 정반대다 — "신경망이 고차원에서 너무 선형적이기 때문"이다.

이걸 linear explanation(선형성 가설)이라고 부르는데, Goodfellow 등이 2015년에 제안한 이론이다.

왜 선형성이 문제인가. 가장 간단한 선형 모델을 생각해보자. 입력 x를 받아 가중치 w와의 내적 (w·x)을 출력하는 모델이다. 만약 입력에 작은 변동 η를 더하면, 출력 변화는 (w·η)다.

이 변동을 가장 효과적으로 만들려면 어떻게 해야 할까? η의 각 성분을 w의 같은 성분과 같은 부호로 맞추면 된다. 그러면 각 성분의 기여가 모두 양수로 더해진다.

여기서 핵심 통찰이 나온다. 각 입력 차원에서의 변화는 매우 작더라도(사람이 못 느낄 정도) 차원이 수만 개라면 그 작은 변화들이 모두 같은 방향으로 합쳐져 출력에서는 거대한 변화를 만든다.

구체적으로, 픽셀당 변화가 0.01이라고 해도 입력 차원이 10,000이면 출력은 100만큼 변할 수 있다. 픽셀 한 개의 변화는 사람이 절대 못 느끼지만, 그게 모여서 모델 출력을 흔드는 데는 충분하다.

🌊 한 개의 작은 물방울은 아무 영향이 없다. 하지만 천 개의 물방울이 동시에 같은 방향으로 떨어지면 큰 파도가 된다. 적대적 예제는 정확히 이런 원리다 — 픽셀 하나의 변화는 사소하지만, 수만 개 픽셀이 의도적으로 같은 "공격 방향"으로 동시에 변하면 그 효과가 합산되어 모델 출력을 완전히 뒤집을 수 있다.

🧩 왜 신경망은 선형적인가

"신경망은 비선형 활성 함수로 비선형성을 만든다"라고 배웠는데, 왜 선형적이라고 할까?

비결은 ReLU, LSTM, sigmoid 같은 현대 신경망 부품들이 사실 매우 "piecewise linear"(구간별 선형)에 가깝게 설계되어 있다는 점이다. ReLU는 음수에서는 0, 양수에서는 입력 그대로를 출력하니 양수 영역에서는 완벽한 선형이다. 사실 ReLU 기반 신경망은 입력 공간을 수많은 구간으로 나누고, 각 구간 안에서는 완전히 선형 함수처럼 동작한다.

이게 의도된 설계다 — 선형에 가까운 모델은 학습 시 gradient가 잘 흘러서 최적화가 쉽다. 즉 딥러닝의 성공 비결인 "쉬운 최적화"가 곧 적대적 예제 취약성의 원인이다. 표현력과 안전성 사이의 trade-off가 있다.

🛡️ 두 가지 함의

1) 보안 위협

FGSM 같은 간단한 알고리즘으로 누구나 모델을 속일 수 있다. 자율주행차, 얼굴 인식, 의료 진단 같은 안전 중요 시스템이라면 심각한 문제다. 특히 black-box 공격(모델 구조를 모르고도 공격 가능), 물리 세계 공격(인쇄된 적대적 패치) 등 실세계 위협이 입증되어 있다.

2) 의외의 정칙화 기회: Adversarial Training

흥미롭게도 적대적 예제를 학습에 적극적으로 활용하면 모델 성능이 향상된다. Adversarial training은 학습 중에 매 batch마다 적대적 예제를 만들어서 모델이 그것까지 올바르게 분류하도록 학습시킨다.

그 결과 모델의 decision boundary가 데이터에서 더 멀리 밀려난다. 즉 데이터 주변의 "안전 마진"이 넓어진다. 이게 적대적 공격에 강건해질 뿐 아니라 일반적인 일반화 성능까지 개선하는 경우가 많다. 적대적 예제가 강력한 정칙화 도구가 되는 것이다.

3) 진단 도구

적대적 예제가 존재한다는 사실 자체가 "이 모델이 이미지의 진짜 의미가 아니라 표면적인 통계 패턴을 학습했다"는 진단 도구로 작용한다. 모델이 진짜 강아지의 본질을 이해했다면 픽셀 몇 개 흔든다고 고양이로 보일 리 없다. 적대적 예제는 모델 해석과 개선의 출발점이 된다.

위젯 22선형 누적 — 작은 섭동이 차원 수만큼 쌓인다

픽셀당 섭동 크기는 그대로 두고 입력 차원 n만 키워 보라. 픽셀 하나의 변화(왼쪽 막대)는 늘 작지만, 출력 활성값의 총 변화(오른쪽)는 차원에 비례해 폭증한다. 고차원이 적대적 예제를 가능케 하는 메커니즘이다.

🛡️ 함의 둘: ① security — 분류기를 값싸게 속일 수 있다. ② 흥미롭게도 regularization — adversarial example을 훈련에 섞는 adversarial training은 decision boundary를 데이터에서 멀리 밀어 robustness와 generalization을 함께 높인다. 적대적 예제는 “모델이 의미가 아니라 표면적 선형 통계를 배웠다”는 진단 도구이기도 하다 🔬.

🎯 Model Answer (English)

An adversarial example is an input carrying a tiny, deliberately crafted perturbation — imperceptible to a human — that makes a high-accuracy network misclassify with high confidence (e.g. FGSM, which nudges each pixel slightly in the direction that increases the loss). The main point is its cause: not excessive non-linearity, but excessive linearity in high dimensions. For a linear response, moving each input dimension by a tiny amount in the gradient's direction shifts the output by an amount that grows with the input dimension — each component changes negligibly, yet thousands of aligned changes sum to a large shift. This is both a security threat and, usefully, a regulariser: adversarial training pushes decision boundaries away from the data and improves generalisation.

📝 시험 답안 골격

  • 정의 — 사람 눈에 안 보이는 의도적 미세 섭동으로 고정확도 모델을 고확신 오분류시키는 입력. 대표 생성법 FGSM (손실 증가 방향으로 각 픽셀 살짝 이동).
  • 핵심 원인은 비선형성이 아니라 고차원에서의 선형성. 픽셀당 변화는 작지만 수만 차원에 걸쳐 같은 방향으로 합산되어 출력 변화가 폭증. ReLU/LSTM 같은 부품의 piecewise-linearity가 원인.
  • 함의 — (1) 보안 위협 (값싸게 속일 수 있음), (2) 정칙화 기회 (adversarial training이 decision boundary를 멀리 밀어 일반화 향상), (3) 진단 도구 (모델이 진짜 의미가 아닌 표면적 통계를 학습했음을 폭로).
