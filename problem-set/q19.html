🧹 Q19 · 정칙화된 오토인코더(regularized autoencoders)

Why do we need regularized autoencoders and how can we make them?

📌 질문 해석

두 갈래 — ① 왜 regularized autoencoder가 필요한지(항등함수 문제), ② 어떻게 만드는지(sparse·denoising·contractive).

🧹 왜 필요? autoencoder의 capacity가 충분히 크면(특히 은닉 차원 ≥ 입력인 overcomplete 경우) identity function(항등함수)을 그대로 외워 입력을 출력으로 복사할 수 있다 📋. 복원 오차는 0이지만 배운 건 아무것도 없다. 우리가 원하는 건 “복사”가 아니라 데이터의 의미 있는 구조. 정칙화는 복원 외의 추가 목표를 부과해 capacity와 무관하게 쓸모 있는 표현을 배우게 강제한다 ✅.

🛠️ 어떻게 만드나 — 추가 목표가 무엇이냐로 갈린다:

✨ Sparse AE은닉 활성에 벌점 $\Omega(h)=\lambda\lVert h\rVert_1$. 대부분 유닛을 0 근처로 눌러 희소·부분 기반(parts-based) 특징 학습. 🌫️ Denoising AE (DAE)입력을 일부러 손상시켜 $\tilde x$를 넣고 깨끗한 $x$를 복원하게 학습. 입력이 손상돼 단순 복사가 불가능 → 데이터 manifold를 배워야 복원 가능. manifold로 향하는 vector field를 학습. 🤏 Contractive AE (CAE)encoder Jacobian의 Frobenius norm $\lVert\partial h/\partial x\rVert_F^2$에 벌점. 표현이 입력의 작은 변화에 둔감(수축)해져 데이터가 놓인 방향(tangent)만 민감하게 잡음.
📝 정칙화 없는 AE = 받아쓰기에서 문제지를 그대로 베껴 내는 학생(만점이나 이해 0). sparse·denoising·contractive 정칙화는 각각 “핵심 단어만 적어”, “일부 글자 지운 문제를 복원해”, “문제가 조금 바뀌어도 같은 답을 써”라는 규칙을 걸어 베끼기 대신 내용을 이해하게 만든다.
🎯 Model Answer (English)

Why: an autoencoder with enough capacity — especially an over-complete one whose hidden layer is at least as large as the input — can simply learn the identity function, copying input to output with zero reconstruction error while learning nothing useful. Regularisation imposes an additional objective beyond reconstruction so a useful representation is learned regardless of capacity. How: (1) a sparse autoencoder adds a penalty $\lambda\lVert h\rVert_1$ on the hidden activations, forcing most units to zero and learning parts-based features; (2) a denoising autoencoder corrupts the input and trains the network to reconstruct the clean version, so copying is impossible and it must learn the data manifold; (3) a contractive autoencoder penalises the Frobenius norm of the encoder's Jacobian $\lVert\partial h/\partial x\rVert_F^2$, making the code insensitive to small input changes and sensitive only along the manifold.

📝 시험 답안 골격

  • 필요 이유 — 용량 큰 AE는 항등함수를 외워 복사만 함(배움 0). 복원 외 목표를 부과해야 유용 표현.
  • 희소 — 은닉에 $L_1$ 벌점(부분 기반). 잡음제거(DAE) — 손상입력→깨끗복원(매니폴드 학습).
  • 수축(CAE) — 야코비안 노름 벌점으로 입력 변화에 둔감(접선만 민감).
