📉 Q1 · 작은 데이터셋의 정칙화 전략

When the dataset is small compared to the model size, what kind of regularization approaches can we take?

📌 질문 해석

이 문제는 “데이터가 모델보다 작을 때 쓸 수 있는 정칙화 접근들”을 묻는다 — 한 기법이 아니라 여러 방법을 분류해 나열하고, 각각이 왜 작은 데이터에서 과적합을 막는지까지 엮어야 만점.

🎯 이 문제의 뿌리는 bias-variance tradeoff다. 모델의 capacity(표현 용량)가 데이터 양보다 크면 모델이 신호뿐 아니라 잡음까지 외워버린다 😵 — 훈련 오차는 0에 가깝지만 새 데이터에선 무너지는 overfitting(과적합)이다.

💡 정칙화(regularization)의 본질은 “우리가 미리 아는 prior(사전 지식)를 모델에 넣어, 잡음을 외울 자유를 빼앗는 것”. 데이터가 적을수록 이 prior 비중을 키운다.

📐 점 3개만 주고 곡선을 그리라면 그 점을 지나는 곡선은 무한히 많다. 제약이 없으면 가장 구불구불한 괴물 곡선이 나온다 🐙. 정칙화는 “매끄럽게 그려”, “대칭일 것” 같은 믿음을 더해 답 후보를 좁히는 일이다.

🔧 작은 데이터에서 쓸 수 있는 손잡이들

🏋️ 1. Parameter Norm Penalty (가중치 벌점)

모델의 모든 가중치는 "데이터로부터 배운 값"이다. 가중치가 클수록 모델은 입력의 작은 변화에 크게 반응한다 — 즉 출력이 민감해진다. 이런 민감한 모델일수록 훈련 데이터의 잡음까지 충실히 외워서 일반화에 실패한다.

L2 (weight decay)는 손실 함수 옆에 "가중치가 크면 벌금"이라는 추가 비용을 붙인다. 학습 중에 모델은 두 목표를 동시에 본다: (가) 데이터를 잘 맞히기, (나) 가중치를 작게 유지하기. 두 목표가 충돌할 때 모델은 타협해서 충분히 데이터를 맞히되, 필요 이상으로 큰 가중치는 쓰지 않는 쪽으로 수렴한다. 결과적으로 매 학습 step마다 가중치가 조금씩 0 방향으로 끌려가는데, 이 현상이 이름 그대로 "decay(서서히 줄어듦)"다.

비유로 보면, L2는 마치 스프링이 가중치를 원점에 묶어두는 것과 같다. 데이터가 강하게 가중치를 한쪽으로 끌어당기면 가중치는 그쪽으로 움직이지만, 데이터의 신호가 약한 부분에서는 스프링이 다시 잡아당겨 가중치가 작은 채로 남는다. 잡음 같은 약한 신호는 절대로 큰 가중치를 만들지 못한다.

L1은 같은 벌점이지만, 가중치의 절대값을 기준으로 매긴다. L2가 큰 가중치에 더 가혹한 벌점을 주는 반면, L1은 가중치 크기와 상관없이 일정한 힘으로 0 쪽으로 민다. 그래서 작은 가중치도 결국 0에 도달하고, 모델은 자연스럽게 "꼭 필요한 가중치만 살리고 나머지는 0으로 꺼버리는" 형태가 된다. 이게 sparsity(희소성), 즉 자동 특징 선택 효과다.

직관적으로 비교하면, L2는 모든 가중치를 "조금씩 줄이지만 완전히 끄지는 않는다", L1은 "쓸모없는 가중치는 아예 꺼버린다". 둘 다 모델 표현력을 깎아 잡음 fit을 막지만, 결과 모델의 모양이 다르다.

핵심 한 줄: 큰 가중치 = 잡음까지 외울 능력. 벌점을 부과해 가중치를 작게 유지하면 모델이 단순해지고, 단순한 모델은 새 데이터에서 더 잘 동작한다.

🔗 2. Parameter Sharing / Tying (파라미터 공유)

벌점이 가중치 "크기"에 제약을 거는 방법이라면, 파라미터 공유는 가중치 "개수"를 구조적으로 줄여버리는 방법이다. 가중치가 많을수록 모델이 외울 수 있는 디테일도 많아지니, 처음부터 가중치 수를 줄이면 외울 능력 자체가 제한된다.

대표 예시는 CNN(합성곱 신경망)이다. 일반적인 fully-connected layer라면 입력 픽셀 하나하나마다 출력 뉴런까지 별개의 가중치가 필요하다. 28×28 이미지로 100차원 특징을 뽑으려면 약 7만 8천 개의 독립된 가중치가 생긴다. 반면 CNN의 3×3 합성곱 필터는 단 9개 가중치로 이미지의 모든 위치를 훑는다 — 이미지의 왼쪽 위든 오른쪽 아래든 같은 필터가 같은 패턴을 찾는다. 100개 채널을 만들어도 가중치는 900개뿐이다. 약 87배 줄어든다.

이게 가능한 이유는 이미지에 "강아지는 화면 어디에 있든 강아지"라는 사전 지식이 있기 때문이다. 위치별로 다른 가중치를 만들 필요가 없다 — 같은 가중치로 충분하다. 이 사전 지식을 모델 구조에 박아 넣은 셈이다.

RNN도 같은 원리다. 시간 t=1에서 입력을 처리하는 가중치와 t=100에서 처리하는 가중치를 동일하게 묶는다. "시간이 어디든 같은 규칙으로 다음 상태를 만든다"는 prior다. 덕분에 시퀀스 길이가 1000이어도 가중치 수는 그대로다.

Multi-task learning은 다른 각도에서 공유를 활용한다. 같은 모델로 여러 task(예: 감정 분류 + 주제 분류)를 동시에 학습시키면, 두 task가 공통으로 쓰는 hidden layer가 한 task의 데이터만으로는 학습 안 되는 표현까지 잡아낸다. 데이터를 늘리는 효과와 비슷하다.

핵심 한 줄: 가중치 수 자체를 줄이면 외울 수 있는 디테일이 줄어든다. CNN·RNN의 구조 자체가 이미 강력한 정칙화다.

🧪 3. Data Augmentation & Noise Injection (데이터 증강·잡음 주입)

정칙화의 다른 축은 "모델을 건드리는" 게 아니라 "데이터를 건드리는" 쪽이다. 데이터가 적을 때 가장 단순한 해결책은 데이터를 더 만드는 것인데, 라벨링은 비싸니까 라벨을 바꾸지 않는 변형으로 가짜 데이터를 만든다.

이미지라면 회전, 좌우 반전, 약간의 자르기, 색조 변경 같은 변형이 가능하다. "이 이미지가 강아지면, 좌우 뒤집어도 강아지다." 이런 변형으로 데이터를 N배 늘리면, 모델은 다양한 각도·위치·색조의 강아지를 모두 보고 학습하니 "강아지"라는 개념을 더 일반적으로 잡게 된다. 텍스트라면 동의어 교체, 한 언어로 번역했다가 다시 원어로 되돌리는 back-translation 같은 기법이 같은 역할을 한다.

Noise injection은 데이터 자체에 잡음을 일부러 섞는 방법이다. 입력 이미지에 살짝 흐릿함을 더하거나 픽셀 값에 랜덤 변동을 준다. 모델이 "정확히 이 픽셀 값"에 의존하지 못하게 만들어, 약간 다른 입력에도 같은 답을 내도록 강제한다. 이게 robustness, 즉 강건성이다.

Dropout은 noise injection의 가장 강력한 형태 중 하나다. 학습 중 매 step마다 hidden layer의 뉴런 절반 정도를 무작위로 꺼버린다. 다음 step에서는 다른 뉴런이 꺼진다. 결과적으로 매번 다른 형태의 작은 sub-network가 학습된다.

이게 효과적인 이유는 두 가지다. 첫째, 한 뉴런이 다른 특정 뉴런에 의존할 수 없다. 옆 뉴런이 언제 꺼질지 모르니, 모든 뉴런이 단독으로도 의미 있는 feature를 잡도록 학습된다. 이걸 "co-adaptation 차단"이라고 부른다. 둘째, dropout은 사실상 수많은 sub-network의 앙상블을 학습하는 것과 같다. 추론할 때는 모든 뉴런을 다 켜서 사용하지만, 그게 학습 중에 본 모든 sub-network들의 평균 예측에 가까워진다.

Label smoothing은 잡음을 라벨에 주는 변형이다. 보통 정답을 100% 확신(예: 강아지 = 1.0, 나머지 = 0.0)으로 가르치는데, 이걸 약간 흐리게(강아지 = 0.9, 나머지에 0.1 분산) 만든다. 모델이 정답에 과도하게 확신하지 않게 되어, calibration(확신도 보정)이 좋아지고 overfitting도 줄어든다.

핵심 한 줄: 데이터를 다양하게 만들고 잡음을 섞으면 모델이 특정 입력에 과도하게 의존하지 못한다. Dropout은 학습 중 매번 다른 sub-network를 만들어 앙상블 효과까지 얻는다.

⏱️ 4. Early Stopping (조기 종료)

학습을 너무 오래 시키면 모델이 결국 훈련 데이터의 잡음까지 외운다. 그래서 "외우기 직전에" 학습을 끊으면 된다는 게 조기 종료의 아이디어다.

방법은 단순하다. 학습 데이터와 별개로 검증(validation) 데이터를 따로 떼어 두고, 학습 중 주기적으로 검증 데이터의 손실을 측정한다. 처음에는 학습 손실과 검증 손실이 함께 줄어든다 — 모델이 진짜 패턴을 배우는 중이다. 그러다 어느 시점부터 학습 손실은 계속 줄지만 검증 손실은 다시 올라가기 시작한다. 이 변곡점이 모델이 진짜 패턴 학습을 마치고 잡음을 외우기 시작하는 순간이다. 이때 학습을 멈추고 가장 좋았던 검증 손실 시점의 가중치를 저장한다.

실용적으로는 검증 손실이 일정 횟수(patience) 동안 더 개선되지 않으면 멈춘다. 비용은 거의 없다 — 검증 손실을 한 번 더 측정하는 것뿐.

왜 L2와 비슷한 효과인가: 가중치는 보통 0 근처의 작은 값으로 초기화된다. 학습이 진행될수록 가중치는 점점 커진다 — 데이터 fit을 위해서 필요한 만큼 멀어진다. 학습을 일찍 끊으면 가중치가 아직 충분히 자라지 못한 상태에서 멈춘다. "가중치를 작게 유지한다"는 결과는 L2가 하는 일과 정확히 같다. 즉 학습 시간 자체가 정칙화 강도 역할을 한다 — 오래 학습할수록 정칙화가 약하고, 일찍 끊을수록 정칙화가 강하다.

비유로 보면, 조기 종료는 요리할 때 "타기 직전에 불 끄기"다. 너무 일찍 끄면 설익고(underfit), 너무 늦으면 탄다(overfit). 검증 손실 곡선이 "타기 시작하는 시점"을 알려주는 타이머 역할을 한다.

핵심 한 줄: 검증 손실이 다시 올라가면 학습 중단. 가중치가 작은 상태로 멈추므로 L2와 같은 효과가 거의 공짜로 얻어진다.

🌍 5. Transfer Learning / Unsupervised Pretraining (전이·사전훈련)

지금까지의 손잡이들은 모두 "주어진 작은 데이터 안에서 잘 해보자"는 접근이었다. 전이학습은 발상이 다르다 — 다른 곳에서 배운 지식을 가져와서 작은 데이터의 한계를 우회한다.

전이학습 절차는 두 단계다. 먼저 큰 source dataset(예: ImageNet의 100만 장 이미지, 인터넷의 수십억 단어)으로 모델을 충분히 학습시킨다. 이걸 pretrained model이라 한다. 그다음 작은 target dataset(우리가 풀고 싶은 문제, 예: 의료 영상 1,000장)으로 모델을 추가 학습시킨다. 이때 마지막 layer만 새로 학습시키거나, 전체를 매우 작은 learning rate로 살짝만 조정한다 — 이걸 fine-tuning이라고 부른다.

왜 효과가 클까. 처음부터 작은 데이터로 학습시키면 모델은 "엣지가 무엇인지", "선과 곡선이 무엇인지" 같은 가장 기초적인 표현부터 다 새로 배워야 한다. 1,000장으로는 절대 못 한다. 반면 ImageNet으로 미리 학습한 모델은 이미 "엣지·텍스처·물체 부분"까지 다 배워둔 상태다. 우리는 그 위에 올려 "이 데이터셋에 특화된 분류 규칙"만 새로 가르치면 된다. 작은 데이터로도 충분히 가능한 일이다.

비유하자면, 한국어를 막 배우기 시작한 사람에게 "법률 문서를 해석하라"고 하면 불가능하다. 하지만 한국어를 이미 능숙하게 하는 사람에게 법률 용어 1,000개만 추가로 가르치면 가능하다. 전이학습은 후자의 상황을 만든다.

Unsupervised pretraining은 한 단계 더 나아간다. 사전훈련 단계에서 label조차 필요 없는 방법으로 학습한다. 예를 들어 BERT는 "문장에서 일부 단어를 가리고 그게 뭐였는지 맞히기" 같은 self-supervised 과제로 인터넷의 수백억 단어를 학습한다. label이 없으니 데이터가 사실상 무한대다. 이렇게 배운 일반 언어 표현 위에 우리는 작은 labeled 데이터로 "감정 분류"나 "의학 텍스트 분류" 같은 특정 task만 추가 학습하면 된다.

왜 작은 데이터일수록 효과가 큰가. 데이터가 1억 장이면 from-scratch로 학습해도 모델이 충분한 일반 표현을 잡을 수 있으니 전이학습이 큰 차이를 만들지 못한다. 하지만 데이터가 1,000장이면 from-scratch는 절망적이고, pretrained 모델 없이는 사실상 불가능하다. 그래서 "데이터가 적을수록 전이학습의 효과가 극적으로 커진다"는 게 시험 답안에서 가장 강조할 포인트다.

핵심 한 줄: 큰 데이터로 미리 배운 지식을 가져오면 작은 데이터의 한계를 우회할 수 있다. 데이터가 적을수록 효과가 크다.

📌 What the question asks

Lists the regularization approaches available when the dataset is small relative to model size — name and group several methods and tie each to why it curbs overfitting.

🎯 The root is the bias–variance tradeoff. When capacity far exceeds what the data constrains, the model memorizes noise 😵 — near-zero training error but poor test error (overfitting). Regularization injects a prior that removes the freedom to memorize; the smaller the data, the heavier this prior should weigh.

📐 Given only three points, infinitely many curves pass through them; with no constraint the wildest one wins 🐙. Regularization adds beliefs (“be smooth”, “be symmetric”) that narrow the candidates.

🔧 Handles you can pull on small data

🏋️ Parameter norm penalty — add a size penalty: $\tilde J = J + \alpha\lVert w\rVert_2^2$. L2 (weight decay) pulls weights toward 0; L1 zeroes some, giving sparsity and automatic feature selection. (Bayesian view: L2 = Gaussian prior, L1 = Laplace prior.)

🔗 Parameter sharing / tying — reuse parameters across positions (CNN kernels) or time (RNN weights) to cut degrees of freedom. Multi-task learning shares representations too.

🧪 Data augmentation & noise injection — label-preserving transforms, plus noise on inputs, weights, hidden units (dropout), and labels (label smoothing).

⏱️ Early stopping — stop when validation error stops improving; under a quadratic approximation it is equivalent to L2, and nearly free.

🌍 Transfer learning / unsupervised pretraining — learn features from large external or unlabeled data, then fine-tune. The biggest payoff comes when your data is tiny ⬆️.

🎯 Model Answer (English)

When the model has far more capacity than the small dataset can constrain, it overfits by memorising noise, so the cure is to inject prior knowledge that shrinks the hypothesis space. The main approaches are: (1) parameter-norm penalties — L2 weight decay and L1 sparsity; (2) parameter sharing or tying to reduce the number of free parameters; (3) data augmentation and noise injection (on inputs, weights, hidden units via dropout, and labels via label smoothing); (4) early stopping, which is equivalent to L2 under a quadratic approximation; and (5) transfer learning or unsupervised pre-training, which import knowledge learned from external data. The smaller the dataset, the more weight these priors should carry, and transfer learning becomes especially valuable.
