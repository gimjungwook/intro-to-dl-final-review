📉 Q1 · 작은 데이터셋의 정칙화 전략

When the dataset is small compared to the model size, what kind of regularization approaches can we take?

📌 질문 해석

이 문제는 “데이터가 모델보다 작을 때 쓸 수 있는 정칙화 접근들”을 묻는다 — 한 기법이 아니라 여러 방법을 분류해 나열하고, 각각이 왜 작은 데이터에서 과적합을 막는지까지 엮어야 만점.

🎯 이 문제의 뿌리는 bias-variance tradeoff다. 모델의 capacity(표현 용량)가 데이터 양보다 크면 모델이 신호뿐 아니라 잡음까지 외워버린다 😵 — 훈련 오차는 0에 가깝지만 새 데이터에선 무너지는 overfitting(과적합)이다.

💡 정칙화(regularization)의 본질은 “우리가 미리 아는 prior(사전 지식)를 모델에 넣어, 잡음을 외울 자유를 빼앗는 것”. 데이터가 적을수록 이 prior 비중을 키운다.

📐 점 3개만 주고 곡선을 그리라면 그 점을 지나는 곡선은 무한히 많다. 제약이 없으면 가장 구불구불한 괴물 곡선이 나온다 🐙. 정칙화는 “매끄럽게 그려”, “대칭일 것” 같은 믿음을 더해 답 후보를 좁히는 일이다.

🔧 작은 데이터에서 쓸 수 있는 손잡이들

🏋️ 1. Parameter Norm Penalty (벌점)

L2 (weight decay) — 비용에 가중치의 제곱 합을 더한다:

$$\tilde J(w) = J(w) + \alpha\lVert w\rVert_2^2 = J(w) + \alpha\sum_i w_i^2$$

기울기는 $\nabla_w \tilde J = \nabla_w J + 2\alpha w$이고, 경사하강 한 step은

$$w \leftarrow (1 - 2\eta\alpha)\,w - \eta\nabla_w J$$

로 정리된다. 즉 매 step마다 $w$가 $(1-2\eta\alpha)$배로 줄어든다 — 원점으로 끌어당기는 효과가 이름(weight decay)의 이유다.

L1 — 절대값 합을 벌점으로 쓴다: $\tilde J = J + \alpha\sum_i |w_i|$. 기울기는 $\alpha \cdot \text{sign}(w_i)$로, 부호만 보고 크기와 무관하게 일정 속도로 0 쪽으로 밀어낸다. 그래서 작은 가중치도 정확히 0에 도달해 자동 특징 선택(sparsity)이 일어난다.

기하학적 차이: 같은 손실 등고선 위에서 L2 제약은 원, L1 제약은 마름모다. 마름모의 모서리는 좌표축 위에 있으므로 등고선이 그 모서리에서 처음 만나는 경우가 많고, 그 좌표는 정확히 0이 된다 → L1 sparsity.

베이지안 해석: MAP 추정 = 최대우도 + log prior. Gaussian prior $\mathcal{N}(0, \sigma^2)$의 log는 $-\frac{1}{2\sigma^2}w^2$ → L2. Laplace prior $\frac{1}{2b}e^{-|w|/b}$의 log는 $-\frac{1}{b}|w|$ → L1. 벌점 = 가중치에 대한 prior이고, 데이터가 적을수록 prior 비중($\alpha$)을 키운다.

🔗 2. Parameter Sharing / Tying (파라미터 공유)

같은 weight를 여러 곳에서 재사용 = free parameter 수를 구조적으로 줄인다. 모델 표현력은 유지하면서 자유도만 깎는 강한 정칙화다.

CNN 예시 — 28×28 입력에서 100 채널 출력을 만들 때:

  • FC layer: $28 \cdot 28 \cdot 100 = 78{,}400$ weights
  • Conv 3×3: $3 \cdot 3 \cdot 100 = 900$ weights (커널이 모든 공간 위치에서 동일)

약 87배 적은 파라미터다. 이게 가능한 이유는 이미지에 translation invariance(평행이동 등가)라는 사전 지식을 구조에 내장하기 때문 — "강아지 패턴은 어디 있든 강아지"라는 믿음을 모델 아키텍처가 가정한다.

RNN도 마찬가지로 같은 weight matrix $W_h$를 모든 timestep에서 재사용해 time invariance(시간 무관) prior를 주입한다.

Multi-task learning: 여러 task가 hidden layer를 공유하면 표현이 task 간 평균화 효과를 받아 사실상 데이터 양이 늘어난 것과 같다.

🧪 3. Data Augmentation & Noise Injection (증강·잡음)

Data augmentation — 라벨을 바꾸지 않는 변환으로 데이터셋을 부풀린다:

  • 이미지: rotation, crop, flip, color jitter, mixup
  • 텍스트: synonym swap, back-translation
  • 오디오: time stretch, pitch shift

모델은 "이런 변형에 답이 같다"는 invariance를 학습하게 되고, 사실상 데이터가 N배 늘어난 효과가 난다.

입력 noise: $x \to x + \epsilon, \epsilon \sim \mathcal{N}(0, \sigma^2)$. Bishop(1995)은 이게 가중치에 대한 L2 정칙화와 근사적으로 동등하다는 걸 보였다.

Dropout — 가장 강력한 noise injection 정칙화:

  • 학습 시: 각 hidden unit을 확률 $p$(보통 0.5)로 0으로 만든다
  • 매 미니배치마다 다른 sub-network가 학습된다
  • 추론 시: 전체 network 사용, 출력 weight를 $(1-p)$배로 스케일

앙상블 해석: $n$개 unit이 있으면 $2^n$개의 sub-network가 존재하고, dropout은 그들의 암묵적 평균을 학습하는 것과 같다. Co-adaptation 차단: 한 unit이 다른 특정 unit에 의존하지 못하므로, 각 unit이 단독으로도 유의미한 feature를 학습하게 된다 → 표현이 강건해진다.

Label smoothing — one-hot 타깃 $y$ 대신 $(1-\epsilon)\,y + \epsilon/K$를 쓴다. 정답에 100% 확신을 주지 않아 overconfidence를 막고 calibration이 좋아진다.

⏱️ 4. Early Stopping (조기 종료)

메커니즘: 매 epoch마다 validation loss를 측정 → patience epoch 동안 개선이 없으면 학습 중단 → 가장 좋았던 epoch의 weight를 복원. 비용은 거의 0이다(val 1회 측정 + checkpoint 저장).

왜 L2와 동치인가(quadratic 근사 아래) — 최적점 $w^*$ 근처에서 손실을 2차 근사하면:

$$J(w) \approx J(w^*) + \tfrac{1}{2}(w - w^*)^T H (w - w^*)$$

경사하강 $t$ step 후의 weight는

$$w^{(t)} - w^* = (I - \eta H)^t (w^{(0)} - w^*)$$

로 표현된다. $t$가 작을수록 $w$가 초기값(보통 0 근처)에 가까이 머무른다 — 즉 iteration 수 $t$가 정칙화 강도 역할을 한다($t \leftrightarrow 1/\alpha$). 학습을 일찍 끊으면 가중치가 작은 채로 멈추니, 결과적으로 L2 패널티가 가중치를 작게 유지한 것과 같은 효과가 난다.

🌍 5. Transfer Learning / Unsupervised Pretraining (전이·사전훈련)

전이학습:

  1. Pretrain: 큰 source dataset(ImageNet, Common Crawl 등)으로 모델을 학습
  2. Fine-tune: 작은 target dataset로 마지막 layer만 또는 전체를 낮은 learning rate로 조정

왜 작은 데이터에서 효과가 큰가:

  • target alone — capacity ≫ data → 과적합 확정
  • pretrained init — 이미 좋은 weight = 가설 공간이 사실상 축소된 것과 같다 = 강력한 implicit prior
  • low-level feature(edge, texture, 단어 의미)는 task 사이에 공통적이고, 작은 target 데이터만으로는 절대 못 배울 일반 표현을 source에서 빌려온다

Unsupervised pretraining(autoencoder, BERT의 MLM, GPT 등): label 없이 학습 가능 → 데이터가 사실상 무한대(인터넷 전체). 표현을 먼저 배우고 작은 labeled data로 head만 학습하면 labeled 데이터의 한계를 우회할 수 있다.

효과 크기 법칙: target dataset이 작을수록 transfer 이득이 커진다. 데이터가 1억 장이면 from scratch도 괜찮지만, 1,000장이면 pretrained 없이는 거의 불가능하다.

🎯 Model Answer (English)

When the model has far more capacity than the small dataset can constrain, it overfits by memorising noise, so the cure is to inject prior knowledge that shrinks the hypothesis space. The main approaches are: (1) parameter-norm penalties — $L_2$ weight decay and $L_1$ sparsity; (2) parameter sharing or tying to reduce the number of free parameters; (3) data augmentation and noise injection (on inputs, weights, hidden units via dropout, and labels via label smoothing); (4) early stopping, which is equivalent to $L_2$ under a quadratic approximation; and (5) transfer learning or unsupervised pre-training, which import knowledge learned from external data. The smaller the dataset, the more weight these priors should carry, and transfer learning becomes especially valuable.

📝 시험 답안 골격

  • 핵심 한 줄 — 데이터 부족 = 고분산 과적합. 정칙화 = 사전 지식 주입으로 가설 공간 축소.
  • 벌점(L2/L1) · 파라미터 공유 · 데이터 증강과 노이즈 · 드롭아웃 · 조기 종료 · 비지도 사전훈련/전이를 나열.
  • 데이터가 적을수록 사전의 비중을 키운다, 특히 전이학습의 효과가 커진다고 마무리.
