🪞 Q18 · 오토인코더 vs PCA

Compare Autoencoder and PCA.

📌 질문 해석

“autoencoder와 PCA를 비교하라.” 핵심은 linear AE = PCA이고 non-linear AE가 그걸 일반화한다는 점.

🪞 PCA와 Autoencoder는 비슷한 일을 하는 두 모델이다. 둘 다 입력을 저차원 표현(code)으로 압축한 뒤 다시 원본에 가깝게 복원하는 방식으로 데이터의 핵심 구조를 학습한다. 결정적 차이는 선형이냐 비선형이냐에 있고, 사실 둘은 같은 가족이라고 볼 수 있다.

📐 PCA (주성분 분석, Principal Component Analysis)

PCA는 데이터에서 분산이 가장 큰 방향들을 찾아 그 방향으로 데이터를 투영(projection)한다. "주성분(principal components)"이라 부르는 이 방향들은 서로 직교한다.

예를 들어 2차원 데이터가 대각선 방향으로 길게 펴져 있다면, 첫 번째 주성분은 그 대각선 방향이 된다. 데이터를 그 방향으로 투영하면 정보 손실을 최소화하면서 1차원으로 압축할 수 있다.

중요한 점은 PCA의 모든 동작이 선형(linear)이라는 것이다. 압축(데이터를 주성분 방향에 투영)도 선형이고, 복원(투영 결과로부터 원본 추정)도 선형이다. 따라서 PCA가 학습할 수 있는 구조는 "선형 부분공간(평평한 면)"으로 제한된다.

🔑 핵심 사실: Linear Autoencoder = PCA

이 사실이 두 모델의 관계를 가장 명확히 보여준다. 은닉층이 하나만 있고, 활성 함수가 선형(없음)이고, 손실 함수가 제곱 오차인 autoencoder는 PCA와 정확히 같은 부분공간을 학습한다.

즉 가장 단순한 형태의 autoencoder는 PCA 그 자체다. 이걸 알면 autoencoder의 본질이 명확해진다 — autoencoder는 PCA의 일반화다.

🌀 Autoencoder의 일반화

일반적인 autoencoder는 두 부분으로 이루어진다. Encoder는 입력을 저차원 code로 압축하고, Decoder는 그 code로부터 원본을 복원한다. 학습은 "원본과 복원의 차이"를 최소화하도록 한다.

PCA와 달리 autoencoder는 비선형 활성 함수(ReLU, sigmoid 등)와 여러 layer를 쓸 수 있다. 그 결과 PCA의 평평한 선형 부분공간을 넘어, 휘어진 면(manifold)까지 학습할 수 있다.

예를 들어 데이터가 "원 모양"으로 분포해 있다면, PCA는 그걸 평평한 직선으로만 근사할 수 있어 정보 손실이 크다. 하지만 비선형 autoencoder는 그 원의 곡선 자체를 따라가는 표현을 학습할 수 있다.

🗺️ PCA를 종이를 평평하게 편 채로 데이터의 그림자를 비추는 것에 비유할 수 있다. 그림자는 항상 평평한 면 위에만 그려진다. Autoencoder는 종이를 자유롭게 접고 휘어서, 데이터가 실제로 놓인 곡면을 따라가는 것이다. 데이터가 곡면 위에 분포해 있다면, 후자가 훨씬 자연스러운 표현을 학습한다.

⚖️ 두 모델의 trade-off

PCA의 장점

  • 닫힌 해(closed-form solution)가 있어 한 번의 행렬 계산으로 즉시 풀린다 — 학습 시간이 사실상 0.
  • 결정론적(deterministic)이라 매번 같은 결과가 나온다.
  • 주성분들이 분산 크기 순으로 자동 정렬된다 — 첫 번째 성분이 가장 중요한 방향이라는 게 명확.
  • local minimum 같은 학습 어려움이 없다.
  • 해석이 쉽다 — 각 주성분이 데이터의 어떤 방향을 나타내는지 직관적으로 본다.

PCA의 단점

  • 선형 구조만 잡을 수 있어 표현력이 제한적이다.
  • 휘어진 manifold나 복잡한 비선형 관계는 잡지 못한다.

Autoencoder의 장점

  • 비선형 활성과 여러 layer로 표현력이 매우 크다.
  • 휘어진 manifold도 학습 가능하다.
  • 깊이 쌓으면 계층적 표현(예: 이미지의 edge → texture → object)이 자동으로 형성된다.

Autoencoder의 단점

  • Gradient descent로 학습해야 하니 시간과 비용이 든다.
  • 모델이 지나치게 강력하면 그냥 입력을 그대로 외워서 출력하는 identity 함수를 학습해버릴 위험이 있다 — 압축이 무의미해진다. 이걸 막기 위해 정칙화(예: code 차원을 좁히기, sparsity 제약, denoising 등)가 필요하다.
  • local minimum, 학습 안정성 등 일반 신경망의 문제를 그대로 떠안는다.
  • 해석이 PCA만큼 명확하지 않다.

📌 정리

"PCA와 autoencoder의 차이는?"에 대한 핵심 답은 다음과 같다. PCA는 선형, autoencoder는 비선형이며, autoencoder는 PCA의 비선형 일반화다. 가장 단순한 linear autoencoder는 PCA와 같은 결과를 학습한다. 데이터에 비선형 구조가 있으면 autoencoder가 PCA보다 훨씬 풍부한 표현을 잡지만, 그 표현력의 대가로 학습 비용·해석 어려움·정칙화 필요성이 따라온다.

🎯 Model Answer (English)

Both compress the input to a low-dimensional code and reconstruct it. PCA finds the orthogonal directions of greatest variance and projects linearly onto that subspace; crucially, a one-hidden-layer autoencoder with linear activations and squared-error loss learns the same subspace as PCA, so a linear autoencoder is PCA. An autoencoder can use non-linear activations and multiple layers, so it generalises PCA from a flat linear subspace to curved manifolds, giving far greater representational power. Trade-offs: PCA has a closed-form, deterministic solution with ordered components and is easy to interpret, whereas a non-linear autoencoder is more flexible but trained by gradient descent and, if too powerful, risks simply copying the input — hence the need for regularisation (Q19).

📝 시험 답안 골격

  • 선형 AE(은닉1·선형·MSE) = PCA. 비선형 AE는 PCA의 비선형 일반화(매니폴드).
  • PCA — 선형 부분공간, 닫힌 해, 정렬된 성분, 해석 쉬움.
  • AE — 비선형·깊이로 표현력↑, 단 항등 학습 위험 → 정칙화 필요.
