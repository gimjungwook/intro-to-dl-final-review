🔁 Q10 · CNN의 평행이동 불변성(translation invariance)

What is translation invariance with CNN?

🔁 이 문제의 핵심은 두 개념을 정확히 구분하는 것 👇.

➡️ Equivariance (등가성)

  • 입력이 움직이면 출력도 같이 움직임.
  • $f(\text{Shift}(x)) = \text{Shift}(f(x))$.
  • convolution 자체의 성질.

🛡️ Invariance (불변성)

  • 입력이 움직여도 출력 그대로.
  • $f(\text{Shift}(x)) = f(x)$.
  • pooling이 더해질 때 (근사적으로) 생김.

⚠️ 흔한 오해: “CNN은 평행이동 불변”이라고 뭉뚱그리는 것. 정확히는 convolution 층은 equivariant이지 invariant가 아니다. 고양이를 오른쪽으로 옮기면 feature map의 활성도 오른쪽으로 옮겨간다(equivariance). invariance는 그 위에 pooling이 얹힐 때 생긴다 — max pooling은 한 영역에서 가장 강한 반응만 남기므로 그 영역 안에서 입력이 조금 움직여도 출력이 안 변한다 = 작은 평행이동에 대한 근사 불변성 🎯.

위젯 10입력을 밀어 보라 — 특징맵은 따라가고(등가), 풀링은 버틴다(불변)

입력의 신호 위치를 슬라이더로 옮기면, 합성곱 특징맵(가운데)의 활성도 같은 방향으로 옮겨 간다(등가성). 그러나 풀링 출력(아래)은 신호가 같은 풀링 창 안에서 움직이는 한 변하지 않는다(근사 불변성). 창을 벗어날 만큼 크게 옮기면 풀링 출력도 바뀐다 — 불변성이 “작은” 이동에만 성립함을 보여 준다.

🤔 왜 둘 다 필요? 과제가 다르기 때문 — “고양이가 어디 있나”(localization)엔 equivariance, “고양이가 있나”(classification)엔 invariance. CNN은 convolution으로 equivariance를 주고 pooling으로 invariance를 쌓아 깊어질수록 점점 더 큰 이동에 둔감해진다. 단 pooling이 주는 invariance는 국소적·근사적이고, 큰 평행이동에 대한 견고함은 parameter sharing과 깊은 pooling의 합작이다 🧩.

🎯 Model Answer (English)

The key is to distinguish two concepts. Equivariance means "when the input shifts, the output shifts the same way", $f(\text{Shift}(x)) = \text{Shift}(f(x))$ — this is what convolution itself provides. Invariance means "the output is unchanged when the input shifts", $f(\text{Shift}(x)) = f(x)$ — convolution alone does not give this. Translation invariance appears only when pooling is added: max pooling keeps the strongest response in a region, so a small shift within that region leaves the output unchanged, producing approximate invariance to small translations. Classification needs invariance ("is there a cat?"), whereas localisation needs equivariance ("where is the cat?"); a CNN supplies equivariance through convolution and stacks pooling to build up invariance, which is therefore local and only approximate.

📝 시험 답안 골격

  • 등가성(움직이면 따라감, 합성곱) vs 불변성(움직여도 그대로, 풀링)을 먼저 구분.
  • 합성곱은 등가적이지 불변이 아님. 최대 풀링이 영역 내 최강 반응만 남겨 작은 이동에 근사 불변.
  • 분류엔 불변성, 위치추정엔 등가성. 풀링 불변성은 국소·근사.
