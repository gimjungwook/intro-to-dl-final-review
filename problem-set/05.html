    데이터의 구조 그 자체가 가르침이다. 천천히 변하는 특징을 뽑고(SFA), 입력을 압축하고(오토인코더), 그 압축을 쓸모 있게 정칙화하고, 그렇게 배운 표상이 왜 분류를 돕는지, 그리고 분산 표상이 왜 그토록 강력한지를 본다.

    🐢 Q17 · 느린 특징 분석(Slow Feature Analysis, SFA)

    What is slow feature analysis (SFA)?

    SFA는 느림 원리(slowness principle)에 기반한 비지도 특징 학습 기법이다. 핵심 가정은 “환경의 중요한 고수준 특징은 원시 감각 입력보다 천천히 변한다”는 것이다.

    얼룩말이 화면을 가로질러 달릴 때, 한 픽셀의 값은 검정↔흰색을 매 순간 빠르게 오간다(줄무늬가 지나가므로). 그러나 “얼룩말이 있다”라는 사실은 여러 프레임에 걸쳐 천천히 변한다. 빠르게 진동하는 픽셀이 아니라 천천히 변하는 “얼룩말의 존재”야말로 우리가 원하는 특징이다.

    SFA는 입력의 시계열에서, 시간에 따라 가능한 한 천천히 변하는 특징 $f(x)$를 학습한다. 목적함수는 특징의 시간 변화율(제곱)을 최소화하는 것이다.

    $$ \min_{f}\ \mathbb{E}\big[(f(x_{t+1}) - f(x_t))^2\big] $$

    그냥 두면 $f$가 상수가 되어 버린다(아무것도 안 변하면 가장 느리다). 그래서 두 제약을 건다 — 평균 0, 분산 1(상수 같은 자명해 배제)과 특징 간 무상관/직교(모든 특징이 같은 느린 신호로 붕괴하는 것 방지). 그 결과 특징들이 느린 순서대로 정렬되어 나온다. 선형 SFA는 고윳값 문제로 효율적으로 풀리며, 비선형은 입력을 비선형 확장한 뒤 같은 절차를 쓴다. SFA가 학습하는 천천히 변하는 인자는 시각 피질의 복합 세포나 장소 세포 같은 불변 표현과 연결되어, “불변성을 비지도로 배운다”는 관점의 대표 예다.

    🎯 Model Answer (English)

    SFA is an unsupervised feature-learning method built on the slowness principle: the meaningful high-level features of an environment vary slowly compared with the raw sensory input — a zebra crossing the view flips a pixel rapidly between black and white, yet "a zebra is present" changes slowly. SFA learns features $f(x)$ from a time series that change as slowly as possible, minimising the squared time-derivative $\mathbb{E}[(f(x_{t+1})-f(x_t))^2]$. To rule out the trivial constant solution it imposes zero mean and unit variance, and to stop every feature collapsing onto the same slow signal it requires the features to be decorrelated/orthogonal. Linear SFA reduces to an eigenvalue problem, and the slow features it recovers correspond to invariant representations such as complex cells — a classic example of learning invariances without labels.

    📝 시험 답안 골격

    • 느림 원리 — 고수준 특징은 원시 입력보다 천천히 변함(얼룩말 픽셀 vs 존재).
    • 목적 — 시간 변화율 $\mathbb{E}[(f(x_{t+1})-f(x_t))^2]$ 최소화.
    • 제약 — 평균0·분산1(자명해 배제) + 직교(붕괴 방지). 불변 특징을 비지도로 학습.

    🪞 Q18 · 오토인코더 vs PCA

    Compare Autoencoder and PCA.

    둘 다 입력을 저차원으로 압축했다가 복원하며 데이터의 핵심 구조를 잡아낸다. 결정적 차이는 선형이냐 비선형이냐다.

    PCA는 분산이 가장 큰 직교 방향(주성분)들을 찾아 그 부분공간에 선형 투영한다. 복원도 선형이다. 핵심 사실은, 은닉층 하나에 선형 활성, 제곱오차를 쓰는 오토인코더는 PCA와 같은 부분공간을 학습한다는 것이다. 즉 선형 오토인코더 = PCA다.

    오토인코더는 인코더 $f$와 디코더 $g$에 비선형 활성과 여러 층을 둘 수 있어, PCA의 평평한 선형 부분공간을 넘어 휘어진 매니폴드(manifold)까지 학습한다. 그래서 오토인코더는 PCA의 비선형 일반화다.

    PCA

    • 선형 부분공간(평면)만.
    • 닫힌 형식 해, 결정적, 주성분이 분산 순 정렬.
    • 국소 최소 없음, 해석 쉬움. 표현력 제한.

    오토인코더

    • 비선형 매니폴드까지. 표현력 큼.
    • 경사하강 학습, 깊게 쌓기 가능.
    • 지나치게 강력하면 항등함수를 외울 위험 → 정칙화 필요(Q19).
    🎯 Model Answer (English)

    Both compress the input to a low-dimensional code and reconstruct it. PCA finds the orthogonal directions of greatest variance and projects linearly onto that subspace; crucially, a one-hidden-layer autoencoder with linear activations and squared-error loss learns the same subspace as PCA, so a linear autoencoder is PCA. An autoencoder can use non-linear activations and multiple layers, so it generalises PCA from a flat linear subspace to curved manifolds, giving far greater representational power. Trade-offs: PCA has a closed-form, deterministic solution with ordered components and is easy to interpret, whereas a non-linear autoencoder is more flexible but trained by gradient descent and, if too powerful, risks simply copying the input — hence the need for regularisation (Q19).

    📝 시험 답안 골격

    • 선형 AE(은닉1·선형·MSE) = PCA. 비선형 AE는 PCA의 비선형 일반화(매니폴드).
    • PCA — 선형 부분공간, 닫힌 해, 정렬된 성분, 해석 쉬움.
    • AE — 비선형·깊이로 표현력↑, 단 항등 학습 위험 → 정칙화 필요.

    🧹 Q19 · 정칙화된 오토인코더(regularized autoencoders)

    Why do we need regularized autoencoders and how can we make them?

    왜 필요한가. 오토인코더의 용량이 충분히 크면(특히 은닉 차원이 입력 이상인 과완전 경우, 혹은 강력한 비선형) 항등함수(identity)를 그대로 외워 입력을 출력으로 복사할 수 있다. 복원 오차는 0이지만 배운 것은 아무것도 없다. 미완전(은닉<입력) 오토인코더조차 충분히 강력하면 표본을 암기할 수 있다. 우리가 원하는 것은 “복사”가 아니라 데이터의 의미 있는 구조다. 정칙화는 복원 외의 추가 목표를 부과해, 용량과 무관하게 쓸모 있는 표현을 배우도록 강제한다.

    어떻게 만드는가. 추가 목표가 무엇이냐로 세 종류로 나뉜다.

    희소 AE은닉 활성에 벌점 $\Omega(h)=\lambda\lVert h\rVert_1$. 대부분 유닛을 0 근처로 눌러 희소·부분 기반(parts-based) 특징을 학습. 잡음 제거 AE
    (DAE)입력을 일부러 손상시켜 $\tilde{x}$를 넣고 깨끗한 $x$를 복원하게 학습. 입력이 손상돼 단순 복사가 불가능 → 데이터 매니폴드를 배워야 복원 가능. 매니폴드로 향하는 벡터장을 학습. 수축 AE
    (CAE)인코더 야코비안의 프로베니우스 노름 $\lVert \partial h/\partial x\rVert_F^2$에 벌점. 표현이 입력의 작은 변화에 둔감(수축)해져, 데이터가 놓인 방향(접선)만 민감하게 잡음.
    정칙화 없는 오토인코더는 “받아쓰기 시험에서 문제지를 그대로 베껴 내는 학생”이다. 만점이지만 이해는 0이다. 희소·잡음제거·수축 정칙화는 각각 “핵심 단어만 적어라”, “일부 글자를 지운 문제를 복원하라”, “문제가 조금 바뀌어도 같은 답을 써라”라는 추가 규칙을 걸어, 베끼기 대신 내용을 이해하게 만든다.
    🎯 Model Answer (English)

    Why: an autoencoder with enough capacity — especially an over-complete one whose hidden layer is at least as large as the input — can simply learn the identity function, copying input to output with zero reconstruction error while learning nothing useful. Regularisation imposes an additional objective beyond reconstruction so a useful representation is learned regardless of capacity. How: (1) a sparse autoencoder adds a penalty $\lambda\lVert h\rVert_1$ on the hidden activations, forcing most units to zero and learning parts-based features; (2) a denoising autoencoder corrupts the input and trains the network to reconstruct the clean version, so copying is impossible and it must learn the data manifold; (3) a contractive autoencoder penalises the Frobenius norm of the encoder's Jacobian $\lVert\partial h/\partial x\rVert_F^2$, making the code insensitive to small input changes and sensitive only along the manifold.

    📝 시험 답안 골격

    • 필요 이유 — 용량 큰 AE는 항등함수를 외워 복사만 함(배움 0). 복원 외 목표를 부과해야 유용 표현.
    • 희소 — 은닉에 $L_1$ 벌점(부분 기반). 잡음제거(DAE) — 손상입력→깨끗복원(매니폴드 학습).
    • 수축(CAE) — 야코비안 노름 벌점으로 입력 변화에 둔감(접선만 민감).

    🧭 Q20 · 비지도 학습이 다운스트림 과제를 돕는 이유

    Why is unsupervised learning helpful for the downstream tasks like classification?

    핵심 가정은 “입력 분포 $p(x)$의 구조가 $p(y\mid x)$에 대한 정보를 담고 있다”는 것이다. 분류하려는 라벨 $y$를 만들어 내는 변동 인자(factors of variation)는, 입력 $x$의 분포 모양을 결정하는 인자와 상당 부분 겹친다.

    구체적으로, 같은 클래스의 예제들은 입력 공간에서 군집을 이루거나 같은 매니폴드 위에 놓인다. 비지도 학습은 라벨 없이도 이 군집·매니폴드·변동 인자를 발견해, $x$의 좋은 표현(잘 분리되고 매끄러운)을 만든다. 그 표현 공간에서는 분류 경계가 단순해져, 더 적은 라벨로 학습되고 더 잘 일반화된다.

    실용적으로 두 방식으로 쓰인다. ① 사전훈련/초기화 — 대량의 비라벨 데이터로 표현을 먼저 배워 좋은 초기값(정칙화 효과, 유리한 수렴 분지)으로 삼고 작은 라벨로 미세조정. ② 준지도 학습 — 표현을 지도·비지도 과제가 공유. 예로 언어모델(비지도)로 배운 단어 임베딩이 다운스트림 자연어 과제를 돕고, 오토인코더가 배운 에지·질감이 시각 분류를 돕는다.

    단, 만능은 아니다. 이 도움은 비지도로 배운 특징이 실제로 $y$와 관련 있을 때만 성립한다. $p(x)$의 구조와 $p(y\mid x)$가 무관하면(예: 라벨이 입력의 사소한 측면에만 의존) 비지도 사전훈련은 도움이 안 되거나 해로울 수 있다.

    🎯 Model Answer (English)

    The core assumption is that the structure of the input distribution $p(x)$ carries information about $p(y\mid x)$: the factors of variation that shape $p(x)$ overlap substantially with the factors we want to predict. Examples of one class cluster together or lie on a shared manifold, and unsupervised learning discovers these clusters, manifolds and factors without labels, producing a good representation of $x$ in which the decision boundary becomes simple — so the downstream classifier needs fewer labels and generalises better. In practice it is used as pre-training/initialisation (learn from abundant unlabelled data, then fine-tune) or as semi-supervised shared representations, e.g. word embeddings from a language model or edges and textures from an autoencoder. The caveat: it helps only when the unsupervised features are actually relevant to $y$ — if $p(x)$ and $p(y\mid x)$ are unrelated, it may not help.

    📝 시험 답안 골격

    • 핵심 — $p(x)$의 구조가 $p(y|x)$의 정보를 담음. 군집/매니폴드/변동 인자가 라벨과 겹침.
    • 비지도가 좋은 표현 발견 → 표현 공간에서 분류 단순, 적은 라벨로 일반화.
    • 사전훈련/초기화 + 준지도. 예 단어 임베딩·오토인코더 특징. 단 $p(x)$가 $y$와 관련될 때만.

    🌈 Q21 · 분산 표상(distributed representation) — compact vs sparse

    What is distributed representation? Why is it so important in deep learning? Compare compact and sparse representations.

    분산 표상이란, 하나의 개념을 여러 유닛에 걸친 활성 패턴으로 나타내고, 동시에 각 유닛이 여러 개념을 표현하는 데 참여하는 방식이다. 반대는 국소(local)/원-핫 표상 — 한 개념당 한 유닛이 전담한다.

    왜 중요한가. 표현력이 지수적이기 때문이다. $n$개의 이진 특징은 서로 다른 패턴으로 최대 $2^n$개의 영역(구성)을 구별할 수 있다. 국소 표상은 $n$개 유닛으로 $n$개 개념밖에 구별 못 한다. 이 지수적 격차가 일반화의 원천이다 — 특징이 개념들 사이에서 재사용되므로, “빨강+자동차”와 “파랑+트럭”을 본 적 있으면 본 적 없는 “빨강+트럭”으로 일반화한다. $O(n)$개의 파라미터로 $O(2^n)$개의 영역을 기술하는 통계적 효율이 딥러닝이 적은 데이터로도 일반화하는 핵심 이유다.

    위젯 21같은 n개 유닛 — 국소는 n개, 분산은 2ⁿ개를 구별한다

    유닛 수 n을 키워 보라. 국소 표상이 구별하는 개념 수(파랑)는 n으로 선형으로 늘지만, 분산 표상의 구별 수(빨강)는 $2^n$으로 폭증한다. n=20이면 국소는 20개, 분산은 100만 개를 넘는다.

    세 모드 비교. 얼마나 많은 유닛이 동시에 켜지는가로 나뉜다.

    국소 (one-hot)

    • 정확히 1개 유닛만 활성.
    • $n$개로 $n$개념. 일반화·재사용 없음.
    • 가장 해석 쉬움.

    조밀(compact) 분산

    • 많은 유닛이 동시 활성.
    • 용량 최대 $2^n$. 통계적 효율 최고.
    • 해석 어렵고 특징이 얽힐(entangled) 수 있음.

    희소(sparse) 분산은 그 중간이다 — $n$개 중 소수 $k$개만 켜진다. 용량은 $\binom{n}{k}$로 여전히 매우 크면서, 활성 유닛이 적어 해석과 분리(disentangle)가 쉽고, 잡음에 강하며, 에너지 효율적이다(생물학적 뇌와도 닮았다). 정리하면, 국소는 단순함, 조밀 분산은 최대 용량, 희소 분산은 용량과 해석성·강건성 사이의 균형을 준다.

    🎯 Model Answer (English)

    A distributed representation encodes a concept as a pattern of activity over many units, with each unit helping to represent many concepts; the opposite is a local (one-hot) representation, one unit per concept. It matters because its capacity is exponential: $n$ binary features can distinguish up to $2^n$ regions, whereas $n$ local units distinguish only $n$. This is the source of generalisation — features are reused across concepts, so having seen "red car" and "blue truck" the model generalises to an unseen "red truck" — and the statistical efficiency ($O(n)$ parameters describing $O(2^n)$ regions) behind deep learning. Comparing the modes: local (exactly one unit active; $n$ concepts; no reuse; most interpretable), dense/compact distributed (many units active; capacity up to $2^n$; maximal efficiency but entangled and hard to interpret), and sparse distributed ($k$ of $n$ active; capacity $\binom{n}{k}$ still huge, but more interpretable, robust, and energy-efficient) — a trade-off between capacity, interpretability, and robustness.

    📝 시험 답안 골격

    • 분산 표상 — 개념=여러 유닛의 패턴, 각 유닛=여러 개념에 참여. 반대 = 국소/원-핫.
    • 중요성 — $n$ 특징 → $2^n$ 영역, 특징 재사용 → 미관측 조합으로 일반화. $O(n)$ 파라미터로 $O(2^n)$ 기술.
    • 비교 — 국소(1개, 해석 쉬움) / 조밀(다수, 용량 최대, 얽힘) / 희소($k$개, 용량 크면서 해석·강건).
