🎯 Q23 · RBF 네트워크와 적대적 예제 면역

Describe radial basis function networks. And discuss why it does not have the adversarial example issue.

📌 질문 해석

두 갈래 질문 — ① RBF network가 무엇인지 기술하고, ② 왜 adversarial example에 강한지 논하라. 구조와 robust 이유를 연결해야 한다.

🎯 이 질문은 두 부분이다. 먼저 RBF 네트워크가 어떤 모델인지 이해하고, 그 다음 왜 적대적 예제(Q22)에 강한지를 그 구조와 연결해 설명해야 한다.

📖 RBF Network란

RBF(Radial Basis Function, 방사 기저 함수) 네트워크는 일반적인 신경망과 작동 원리가 다른 특수한 모델이다. 핵심 아이디어는 다음과 같다 — 은닉층의 각 뉴런이 "중심점(center)"이라 부르는 특정 입력 위치 근처에서만 강하게 활성화된다는 것이다.

구체적으로, 각 RBF 뉴런은 입력 x와 그 뉴런의 중심점 사이의 거리를 측정한다. 거리가 가까우면 뉴런이 강하게 (예: 거의 1로) 활성화된다. 거리가 멀어지면 활성값이 가우시안 곡선을 따라 빠르게 0으로 떨어진다.

예를 들어 한 RBF 뉴런의 중심이 "전형적인 강아지 이미지"라면, 그 뉴런은 강아지 같은 이미지에서 강하게 활성화되고, 자동차나 풍경 이미지에서는 거의 0이 된다. 각 뉴런이 입력 공간의 특정 "구역" 하나를 담당하는 셈이다.

최종 출력은 모든 RBF 뉴런의 활성값에 가중치를 곱해 합한 형태로 만들어진다.

🆚 일반 신경망과의 결정적 차이

ReLU나 sigmoid 같은 일반적인 뉴런과 RBF 뉴런의 차이를 명확히 이해해야 한다.

일반 뉴런: 입력에 가중치를 곱한 합 (선형 결합)을 계산한 뒤 활성 함수를 적용한다. 입력이 어느 방향으로 가든, 가중치 방향과 같으면 활성이 무한정 커지고 반대면 작아진다. 즉 입력 공간 전체에 걸쳐 선형적으로 반응한다 — 어디서든 계속 반응한다.

RBF 뉴런: 입력과 중심점 사이의 거리를 본다. 거리가 어떤 방향으로든 일정 이상 멀어지면 즉시 0으로 포화(saturate)된다. 즉 중심점 근처의 좁은 영역에서만 반응한다 — 그 외 영역에서는 거의 반응하지 않는다.

🛡️ 왜 적대적 예제에 강한가

이제 핵심 질문 — RBF가 왜 적대적 예제에 면역에 가까운가?

Q22에서 본 적대적 예제의 원리를 다시 떠올려보자. 적대적 예제는 고차원에서의 선형성 누적을 활용한다. 픽셀 하나당 변화는 작지만 수만 차원에 걸쳐 같은 공격 방향으로 모두 더해지면 출력이 크게 흔들린다.

이 공격이 작동하려면 "입력의 작은 변화가 출력의 큰 변화로 누적되는 선형 경로"가 필요하다. 일반 신경망은 piecewise linear 구조라 이런 경로가 풍부하게 존재한다.

RBF는 정반대다. RBF 뉴런은 입력이 중심에서 어느 방향으로든 멀어지면 활성값이 줄어든다. 적대적 섭동을 더하면 입력이 중심에서 더 멀어지니, 활성값은 오히려 작아진다. "누적이 작동할 선형 경로 자체가 존재하지 않는다"는 게 핵심이다.

섭동이 어느 방향이든 입력은 결국 중심에서 멀어진다. RBF 뉴런은 "이 입력은 내가 아는 영역에서 멀어요"라고 답하며 0에 가깝게 꺼진다. 적대적 공격이 의도한 "잘못된 클래스로 high confidence 출력"을 만들 방법이 없다.

🎤 일반 뉴런을 무지향성(omnidirectional) 마이크에 비유해보자. 어느 방향에서 와도 소리에 반응한다. 사방의 작은 잡음들이 합쳐져 큰 소리로 인식될 수 있다 — 이게 적대적 공격의 원리다. RBF 뉴런은 특정 지점에서만 듣는 지향성(unidirectional) 마이크다. 그 지점이 아닌 방향의 잡음은 아무리 합쳐도 마이크에 들어오지 않는다. 적대적 섭동이 입력을 그 "특정 지점" 밖으로 밀어내면, RBF는 그 신호 자체를 받지 못한다.

🤷 결과: "나는 모른다"라고 답하는 모델

RBF 네트워크의 한 가지 흥미로운 특성은 훈련 데이터 근처에서만 high confidence로 분류하고, 그 외 영역에서는 모든 클래스에 낮은 확신을 보인다는 점이다. 즉 익숙한 입력은 자신 있게 분류하지만, 처음 보는 종류의 입력은 사실상 "나는 잘 모른다"라고 답한다.

적대적 예제는 결국 모델을 훈련 데이터에서 멀리 미는 입력이다. 일반 신경망은 그 먼 영역에서도 (선형 외삽으로) 자신 있게 답하지만, RBF는 그곳에서 모든 클래스에 낮은 확신을 주기에 적대적 공격이 의도한 "고확신 오분류"가 불가능하다. 자연스럽게 적대적 입력을 거부하는 셈이다.

⚖️ Trade-off: Robustness vs Accuracy

그렇다면 모든 모델을 RBF로 만들면 안전한 거 아닌가? 그렇지 않다. RBF에는 큰 대가가 따른다.

1) 좁은 영역만 커버 — 각 RBF 뉴런이 작은 구역만 담당하니, 입력 공간 전체를 커버하려면 매우 많은 뉴런이 필요하다. 고차원 입력(예: 이미지)에서는 차원의 저주로 필요한 뉴런 수가 폭증한다.

2) 학습 어려움 — RBF 뉴런의 활성이 좁은 영역에서만 0이 아니라, gradient가 대부분의 영역에서 거의 0이다. Gradient descent가 작동하기 어렵다.

3) 일반화 능력 부족 — 본 적 없는 입력에 대해 보수적으로 "모른다"고 답하니, 새로운 데이터에 대한 일반화 성능이 일반 신경망보다 약하다.

그래서 Goodfellow가 지적했듯, RBF는 강건하지만 정확도가 낮다. 이게 robustness–accuracy trade-off의 교과서적 예다. 일반 신경망의 강한 일반화 능력은 곧 선형성에서 오는 것이며, 그 선형성이 적대적 취약성도 함께 만든다. 한쪽을 얻으려면 다른 쪽을 일부 잃어야 한다.

📌 정리

"왜 RBF는 적대적 예제 문제가 없나?"에 대한 답은 다음과 같다. RBF 뉴런은 중심에서 멀어지면 즉시 포화돼 0이 되는 비선형 구조라, 적대적 공격이 활용하는 "선형성 누적 경로"가 존재하지 않는다. 어느 방향으로 섭동을 가해도 활성이 줄어들 뿐 커지지 않는다. 대신 좁은 영역 커버, 학습 어려움, 약한 일반화라는 대가를 지불한다 — robustness와 accuracy의 trade-off다.

🎯 Model Answer (English)

A radial basis function (RBF) network has hidden units that respond to the distance from a prototype centre $\mu_i$: $h_i(x) = \exp(-\beta_i\lVert x - \mu_i\rVert^2)$. Each unit fires only near its centre and saturates to zero far away. It resists adversarial examples precisely because it is not linear: there is no linear path along which tiny per-dimension perturbations can accumulate into a large response — moving the input in any direction merely takes it further from the centre and lowers the activation. As a result the network is confident only near the training data and effectively reports "I don't know" elsewhere, so adversarial inputs are rejected with low confidence. The cost is lower accuracy and harder training — a clear robustness–accuracy trade-off.

📝 시험 답안 골격

  • RBF 유닛 — 중심점으로부터의 거리에 가우시안으로 반응, 멀면 0으로 포화. 입력 공간의 좁은 영역만 담당.
  • 적대적 면역 이유 — 선형 누적 경로가 없음. 섭동은 입력을 중심에서 멀어지게 해 응답을 오히려 줄임. 데이터 근처에서만 고확신.
  • 트레이드오프 — 강건하지만 학습 어렵고 정확도/일반화가 낮음.
