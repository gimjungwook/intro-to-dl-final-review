🌈 Q21 · 분산 표상(distributed representation) — compact vs sparse

What is distributed representation? Why is it so important in deep learning? Compare compact and sparse representations.

📌 질문 해석

세 갈래 — ① distributed representation이 무엇인지, ② 왜 그렇게 중요한지 (n개 유닛으로 2의 n제곱 영역 표현), ③ compact vs sparse 비교.

🌈 이 질문은 딥러닝 표현 학습의 가장 핵심적인 개념을 다룬다. 신경망이 왜 그토록 강력한지, 왜 적은 데이터로도 본 적 없는 새로운 상황에 일반화할 수 있는지의 근본 이유가 여기에 있다.

📖 Distributed Representation이란

분산 표상(distributed representation)은 두 가지 특징을 동시에 갖는 표현 방식이다.

1) 하나의 개념을 여러 유닛(뉴런)에 걸친 활성화 패턴으로 표현한다. "강아지"라는 개념이 단 하나의 뉴런에 저장되는 게 아니라, 수십 또는 수백 개 뉴런의 활성 패턴 전체로 표현된다.

예를 들어 "강아지" = (뉴런1=0.8, 뉴런2=0.3, 뉴런3=0.9, …, 뉴런100=0.6)이라는 패턴이다. 단일 위치가 아니라 패턴 전체가 개념을 담는다.

2) 각 유닛은 여러 개념의 표현에 동시에 참여한다. 뉴런 1번이 강아지에서도 활성화되고, 고양이에서도 어느 정도 활성화되고, 사자에서도 약간 활성화될 수 있다. 한 뉴런이 어떤 추상적 특징(예: "털이 있다", "네 발이다")을 잡고, 여러 개념이 그 특징을 공유한다.

이것의 반대는 local representation 또는 one-hot 표현이다. 한 개념당 정확히 한 유닛이 할당되어, 강아지 = (1, 0, 0, …), 고양이 = (0, 1, 0, …) 같은 형태다.

💥 왜 그렇게 중요한가: 지수적 표현력

분산 표상이 딥러닝의 본질적 강점인 이유는 표현력이 지수적으로 증가한다는 사실에 있다.

유닛이 n개 있다고 하자. 각 유닛이 켜짐(1) 또는 꺼짐(0) 두 상태를 갖는다면, n개 유닛의 활성화 패턴은 최대 2의 n제곱가지 서로 다른 패턴이 가능하다. 즉 n개 유닛으로 최대 2^n 개의 서로 다른 영역을 구별할 수 있다.

n = 10이면 1,024개 영역, n = 20이면 100만 개 영역, n = 100이면 우주의 입자 수보다 많은 영역을 구별 가능하다.

반면 local representation은 n개 유닛으로 단 n개 개념만 구별 가능하다 — 한 유닛당 한 개념이니까. n = 100이라도 100개 개념이 한계다.

🌟 일반화의 본질: 특징 재사용

이 지수적 격차가 단순한 용량 차이를 넘어 일반화(generalization)의 근본 원천이 되는 이유가 있다. 분산 표상에서는 같은 특징이 여러 개념 사이에서 재사용되기 때문이다.

구체적인 예를 보자. 자동차를 색깔(빨강, 파랑, …)과 종류(승용차, 트럭, …)로 표현한다고 하자.

분산 표상이라면 색깔과 종류를 별개 차원으로 표현한다. 학습 중에 "빨간 승용차"와 "파란 트럭"만 본 적이 있다고 해도, 모델은 "빨강"과 "트럭"이라는 특징을 각각 분리해서 학습했다. 따라서 본 적 없는 "빨간 트럭"이라는 조합도 자연스럽게 표현 가능하다 — 빨강 차원 활성 + 트럭 차원 활성으로.

이게 일반화의 본질이다. 본 적 없는 새로운 조합에 모델이 합리적인 예측을 할 수 있다. 데이터가 무한히 많지 않아도, 본 조합들로부터 학습한 특징들이 새로운 조합으로 자연스럽게 재조합되어 작동한다.

Local representation이라면 이게 불가능하다. "빨간 승용차"용 뉴런과 "파란 트럭"용 뉴런은 독립적이고, "빨간 트럭"이라는 새 조합은 새 뉴런이 따로 학습해야 한다 — 데이터 없이는 불가능하다.

📊 통계적 효율

분산 표상이 가진 또 다른 강력한 측면은 통계적 효율(statistical efficiency)이다. n개 파라미터로 2^n 개 영역을 기술할 수 있으니, 학습할 파라미터 수에 비해 표현 가능한 개념의 수가 지수적으로 많다.

이게 딥러닝이 비교적 적은 데이터로도 강력한 일반화 능력을 보이는 근본 이유 중 하나다. 학습할 파라미터 수에 비해 표현 공간이 훨씬 크니, 데이터에서 추출한 정보가 효율적으로 압축되어 저장된다.

위젯 21같은 n개 유닛 — 국소는 n개, 분산은 2ⁿ개를 구별한다

유닛 수 n을 키워 보라. 국소 표상이 구별하는 개념 수(파랑)는 n으로 선형으로 늘지만, 분산 표상의 구별 수(빨강)는 2의 n제곱으로 폭증한다. n=20이면 국소는 20개, 분산은 100만 개를 넘는다.

🎛️ 세 가지 표상 모드 비교

"분산 표상"이라고 해도 한 가지가 아니다. 한 번에 몇 개 유닛이 동시에 활성화되느냐에 따라 세 가지 모드로 나뉘며, 각각 trade-off가 다르다.

📍 Local (one-hot)

  • 정확히 1개 유닛만 활성.
  • n개 유닛으로 n개 개념만 표현 가능.
  • 특징 재사용 없음, 일반화 능력 매우 제한적.
  • 가장 해석 쉬움 ("뉴런 5번 = 강아지" 같은 일대일 매핑).

🧊 Dense Distributed (조밀 분산)

  • 많은 유닛이 동시에 활성.
  • 표현 가능한 개념 수가 최대 2^n까지 — 최고 용량.
  • 통계적 효율 최고.
  • 해석이 매우 어렵고, 특징이 서로 얽혀(entangled) 한 뉴런의 의미를 분리하기 힘듦.

🎯 Sparse Distributed (희소 분산)

두 극단 사이의 절충안이다. n개 유닛 중 소수의 k개(예: 5~10%)만 활성화되도록 강제한다. 용량은 여전히 매우 크다 — n개 중 k개를 선택하는 경우의 수만큼 표현 가능하니, n=100, k=5라면 약 7천5백만 개 영역을 구별할 수 있다.

장점이 여럿이다.

  • 해석 가능성: 활성 유닛이 적으니 어떤 유닛이 어떤 의미를 가지는지 파악하기 쉽다.
  • Disentanglement: 특징이 더 잘 분리된 형태로 학습된다. 한 유닛이 한 가지 명확한 특징(예: 부분, 속성)을 담당하는 경향.
  • 강건성(robustness): 활성 유닛이 적으니 일부 유닛에 잡음이 들어가도 전체 표현이 크게 흔들리지 않는다.
  • 에너지 효율: 활성 뉴런이 적으니 계산 비용도 적게 든다.
  • 생물학적 유사성: 실제 뇌에서도 동시에 활성화되는 뉴런은 전체의 1~5% 정도라고 알려져 있다. 희소 분산 표상이 자연 시스템과 잘 맞는 형태다.

📌 세 모드의 한 줄 요약

  • Local = 단순함과 해석 쉬움. 하지만 용량 작고 일반화 안 됨.
  • Dense Distributed = 최대 용량과 통계적 효율. 하지만 해석 어렵고 특징 얽힘.
  • Sparse Distributed = 용량 + 해석성 + 강건성의 균형. 생물학적 뇌와도 유사.

실제 딥러닝에서는 hidden layer가 어떤 활성 함수를 쓰느냐, 어떤 정칙화가 걸리느냐에 따라 이 스펙트럼의 어딘가에 위치한다. ReLU 같은 활성 함수는 자연스럽게 약간의 sparsity를 유도하고, L1 정칙화나 sparse autoencoder의 sparsity 벌점은 명시적으로 sparse distributed 형태로 끌어당긴다.

🎯 Model Answer (English)

A distributed representation encodes a concept as a pattern of activity over many units, with each unit helping to represent many concepts; the opposite is a local (one-hot) representation, one unit per concept. It matters because its capacity is exponential: n binary features can distinguish up to 2 to the n regions, whereas n local units distinguish only n. This is the source of generalisation — features are reused across concepts, so having seen "red car" and "blue truck" the model generalises to an unseen "red truck" — and the statistical efficiency (linearly many parameters describing exponentially many regions) behind deep learning. Comparing the modes: local (exactly one unit active; n concepts; no reuse; most interpretable), dense/compact distributed (many units active; capacity up to 2 to the n; maximal efficiency but entangled and hard to interpret), and sparse distributed (k of n active; capacity is the number of ways to choose k from n — still huge, but more interpretable, robust, and energy-efficient) — a trade-off between capacity, interpretability, and robustness.

📝 시험 답안 골격

  • 분산 표상 — 개념=여러 유닛의 패턴, 각 유닛=여러 개념에 참여. 반대 = 국소/원-핫.
  • 중요성 — n개 특징으로 2^n 개 영역 구별 가능, 특징 재사용으로 본 적 없는 조합에 일반화. n개 파라미터로 2^n 개 영역을 기술하는 통계적 효율.
  • 비교 — 국소(1개 활성, 해석 쉬움, 용량 작음) / 조밀(다수 활성, 용량 최대, 특징 얽힘) / 희소(k개 활성, 용량 크면서 해석·강건성·생물학적 유사).
