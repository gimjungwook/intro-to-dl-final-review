🧪 Q3 · 데이터 측면의 정칙화 트릭

As regularization, what kind of tricks can we take regarding data? (pretraining with unlabeled data, data augmentation, noise injection, etc.)

📌 질문 해석

“정칙화로서 데이터에 관해 쓸 수 있는 트릭은?” 괄호의 힌트(pretraining, augmentation, noise)대로 데이터 측 기법을 갈래별로 묶고 왜 통하는지 설명하라는 뜻.

🧪 "데이터로 거는 정칙화"의 공통 원리는 단순하다 — 모델이 보는 학습 분포를 더 넓고 현실적으로 만들어, 좁은 표본을 통째로 외우는 일을 막는 것이다. 모델 자체에는 손대지 않고 입력·라벨 쪽을 손봐서 같은 효과를 얻는다.

1️⃣ Data Augmentation (데이터 증강)

이미지 한 장에서 여러 장을 만들어내는 가장 직관적인 방법이다. 원본 이미지를 살짝 회전시키거나, 좌우로 뒤집거나, 일부를 잘라내거나, 색조를 바꾸어 변형판을 생성한다. 핵심 조건은 라벨이 변하지 않는 변환만 써야 한다는 것이다 — 강아지 이미지는 회전시켜도 여전히 강아지여야 한다.

이렇게 만들면 모델은 같은 강아지를 다양한 각도·위치·색조로 보게 된다. "강아지라는 개념은 회전·이동·색조에 영향받지 않는다"는 invariance(불변성)를 데이터로 직접 가르치는 셈이다. 효과가 가장 큰 영역은 이미지 분류와 객체 인식이다.

주의할 함정: 의미를 바꾸는 변환은 절대 금물이다. 손글씨 숫자를 좌우 반전하면 6은 9가 되고, 알파벳 b는 d가 된다. 이런 변환을 쓰면 모델은 잘못된 invariance를 배운다. 따라서 augmentation은 항상 task별로 "어떤 변환이 라벨을 보존하는가?"를 먼저 정의한 뒤 적용해야 한다.

2️⃣ Noise Injection (잡음 주입)

일부러 데이터나 모델 내부에 잡음을 섞어, 모델이 특정 입력 값에 과도하게 의존하지 못하게 만드는 방법이다. 잡음을 어디에 주입하느냐에 따라 네 가지로 나뉜다.

입력에 주입 — 입력 이미지에 약간의 픽셀 노이즈를 더한다. 모델이 "정확히 이 픽셀 값"이 아니라 "그 근처 어디든" 같은 답을 내도록 강제하니, 작은 변동에 강건해진다. 사실상 데이터 augmentation의 한 형태로 볼 수 있고, 가중치 벌점(L2)과도 비슷한 효과를 낸다.

은닉층에 주입(Dropout) — 가장 강력한 잡음 정칙화. 학습 중 매 step마다 hidden layer의 뉴런 절반 정도를 무작위로 꺼버린다. 다음 step에서는 또 다른 뉴런이 꺼진다. 결과적으로 매번 다른 모양의 작은 sub-network가 학습되고, 추론 때 전체 network를 쓰면 그 모든 sub-network의 평균에 가까운 예측을 내게 된다 — 즉 암묵적 앙상블이다. 한 뉴런이 다른 뉴런에 의존하는 co-adaptation도 차단되어 표현이 더 robust해진다.

가중치에 주입 — 학습 중 가중치 자체에 작은 잡음을 더한다. 가중치가 약간만 흔들려도 손실이 크게 바뀌는 sharp minimum 대신, 가중치가 흔들려도 손실이 안정적인 flat minimum을 모델이 선호하게 된다. 일반적으로 flat minimum이 새 데이터에 더 잘 일반화된다.

라벨에 주입(Label smoothing) — 정답을 100% 확신(예: 강아지 = 1.0, 나머지 = 0.0)이 아니라 약간 흐리게 (강아지 = 0.9, 나머지에 0.1 분산) 만든다. 라벨에도 잡음이 있음을 인정하고 softmax가 과도하게 확신하지 않게 만든다. Calibration이 좋아지고 과적합도 줄어든다.

3️⃣ Unsupervised / Semi-supervised Pretraining (비지도·반지도 사전훈련)

라벨은 비싸지만 라벨 없는 데이터는 흔하다. 인터넷의 수십억 장 이미지나 수백억 단어 텍스트는 라벨이 없어도 그 자체로 풍부한 정보를 담고 있다. 사전훈련은 이 풍부한 비라벨 데이터로 먼저 "표현"을 학습한 뒤, 작은 라벨 데이터로 특정 task를 학습한다.

예를 들어 BERT는 인터넷의 텍스트로 "문장에서 일부 단어를 가리고 그게 뭐였는지 맞히기" 같은 self-supervised 과제로 사전훈련된다. 라벨이 필요 없으니 데이터가 사실상 무한대다. 이렇게 배운 일반 언어 표현 위에 우리는 작은 labeled 데이터로 "감정 분류"나 "의학 텍스트 분류" 같은 특정 task만 추가 학습하면 된다. Autoencoder도 같은 원리로 이미지·텍스트의 구조를 비지도로 먼저 학습한다.

이 접근이 통하는 이유는 입력 분포 자체에 풍부한 구조가 있기 때문이다. 같은 클래스의 예제들은 입력 공간에서 한 군데에 뭉쳐 있거나 같은 곡면(manifold) 위에 놓이는 경향이 있는데, 이 구조를 비지도로 미리 배워두면 분류 경계를 그리기가 훨씬 쉬워진다. "이 입력은 이런 모양으로 분포해 있다"는 지식이 "이 입력의 라벨은 무엇인가?"를 푸는 데 prior로 작용한다.

📚 세 트릭은 모두 "시험 범위를 넓게 공부시키는 법"이다. 증강은 같은 문제를 여러 각도에서 풀게 하기, 잡음 주입은 흐릿한 문제로도 답을 내게 하기, 사전훈련은 시험 전에 기초 교양부터 폭넓게 쌓아두기. 셋 모두 모델이 "기출만 외우는" 식의 과적합을 막는다는 점에서 같은 목표를 공유한다.
🎯 Model Answer (English)

These tricks regularise by making the model see a broader, more realistic input distribution so it cannot simply memorise the small training set. (1) Data augmentation generates new labelled examples through label-preserving transforms — translation, rotation, scaling, cropping, flips, colour jitter — which teaches the model known invariances, but the transform must never change the meaning (a horizontal flip ruins digit recognition by swapping 6 and 9). (2) Noise injection adds noise to inputs (close to an L2 penalty), to hidden units (dropout), to weights (favouring flat, robust minima), or to labels (label smoothing, which prevents an over-confident softmax). (3) Unsupervised or semi-supervised pre-training learns structure from abundant unlabelled data and transfers it as a prior or initialisation for the supervised task.

📝 시험 답안 골격

  • 공통 원리 — 모델이 학습 분포를 더 넓게 보게 해 표본 암기를 막음.
  • 증강(라벨 보존 변환, 불변성 주입) · 노이즈(입력·은닉=드롭아웃·가중치·라벨=평활) · 비라벨 사전훈련/전이.
  • 증강은 의미를 바꾸지 않는 변환만, 입력 잡음은 L2 효과, 사전훈련은 입력 분포의 구조 지식을 분류 task의 prior로 전이.
