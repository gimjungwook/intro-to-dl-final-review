    예상 출제 7문제 (Q&A)

    각 문제를 클릭하면 답이 펼쳐진다. 답을 보기 전에 30초씩 머릿속으로 답해보고 펼쳐라.

    Q1학습을 T·P·E로 설명할 때, 한 축이라도 빠지면 무엇이 모호해지는가? +
    → Sec.1 학습 알고리즘의 정의 T가 빠지면 "무엇을 학습하는가"가 정의되지 않아 같은 데이터로도 분류기·회귀기·군집기 중 어느 것을 만드는지 모름. P가 빠지면 "잘했다"의 기준이 없어 손실 함수가 정해지지 않음. E가 빠지면 알고리즘이 무엇을 보고 학습하는지 모르고, 지도/비지도/강화 구분도 안 됨. 셋이 모두 정해져야 학습이라는 동사가 의미 있게 적용된다.
    Q2훈련 오차가 0이지만 좋은 모델이 아닐 수 있는 이유는? +
    → Sec.2 용량·과적합·과소적합 머신러닝의 목표는 훈련 데이터 암기가 아니라 일반화. 충분히 큰 모델은 항상 훈련 데이터를 100% 외울 수 있지만, 그 모델은 데이터의 잡음까지 따라가서 새 데이터에서는 무너진다. 일반화 격차(시험 오차 − 훈련 오차)가 클수록 외운 모델. 시험에서 묻는 핵심은 "훈련 오차 = 0인데 일반화 격차가 크다 = 과적합"이라는 진단.
    Q3편향-분산 분해식을 적고, 모델 용량을 키울 때 각 항이 어떻게 변하는가? +
    → Sec.3 편향-분산 분해 $$ \mathbb{E}[(y - \hat{f})^2] = \mathrm{Bias}^2 + \mathrm{Variance} + \sigma^2 $$ 용량↑ → 편향² ↓ (모델이 더 다양한 함수를 표현 가능) → 분산 ↑ (데이터 잡음까지 따라감) → 잡음 σ²은 그대로. 총 오차는 U자 곡선. 최적 용량은 그 골짜기.
    Q4왜 우도 L(θ) 최대화 = −log L(θ) 최소화인가? +
    → Sec.4 MLE (1) 로그는 단조증가 함수이므로 $\arg\max L = \arg\max \log L$. (2) 부호를 뒤집어 최대화를 최소화로 바꾸어도 해는 같음. 추가로 곱 → 합 변환이 수치적으로 안정 (underflow 방지). 두 변환 모두 답 보존, 다만 미분/구현이 쉬워짐.
    Q5회귀 문제에 MSE를 쓰는 것은 어떤 분포 가정의 MLE인가? +
    → Sec.4 MLE 출력에 평균 $f(x;\theta)$, 분산 $\sigma^2$인 가우시안 잡음을 가정한 경우의 MLE. NLL을 풀어 적으면 $\sum (y_i - f(x_i;\theta))^2 / (2\sigma^2) + \text{상수}$가 나오는데, 이는 정확히 MSE의 스케일된 형태. 분류에서 교차 엔트로피 = 베르누이/카테고리 가정 MLE도 같은 원리.
    Q6L2 정칙화가 가우시안 사전의 MAP이 되는 이유를 한 줄로 설명하라. +
    → Sec.6 정칙화 가중치 $w$에 평균 0, 분산 $\tau^2$의 가우시안 사전을 주면 $\log p(w) = -\sum w_i^2/(2\tau^2) + \text{상수}$. MAP는 $\arg\max[\log p(x|w) + \log p(w)]$이므로, NLL에 $\frac{1}{2\tau^2}\sum w_i^2 = \lambda \|w\|_2^2$ 항이 더해진다. 이것이 L2 정칙화. 사전이 강할수록(τ 작을수록) λ가 크다.
    Q7검증셋(validation)과 시험셋(test)을 왜 구분해야 하는가? 한 셋으로 둘 다 하면 무슨 문제? +
    → Sec.2 용량·과적합 하이퍼파라미터(학습률, 정칙화 계수, 모델 차수)를 검증셋에서 고른다. 그 과정에서 검증셋에 대한 간접 과적합이 일어남 (선택 자체가 데이터에 맞추는 행위). 시험셋을 검증으로 쓰면 시험 점수가 낙관적으로 부풀려져 실제 배포 성능을 과대평가. 그래서 시험셋은 한 번만 보고, 그 점수는 수정 불가. 데이터 쪼개기: 보통 6:2:2 또는 7:1.5:1.5.

    핵심 수식 7개 (한 페이지 컨닝쪽지)

    이름수식
    일반화 격차 $E_{\text{gen}} = E_{\text{test}} - E_{\text{train}}$. 작을수록 일반화.
    편향-분산 분해 $\mathbb{E}[(y-\hat{f})^2] = \mathrm{Bias}^2 + \mathrm{Var} + \sigma^2$
    MLE $\theta_{\text{MLE}} = \arg\max_\theta \prod_i p(x_i|\theta) = \arg\min_\theta \big[-\sum_i \log p(x_i|\theta)\big]$
    베이즈 정리 $p(\theta|x) \propto p(x|\theta)\, p(\theta)$. 사후 ∝ 우도 × 사전.
    MAP $\theta_{\text{MAP}} = \arg\max_\theta [\log p(x|\theta) + \log p(\theta)]$. 사전 로그가 정칙화 항.
    L2 정칙화 $J(w) = \mathrm{NLL}(w) + \lambda \|w\|_2^2$, $\lambda = 1/(2\tau^2)$. 가우시안 사전 MAP.
    L1 정칙화 $J(w) = \mathrm{NLL}(w) + \lambda \|w\|_1$. 라플라스 사전 MAP, 희소해 유도.

    k-NN 위젯 — 용량을 거꾸로 조절하는 모형

    k-Nearest Neighbors는 매개변수가 따로 없는 모형이다. 그러나 하이퍼파라미터 $k$가 모델 용량을 거꾸로 조절한다. $k=1$이면 가장 가까운 한 점의 라벨을 그대로 따르는 매우 유연한 모델 (용량↑, 분산↑, 편향↓). $k$를 크게 하면 평균이 평활해져 용량↓, 분산↓, 편향↑. 5장의 모든 개념(용량·편향-분산)이 단 하나의 슬라이더로 시각화된다.

    위젯 01k-NN 결정 경계 — k가 용량을 거꾸로 조절

    k=1은 경계가 들쭉날쭉(잡음 점들도 다 외움). k가 클수록 경계가 부드러워지지만 두 클래스를 가르는 미세 구조가 사라진다. 시험 직출 가능: "k가 작을 때와 클 때의 편향·분산 변화를 설명하라."
