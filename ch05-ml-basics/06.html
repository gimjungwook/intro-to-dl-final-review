Section 06 · 데이터 크기와 모델 크기의 시점

    학습 곡선

    데이터 크기 N이 늘어날 때 훈련 오차와 검증 오차가 각각 어떻게 움직이는지를 한 그래프에 그린 것이 학습 곡선이다. 이 곡선의 모양 하나로 "데이터를 더 모을지 모델을 다시 짤지"를 결정할 수 있다.

    앞 장에서 모델 복잡도를 고정한 채 데이터 크기 $N$을 바꿔 가며 그린 곡선이 학습 곡선이다. 이 곡선은 두 가지를 동시에 보여준다. 가로축은 $N$, 세로축은 오차이며, 두 곡선이 함께 그려진다. 하나는 훈련 오차 — 모델이 본 $N$개의 데이터에 대한 평균 손실 — 이고, 다른 하나는 검증 오차 — 모델이 보지 않은 별도의 데이터에 대한 평균 손실 — 이다. 두 곡선의 모양과 그 사이의 간격(일반화 갭, generalization gap)이 모델 진단의 핵심 정보가 된다.

    왜 데이터 크기에 따라 두 오차가 다르게 움직일까. $N$이 매우 작을 때를 떠올려 보자. 데이터 점이 3개라면 어떤 합리적인 모델이라도 그 3개를 거의 완벽히 통과시킬 수 있다. 그래서 훈련 오차는 거의 0에 가깝다. 그러나 3개의 점으로 학습한 모델은 새로운 점에 대해 정확하게 예측하지 못한다. 결과적으로 검증 오차는 매우 크다. $N$이 커질수록 모델이 데이터를 완벽히 통과시키기 어려워진다(점이 너무 많아 동시에 만족시키지 못한다). 그래서 훈련 오차는 점진적으로 증가한다. 동시에 모델이 진짜 패턴에 가까운 함수를 더 잘 잡게 되므로 검증 오차는 감소한다. 두 곡선은 결국 서로 가까워지고, 충분히 큰 $N$에서는 거의 수렴한다.

    학습 곡선의 진단 패턴

    학습 곡선의 모양은 모델의 상태에 따라 네 가지 전형적 패턴을 보인다. 첫째, 두 곡선이 모두 높은 곳에서 수렴하면 편향 문제(과소적합)다. 데이터를 아무리 더 모아도 두 오차 모두 낮아지지 않는다. 모델 자체가 진짜 패턴을 표현하지 못하므로, 처방은 모델을 키우거나 더 좋은 특징을 만드는 일이다. 둘째, 훈련 오차는 낮지만 검증 오차가 훨씬 위쪽에서 떠 있으면 분산 문제(과적합)다. 두 곡선 사이에 큰 간격이 있고, 데이터를 더 모으면 그 간격이 줄어들 가능성이 보인다. 처방은 데이터를 더 모으거나, 정칙화를 강화하거나, 모델을 줄이는 일이다.

    셋째, 두 곡선이 모두 충분히 낮고 거의 만나면 잘 학습된 상태다. 더 모을 데이터의 한계 효용이 낮으므로 다른 자원(설명력, 추론 속도 등)에 투자하는 편이 낫다. 넷째, 검증 오차가 처음에는 감소하다가 어느 지점부터 다시 증가하면 학습이 너무 길어진 상태(epoch 단위 과적합)다. 이 경우 학습 곡선과 별개로 epoch별 검증 오차 곡선을 보고 조기 종료(early stopping)를 적용해야 한다. 학습 곡선은 모델 진단의 가장 신뢰할 수 있는 도구 중 하나이며, 실무에서 가장 먼저 그려야 할 그래프다.

    일반화 갭의 정량적 해석

    학습 곡선의 두 곡선 사이 간격, 즉 일반화 갭(generalization gap)은 $\text{train error}(N)$과 $\text{validation error}(N)$의 차이다. 이 갭이 작으면 모델이 훈련 데이터에 특별히 더 잘 들어맞는 것이 아니라는 뜻이고, 따라서 보지 못한 데이터에 대해서도 비슷한 성능을 보일 것이라는 합리적 기대를 할 수 있다. 갭이 크면 모델이 훈련 데이터에 과도하게 적합한 상태다. PAC 학습 이론은 이 갭의 크기에 대한 확률적 상한을 데이터 크기 $N$, 가설 공간의 복잡도 $\text{VC}(\mathcal{H})$, 신뢰 수준 $\delta$의 함수로 제공한다. 직관적으로는 "복잡도가 크면 갭이 크고, 데이터가 많으면 갭이 작다"는 관계가 핵심이다.

    딥러닝에서 흥미로운 점은 일반화 갭이 이론적 상한보다 훨씬 작게 관측된다는 것이다. 신경망의 매개변수 수는 데이터 크기보다 훨씬 크지만 갭은 폭발하지 않는다. 이 현상은 신경망에 내재된 암묵적 정칙화(implicit regularization), 학습 알고리즘이 선호하는 평탄한 최소점(flat minimum), 또는 다른 미지의 메커니즘 때문이라고 추정된다. 5장에서는 고전적 그림을 그리는 데 집중하고, 딥러닝 특유의 일반화 미스터리는 7-8장에서 다시 등장한다.

    위젯 06학습 곡선 — 데이터 크기 N과 두 오차의 움직임

    N 슬라이더를 움직이면 훈련 오차(파랑)는 위로, 검증 오차(주황)는 아래로 향하며 점차 가까워진다. 그 사이의 색칠된 영역이 일반화 갭이다. N이 충분히 크면 갭이 0에 가까워지고, 두 곡선이 닿는 수준이 모델의 진짜 한계(편향 + 잡음)다.

    스케일링 법칙 — 학습 곡선이 거듭제곱을 따른다

    최근 딥러닝 연구에서 학습 곡선이 거듭제곱 법칙(power law)을 따른다는 관찰이 자주 보고된다. 즉 데이터 크기 $N$, 모델 크기 $M$, 컴퓨팅 자원 $C$가 늘어남에 따라 일반화 오차는 대략 $\text{error} \propto N^{-\alpha}$ 또는 $\text{error} \propto M^{-\beta}$의 형태로 감소한다는 것이다. $\alpha, \beta$는 보통 0.05에서 0.3 사이의 값이고, 이 지수가 작을수록 데이터를 더 많이 모아야 같은 개선을 얻는다. 이를 신경망의 스케일링 법칙(scaling laws)이라 한다. 대규모 언어 모델의 발전이 이 법칙에 기반해 자원 투자를 정당화한다.

    스케일링 법칙의 실용적 함의는 분명하다. 모델의 일반화 오차가 충분히 낮지 않다면, 같은 모델을 더 크게 만들기보다 데이터를 두 배로 늘리는 편이 종종 더 효율적이다. 반대로 데이터가 더 늘릴 수 없는 상한에 다다른 상황이라면 모델 구조를 바꾸는 편이 낫다. 학습 곡선을 그려서 곡선의 기울기가 0에 가까워지는지(데이터 한계) 아니면 여전히 떨어지고 있는지(데이터를 더 모으면 도움)를 보는 것이 이 결정의 출발점이다.

    학습 곡선을 그릴 때 주의할 점

    학습 곡선을 그릴 때 흔히 빠지는 함정 몇 가지를 짚어 두자. 첫째, 데이터 크기 $N$을 늘릴 때 같은 분포에서 추가로 뽑아야 한다. 새로운 출처의 데이터가 섞이면 분포 변화(distribution shift) 효과와 데이터 크기 효과가 뒤섞여 곡선이 깨끗하지 않다. 둘째, 작은 $N$에서는 표본 변동이 크므로 같은 $N$에서 여러 번 무작위로 부분집합을 뽑아 평균을 취해야 의미 있는 곡선이 나온다. 한 번만 뽑으면 곡선이 들쭉날쭉할 수 있다. 셋째, 검증 오차와 시험 오차는 정확히 구분해야 한다. 학습 곡선의 두 번째 곡선으로는 검증 오차를 쓰는 편이 좋고, 시험 오차는 학습 과정 끝의 단 한 번에만 측정한다. 이 구분은 다음 장에서 자세히 다룬다.

    학습 곡선을 운동 능력의 기록에 비유해 보자. 같은 사람이 매주 같은 종목으로 시험을 친다. 처음에는 연습 점수는 들쭉날쭉하고 시험 점수는 낮다. 연습량이 늘수록 연습 점수는 점점 안정되고 약간 낮아지며(완벽하게 외우지 못하므로), 시험 점수는 점점 올라온다. 두 점수가 같은 수준으로 수렴하는 지점이 이 사람의 진짜 실력이다. 더 연습한다고 그 수준 이상으로 올라가지는 않는다. 학습 곡선이 알려주는 정보가 정확히 이것이다.

    다음 장에서는 학습 곡선을 그리기 위해 데이터를 어떻게 나누는지 — 훈련·검증·테스트의 분할과 교차검증의 의미 — 를 본다. 데이터 분할은 단순한 사무 작업이 아니라, 일반화 오차를 정직하게 측정하기 위한 통계적 약속이다.
