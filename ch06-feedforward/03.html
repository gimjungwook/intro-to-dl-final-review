Sub 03 · 비선형성의 종류와 트레이드오프

    활성화 함수 —
    ReLU가 이긴 이유

    시그모이드는 왜 깊은 망에서 무너졌나. ReLU는 왜 단순한데도 강한가. 활성화 함수의 미분이 곧 학습 가능성이다.

    이전 절에서 “비선형 활성 $g$가 없으면 깊이가 무의미해진다”를 짧게 짚었다. 이 절은 그 $g$의 선택이 어떻게 학습 가능성을 좌우하는지 정밀하게 본다. 활성화 함수의 미분이 곧 역전파의 흐름 속도다. 그래서 활성화 함수를 잘못 고르면, 같은 데이터·같은 가중치라도 학습이 멈춰 버린다.

    먼저 “왜 비선형이 필수인가”를 다시 못 박기

    층을 두 개 쌓되 활성화 함수가 선형(또는 없음)이라고 해보자.

    $$ \mathbf{h} = W^{(1)} \mathbf{x} + \mathbf{b}^{(1)}, \qquad \mathbf{y} = W^{(2)} \mathbf{h} + \mathbf{b}^{(2)} $$

    대입하면 $\mathbf{y} = W^{(2)} W^{(1)} \mathbf{x} + (W^{(2)} \mathbf{b}^{(1)} + \mathbf{b}^{(2)})$이다. 새로운 행렬 $W' = W^{(2)} W^{(1)}$과 새로운 편향으로 다시 쓰면 그냥 하나의 선형 변환이다. 100층을 쌓아도 결과는 같다.

    그래서 비선형 활성화는 “장식”이 아니라 깊이가 의미를 가지게 만드는 접착제다. 직선들의 합성이 다시 직선이 되지 않게 막아 주는 꺾임이다.

    고전적 선택지: sigmoid와 tanh

    $$ \sigma(z) = \frac{1}{1 + e^{-z}}, \qquad \tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}} $$

    1980-90년대에는 시그모이드(sigmoid)와 tanh가 표준이었다. 둘 다 부드러운 S자 곡선이고, 모든 점에서 미분 가능하다. 시그모이드는 $(0, 1)$ 사이로, tanh는 $(-1, 1)$ 사이로 출력을 누른다.

    그런데 이 두 함수에는 치명적인 문제가 있다. 입력이 크거나 작아지면 미분값이 0에 가까워진다. 시그모이드의 미분 최댓값은 0.25에 불과하고, 입력이 ±4만 넘어가도 미분은 사실상 0이다. 이를 포화(saturation)라고 부른다.

    경사가 거의 0에 가까운 평지 위의 공을 떠올려 보자. 어디로 굴려야 더 낮은 곳으로 갈지 알 수 없다. 기울기가 0이면 학습 신호도 0이다. 시그모이드의 양 끝은 그런 평지다. 입력이 그쪽 영역에 들어가면 모델은 “여기서 어디로 가야 할지” 알 수가 없다.

    ReLU — 단순함이 이긴 이유

    $$ \text{ReLU}(z) = \max(0, z) $$

    ReLU(Rectified Linear Unit)는 “음수면 0, 양수면 그대로”라는 한 줄짜리 함수다. 너무 단순해서 처음에는 “이게 진짜로 잘 될까?” 하는 의심을 받았다. 그런데 2012년 AlexNet 이후 ReLU가 사실상 표준이 되었다. 이유가 세 가지다.

    1. 양수 구간에서 미분이 정확히 1 — 기울기가 죽지 않는다. 깊은 망을 통과해도 신호가 보존된다.
    2. 계산이 극단적으로 가볍다 — 비교 한 번. 시그모이드의 지수 함수보다 수십 배 빠르다.
    3. 희소성(sparsity) — 음수 입력은 모두 0이 되므로, 자연스럽게 “관련 없는 뉴런을 끄는” 효과가 생긴다.

    물론 그림자도 있다. “죽은 ReLU(Dead ReLU)” 문제다. 학습 중에 어떤 뉴런이 한 번 모든 입력에서 음수만 받게 되면, 그 뉴런은 미분이 0이 되어 다시는 학습되지 않는다. 영원히 0만 출력하는 좀비 뉴런이 된다. 이 문제를 완화하기 위해 음수 구간에 작은 기울기를 두는 변종들이 나왔다.

    ReLU의 변종들 — 음수 구간을 조금 살리기

    • Leaky ReLU: 음수에서 기울기 0.1로 작게 통과. $f(z) = z$ if $z > 0$ else $0.1z$. 죽은 ReLU 완화.
    • PReLU (Parametric ReLU): Leaky의 “0.1” 자리를 학습 가능한 파라미터로 둠. 데이터가 알아서 최적의 음수 기울기를 찾음.
    • ELU (Exponential Linear Unit): 음수에서 부드럽게 $-1$로 수렴. 출력 평균이 0 근처에 머물러 학습 안정성이 높아짐.
    • GELU (Gaussian Error Linear Unit): BERT, GPT의 표준. 음수도 살짝 통과시키되 확률적으로 부드럽게 누른다. ReLU의 “꺾임”이 둥글어진 형태.
    • Maxout: 활성화 함수 자체의 형태를 학습. 여러 선형 함수의 max를 출력으로 사용. ReLU/Leaky/PReLU를 모두 특수 경우로 포함.

    아래 위젯에서 직접 비교하기

    위젯에서 활성화 함수를 골라 그래프를 보고, 마우스로 곡선 위를 움직이면 그 점에서의 함수값과 미분값이 표시된다. 다른 활성화 함수들은 회색으로 배경에 깔려 비교가 쉽다. 점선은 도함수다.

    특히 sigmoid를 선택하고 마우스를 $|z| > 3$ 영역으로 옮겨 보라. 함수값은 거의 0이나 1로 들러붙고, 도함수는 0.01 이하로 떨어진다. ReLU를 선택하면 양수 구간 어디서나 도함수가 정확히 1이다.

    위젯 02활성화 함수 — 그래프, 미분, 트레이드오프

    실선은 활성화 함수, 점선은 그 도함수. 마우스로 호버하면 그 점의 (z, f, f′)이 표시된다. sigmoid·tanh는 양 끝에서 도함수가 0으로 무너지는 반면, ReLU는 양수 구간 어디서나 도함수가 1로 유지된다.

    비교 표 — 한눈에 보기

    함수장점단점주 사용처
    sigmoid 출력이 확률 해석 가능 (0, 1). 미분 형태 단순. 양 끝 포화 → 기울기 소실. 출력 평균이 0이 아님. 이진 분류 출력층 (은닉층 X)
    tanh 0 중심 → sigmoid보다 학습 안정. 여전히 양 끝 포화. 깊은 망에서 한계. RNN의 은닉(과거), 일부 LSTM 게이트
    ReLU 양수 기울기 1로 보존. 계산 가벼움. 희소성. 음수 구간 죽음 (Dead ReLU). 출력 평균 0 아님. CNN/MLP 은닉층 기본 선택
    Leaky ReLU 죽은 ReLU 완화. ReLU의 모든 장점 유지. 음수 기울기 값을 직접 골라야 함 (보통 0.01-0.1). 학습 불안정 시 대체
    ELU 음수에서 부드러움. 출력 평균 0 근처. 지수 계산 → ReLU보다 무거움. 학습 안정성 우선 시
    GELU Transformer에서 검증된 성능. 부드러운 꺾임. 구현 복잡 (정확한 형태는 가우시안 CDF 기반). BERT, GPT, Transformer 계열
    Maxout 활성화 형태 자체를 학습. 파라미터 수 k배 증가. 특수 목적, 연구

    기울기 소실(Vanishing Gradient) — 직접 보기

    왜 sigmoid가 깊은 망에서 무너졌는지, 두 번째 위젯에서 정량적으로 본다. 깊이 $L$의 망에서 같은 활성화 함수를 통과시키면서 각 층의 기울기 크기 $|g_l|$을 추적한다. sigmoid의 미분 최댓값이 0.25이므로, $L$층을 통과한 후 기울기는 최악의 경우 $0.25^L$로 줄어든다. $L=10$이면 약 $10^{-6}$. 학습 신호가 사실상 0이 된다.

    슬라이더로 $L$을 1에서 20까지 늘려 보고, 활성화 함수를 sigmoid → tanh → ReLU로 바꿔 보라. sigmoid는 $L=8$만 되어도 마지막 층 기울기가 1e-3 이하로 떨어지는 반면, ReLU는 양수 영역에서 1을 그대로 유지한다.

    위젯 03Vanishing Gradient — 깊이별 기울기 크기

    막대는 각 층의 기울기 크기. 빨강은 1e-3 이하 (사실상 0). 같은 z = 1.0에서 sigmoid는 6-8층만 통과해도 학습 신호가 사라지지만, ReLU는 양수 영역에서 기울기를 보존한다. 이것이 “ReLU 이후 깊은 망이 가능해졌다”의 정량적 의미다.

    이 절이 잡아 준 그림

    • 비선형 활성은 필수다. 없으면 깊이가 의미를 잃는다.
    • sigmoid·tanh는 양 끝 포화로 깊은 망에서 무너진다. 미분이 0에 가까워지면 학습 신호가 사라진다.
    • ReLU의 강점 = 양수 구간 기울기 1. 깊은 망을 통과해도 신호가 보존된다.
    • ReLU의 약점 = 죽은 뉴런. Leaky/PReLU/ELU/GELU가 그 그림자를 부분적으로 해결한다.
    • 출력층은 별개다. 은닉층은 ReLU 계열, 출력층은 과업에 맞춰 sigmoid/softmax/linear를 쓴다. 이 짝짓기는 다음 절에서.
