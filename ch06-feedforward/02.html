Sub 02 · 한 방향으로 흐르는 함수의 구조

    다층 퍼셉트론(MLP) —
    깊이가 가능하게 하는 것

    은닉층 하나는 입력을 새 좌표계로 옮기는 행렬 곱과 비선형 꺾임의 합성이다. 깊이는 그 합성을 여러 번 반복하는 일이다.

    이전 절에서 “은닉층은 새 좌표계다”라는 그림을 잡았다. 이 절은 그 그림을 수식과 구조로 다시 그린다. 즉 다층 퍼셉트론(multilayer perceptron, MLP)이라는 기계의 내부를 들여다본다.

    피드포워드 신경망 — 한 방향으로 흐르는 함수

    피드포워드 신경망(feedforward neural network)은 입력 $\mathbf{x}$를 출력 $\mathbf{y}$로 보내는 매핑 $\mathbf{y} = f(\mathbf{x}; \boldsymbol{\theta})$를 학습한다. 여기서 “feedforward”라는 이름은 정보가 입력에서 출력으로 한 방향으로만 흐른다는 뜻이다. 어떤 시점의 출력이 다음 시점의 입력으로 돌아가는 순환(feedback) 연결이 없다. 그래서 같은 입력은 항상 같은 출력을 낸다.

    공장의 일방통행 컨베이어 벨트를 떠올려 보자. 원자재(입력)가 한쪽 끝에서 들어오면, 자르고, 조립하고, 칠하고, 포장하는 단계(은닉층)를 차례로 거쳐 완성품(출력)이 다른 쪽으로 나온다. 어느 단계의 결과를 앞 단계로 되돌리지 않는다. 이것이 피드포워드다. 반면 같은 자재를 일부 다시 입력으로 보내는 공장은 순환 신경망(RNN)에 가깝다 — 그건 10장에서 다룬다.

    한 층 = 행렬 곱 + 비선형 활성

    층(layer) 하나가 하는 일은 두 단계로 쪼개진다. 첫째, 아핀 변환(affine transformation) — 입력 벡터에 가중치 행렬을 곱하고 편향을 더한다. 둘째, 비선형 활성(nonlinear activation) — 각 성분에 ReLU 같은 꺾임을 적용한다.

    $$ \mathbf{h}^{(l)} = g\!\left(W^{(l)} \mathbf{h}^{(l-1)} + \mathbf{b}^{(l)}\right) $$

    l번째 층의 출력 = (가중치 곱 + 편향) → 비선형 함수 g.

    각 기호를 풀어 보면 이렇다.

    $\mathbf{h}^{(l-1)}$이전 층의 출력 (또는 $l=1$이면 입력 $\mathbf{x}$)
    $W^{(l)}$가중치 행렬. 행 = 새 좌표축의 개수, 열 = 이전 좌표축의 개수
    $\mathbf{b}^{(l)}$편향 벡터. 좌표축을 평행 이동
    $g$비선형 활성(ReLU 등). 그것이 없으면 전체가 선형으로 붕괴
    $\mathbf{h}^{(l)}$새 좌표계에서의 표현

    가중치 행렬은 “회전·축척·반사”의 합성이다

    가중치 행렬 $W$를 그냥 “숫자들의 표”로 보지 말고 기하학적 변환으로 보자. 선형대수의 SVD(특이값 분해)로 보면 임의의 행렬 $W$는 “회전 → 축척(scaling) → 회전” 세 단계의 합성이다. 즉 가중치 행렬은 입력 공간을 회전시키고, 어떤 방향은 늘리고 어떤 방향은 줄인 뒤, 다시 회전시키는 일을 한다.

    이 변환에 편향 벡터를 더하면 평행 이동이 추가된다. 그래서 $W\mathbf{x} + \mathbf{b}$는 “회전 + 늘이기 + 회전 + 평행 이동” — 일반적인 아핀 변환이다. 평행 이동이 없으면 항상 원점을 지나야 해서 표현력이 떨어진다. 그래서 편향 b는 단순한 부록이 아니라 필수 자유도다.

    그 위에 비선형 활성 $g$가 들어가면, 직선들이 꺾인다. 이전 절의 XOR 예에서 본 것처럼, ReLU의 꺾임이 들어가는 순간 “접힌 종이”처럼 공간을 접을 수 있게 된다. 여기서 “접는다”는 표현은 비유가 아니라 실제 기하다 — ReLU는 입력 공간을 두 개의 반평면(half-plane)으로 나눠, 한쪽은 그대로 두고 다른 쪽은 0으로 눌러 접는다.

    2-2-1 MLP를 행렬로 적기

    이전 절의 XOR MLP를 행렬로 다시 적어 보자. 입력 $\mathbf{x} = (x_1, x_2)$, 은닉 2개, 출력 1개.

    $$ \mathbf{h} = \text{ReLU}\!\left( W^{(1)} \mathbf{x} + \mathbf{b}^{(1)} \right), \qquad \hat y = \sigma\!\left( \mathbf{w}^{(2)\top} \mathbf{h} + b^{(2)} \right) $$

    은닉층은 ReLU, 출력층은 시그모이드(이진 분류).

    구체적 형태
    은닉층 가중치 W⁽¹⁾ — 2×2 행렬, 편향 b⁽¹⁾ — 2×1 벡터
    W⁽¹⁾ = [[1, 1], [1, 1]], b⁽¹⁾ = [-0.5, -1.5]
    출력층 가중치 w⁽²⁾ — 2×1 벡터, 편향 b⁽²⁾ — 스칼라
    w⁽²⁾ = [1, -2], b⁽²⁾ = -0.3

    입력 $(x_1, x_2) = (1, 0)$을 통과시키면 이렇게 흐른다.

    1. $W^{(1)} \mathbf{x} + \mathbf{b}^{(1)} = (1+0-0.5,\ 1+0-1.5) = (0.5, -1)$
    2. ReLU → $\mathbf{h} = (0.5, 0)$
    3. $\mathbf{w}^{(2)\top} \mathbf{h} + b^{(2)} = 1 \cdot 0.5 + (-2)\cdot 0 - 0.3 = 0.2$
    4. 시그모이드(0.2) ≈ 0.55 → 양성

    은닉 두 유닛이 같은 OR-like 합을 쓰지만 편향이 달라서, 하나는 “하나 이상 켜진 경우(OR)”에 반응하고 다른 하나는 “둘 다 켜진 경우(AND)”에 반응한다. 출력은 OR − 2·AND 형태가 되어 정확히 XOR을 흉내낸다. 이런 “OR과 AND의 차이로 XOR” 구성은 6장에서 가장 자주 나오는 미니 예제다.

    왜 다이어그램을 “레이어”로 그리는가

    피드포워드 신경망은 흔히 다음과 같이 그려진다.

    입력 — 데이터가 들어오는 자리 은닉 — 새 좌표계의 축 출력 — 답을 내는 자리

    이 그림이 잡아 주는 것은 두 가지다. 첫째, 각 층 안의 뉴런은 같은 종류의 일을 한다. 그래서 “행렬 한 줄”로 표현할 수 있다. 둘째, 층 사이에는 명확한 순서가 있고, 같은 층 안에서는 병렬이다. 이 사실이 GPU 가속을 가능하게 한다 — 한 층의 모든 뉴런을 한 번의 행렬 곱으로 계산할 수 있기 때문이다.

    은닉층은 “직접 감독되지 않는 표현 공간”이다

    출력층은 정답 데이터와 직접 연결된다. 모델이 무엇을 출력해야 하는지가 분명하다. 그런데 은닉층은 다르다. 데이터가 “첫 번째 은닉 뉴런은 반드시 에지(edge)를 검출하라” 같은 지시를 내려주지 않는다. 그래서 hidden — 숨겨진 층이라고 부른다.

    여기서 “숨겨진”의 의미를 정확히 잡는 것이 중요하다. 은닉층의 활성값은 충분히 읽을 수 있다. 우리가 어떤 입력을 넣었을 때 각 은닉 뉴런이 얼마나 켜졌는지는 코드 한 줄로 출력 가능하다. “숨겨졌다”는 말은 접근 불가능하다는 뜻이 아니라, 직접 감독되는 목표가 없다는 뜻이다.

    이 특성이 딥러닝의 힘과 약점을 동시에 만든다. 힘은 — 모델이 정답을 맞히기 위해 중간 표현을 스스로 조직한다는 점. 이미지에서는 얕은 층이 에지/코너/질감을 잡고, 깊은 층이 부분 구조와 객체 개념을 잡는 경향이 나타난다. 텍스트에서는 단어 관계, 어순, 문맥적 역할이 점차 정리된다.

    약점은 — 이 과정이 사람의 의미 라벨과 정확히 일치하지 않기 때문에 해석이 어렵다는 점. 학습된 모델 안에서 “여기 이 뉴런은 정확히 무엇을 검출하는가?”를 사람의 말로 옮기는 것은 별도의 연구 분야가 되어 있다(설명가능 AI, mechanistic interpretability). 학습 가능성과 해석 가능성은 분리된 문제다.

    층을 쌓는다 = 함수를 합성한다

    이제 깊이로 가자. 두 층짜리 MLP는 함수의 합성으로 적힌다.

    $$ f(\mathbf{x}) = f^{(3)}\!\left( f^{(2)}\!\left( f^{(1)}(\mathbf{x}) \right) \right) $$

    f⁽¹⁾, f⁽²⁾, f⁽³⁾가 차례로 적용된다. 각 단계가 “아핀 + 비선형”.

    왜 합성인가? 한 층의 출력이 다음 층의 입력이기 때문이다. 합성 함수 $f \circ g$의 깊이가 깊다는 것은 “단계적으로 정제”된다는 뜻이다. 1층은 거친 좌표 변환을, 2층은 그 위에서 다시 좌표를 정리하고, 3층은 또 그 위에서 다시 정리한다.

    이미지를 흑백 변환 → 윤곽 추출 → 다각형 단순화 → 도형 인식으로 순차 처리하는 파이프라인을 생각해 보자. 각 단계는 앞 단계의 출력을 입력으로 받아 더 추상적인 표현으로 바꾼다. 깊이가 깊다는 건 이런 파이프라인의 단계 수가 많다는 것이고, 각 단계가 단순할수록 전체는 더 효율적으로 학습된다.

    이 단계적 합성이 왜 강력한지는 6절(만능 근사 정리)에서 더 자세히 다룬다. 핵심만 미리 말해 두면 — 얕은 모델이 같은 함수를 흉내내려면 지수적으로 더 많은 뉴런이 필요할 수 있다. 깊이는 “표현의 재사용”을 가능하게 한다.

    이 절이 잡아 준 그림

    • 한 층 = 행렬 곱(아핀) + 비선형 활성. 두 단계의 합성.
    • 가중치 행렬은 회전·축척·반사의 합성, 즉 좌표 변환.
    • 편향은 평행 이동. 원점에 묶이지 않게 해주는 필수 자유도.
    • 은닉층은 직접 감독되지 않는 새 좌표계. 모델이 스스로 구성.
    • 깊이 = 함수의 합성. 표현이 단계적으로 정제됨.

    다음 절에서는 “비선형 활성 $g$가 왜 그렇게 중요한가”를 더 정밀하게 본다. ReLU, sigmoid, tanh의 차이가 학습 가능성에 어떻게 영향을 미치는지가 핵심이다.
