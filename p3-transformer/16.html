    예상 문제 27선

    Q01 · 개념
    RNN의 두 가지 구조적 한계를 한 문장씩 설명하라.
    (1) 병렬화 불가 — $h_t$가 $h_{t-1}$에 의존하므로 GPU가 한 step씩만 처리 가능. (2) 장거리 의존성 약화 — 같은 가중치 $W_h$가 시퀀스 길이만큼 거듭 곱해져 그래디언트가 0이나 무한대로 발산.
    RNN한계
    Q02 · 직관
    Attention의 핵심 직관을 “가중평균”이라는 단어로 설명하라.
    시퀀스의 한 토큰이 다음 표현을 만들 때, 다른 모든 토큰의 정보를 “관련도에 따라 가중평균”한 것이 attention. 모든 토큰을 동등하게 보는 게 아니라 “어디 얼마나” 볼지를 정하는 분포가 attention 가중치.
    Attention직관
    Q03 · 비유
    Q, K, V를 도서관 검색 비유로 설명하라.
    Query = 내가 찾는 주제(검색어). Key = 각 책의 표지·색인(검색 가능한 인덱스). Value = 책의 본문(실제 가져올 내용). Query와 Key의 유사도가 가중치가 되고, 그 가중치로 Value들을 가중평균한 게 attention 출력.
    QKV비유
    Q04 · 수식
    Scaled Dot-Product Attention의 수식을 정확히 적고 각 단계의 의미를 설명하라.
    $\text{Attention}(Q, K, V) = \text{softmax}(QK^\top / \sqrt{d_k}) V$. $QK^\top$ = 모든 query-key 쌍의 내적(점수). $/\sqrt{d_k}$ = 차원 의존 분산 폭발 방지. softmax = 점수를 확률 분포로. $\cdot V$ = 분포로 Value를 가중합.
    Scaled Dot-Product수식
    Q05 · 수식
    왜 $\sqrt{d_k}$로 나누는가? 만약 나누지 않으면 무슨 일이 생기는가?
    독립인 두 $d_k$차원 벡터의 내적은 분산이 $d_k$로 커진다. $d_k$가 클수록 점수의 분산이 커져 softmax 입력 중 한 값이 매우 크면 softmax 출력이 “한 곳에 거의 1, 나머지는 거의 0”이 된다. 이 상태에서 softmax 미분(자코비안)이 거의 0이 되어 학습이 멈춘다(vanishing gradient). $\sqrt{d_k}$로 나누면 분산이 1로 정규화되어 softmax가 적당히 “부드러운” 분포를 유지.
    스케일링분산
    Q06 · 개념
    Self-Attention과 Cross-Attention의 차이는?
    Self-Attention: Q, K, V가 모두 같은 시퀀스에서 나옴(예: 인코더 입력 또는 디코더 출력). 시퀀스 내부 토큰들 간 관계 학습. Cross-Attention: Q는 디코더 시퀀스, K·V는 인코더 출력. 디코더가 입력 시퀀스의 어디를 참조할지 학습.
    Self-AttnCross-Attn
    Q07 · 개념
    Multi-Head Attention이 단일 헤드보다 강한 이유 두 가지를 설명하라.
    (1) 한 종류 관계만 잡는 단일 attention과 달리, 헤드들이 서로 다른 관계(구문·의미·위치)를 병렬로 학습 가능. (2) $d_{model}$을 $h$개로 나눠도 파라미터 수는 동일하지만, 작은 차원의 attention 여러 개가 큰 차원 attention 하나보다 표현 다양성이 높음.
    Multi-Head표현력
    Q08 · 수식
    Multi-Head Attention의 수식을 적어라.
    $\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h) W^O$ 이때 $\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$. $W^O \in \mathbb{R}^{h d_v \times d_{model}}$는 마지막 “출력 사영”.
    Multi-Head수식
    Q09 · 차원
    $d_{model} = 512, h = 8$일 때, 한 헤드의 $d_k$와 전체 파라미터 수를 단일 헤드($d_k = 512$) 경우와 비교하라.
    한 헤드 $d_k = d_v = d_{model}/h = 64$. Multi-head 전체 파라미터: $h \cdot (3 \cdot d_{model} \cdot d_k) + d_{model} \cdot d_{model} = 8(3 \cdot 512 \cdot 64) + 512 \cdot 512 = 786{,}432 + 262{,}144 = 1{,}048{,}576$. 단일 헤드($d_k = 512$, $W^Q,W^K,W^V,W^O$ 모두 $512\times512$)도 정확히 같은 $1{,}048{,}576$. 파라미터 수 동일.
    차원 계산파라미터
    Q10 · 개념
    왜 Attention만 쓰면 시퀀스 순서를 알 수 없는가?
    Attention 식은 토큰의 “집합”에 대한 가중합으로, 토큰 위치 인덱스 $j$가 식 안에 들어가지 않는다. 입력 시퀀스의 순서를 바꾸면 출력 시퀀스도 같은 순서로 바뀔 뿐, 본질적인 계산 결과는 같다(permutation equivariance). 자연어에서 순서는 의미에 결정적이므로 별도의 위치 정보 주입이 필요.
    PE순서
    Q11 · 수식
    Positional Encoding의 sin·cos 수식을 적고, 차원에 따라 주기가 어떻게 변하는지 설명하라.
    $\text{PE}(pos, 2i) = \sin(pos/10000^{2i/d_{model}})$, $\text{PE}(pos, 2i+1) = \cos(pos/10000^{2i/d_{model}})$. $i$가 클수록 분모 $10000^{2i/d_{model}}$가 커져 sin·cos의 주기가 길어진다. 낮은 차원은 짧은 주기로 빠른 변화 → 인접 위치 구분. 높은 차원은 긴 주기로 느린 변화 → 멀리 떨어진 위치 구분.
    PEsin/cos
    Q12 · 개념
    함수형 PE(sin·cos)와 학습형 PE(learned embedding)의 장단점을 비교하라.
    함수형: 길이 일반화에 강함, 추가 파라미터 0, 위치 차이가 선형 변환으로 표현 가능. 단점은 데이터에 맞춰 미세 조정 불가. 학습형: 데이터에 맞춰 학습되어 성능이 약간 더 좋을 수 있음. 단점은 학습 시 본 최대 길이를 초과한 위치를 처리 못함, 추가 파라미터 필요.
    PE비교
    Q13 · 개념
    Encoder 블록의 sub-layer 두 개를 적고 각 역할을 설명하라.
    (1) Multi-Head Self-Attention — 위치 간 정보 교환. 각 토큰이 다른 토큰들의 정보를 가중합으로 흡수. (2) Feed-Forward Network — 위치별 비선형 변환. 같은 가중치 $W_1, W_2$를 모든 토큰에 독립 적용. 두 sub-layer 모두 뒤에 잔차 연결과 LayerNorm.
    Encoder구조
    Q14 · 개념
    잔차 연결(residual connection)이 깊은 Transformer 학습에 어떻게 도움이 되는가?
    (1) gradient가 sublayer를 우회해 입력까지 곧장 흐를 수 있어 vanishing/exploding gradient 완화. (2) 학습 초기에 출력이 입력에 가깝게 시작하여 안정성 확보. (3) “sublayer가 학습한 변화량”만 잔차로 표현되어 모델이 “입력을 어떻게 수정할지”에 집중.
    Residual학습 안정
    Q15 · 개념
    LayerNorm과 BatchNorm의 차이는? 왜 Transformer는 LayerNorm을 쓰는가?
    LayerNorm: 한 토큰의 모든 차원에 대해 평균·분산 계산(다른 토큰·배치 무관). BatchNorm: 같은 차원의 배치 전체에 대해 평균·분산 계산. 시퀀스 처리에서는 (1) 길이가 배치마다 달라 BatchNorm 불안정, (2) “한 토큰 안의 차원 표준화”가 의미적으로 자연스러움. 그래서 LayerNorm.
    LayerNorm
    Q16 · 개념
    FFN의 역할을 두 가지 적어라.
    (1) 비선형성 도입 — Attention 자체는 선형에 가까우므로 ReLU 같은 비선형이 필요. (2) “세상 지식” 저장 — 중간층 $d_{ff}=2048$가 key-value 메모리처럼 작동, 토큰별 변환 규칙 저장.
    FFN
    Q17 · 개념
    Decoder 블록의 sub-layer 세 개를 적어라.
    (1) Masked Multi-Head Self-Attention — 자기 시퀀스 안에서, 미래 위치를 mask. (2) Multi-Head Cross-Attention — Q=디코더, K·V=인코더 최종 출력. (3) Feed-Forward Network — Encoder와 동일. 각 뒤에 Add&Norm.
    Decoder구조
    Q18 · 수식
    Decoder의 causal mask 행렬 $M$을 정의하고, attention 식에 어떻게 들어가는지 설명하라.
    $M_{ij} = 0$ if $j \le i$, $-\infty$ otherwise. 식은 $\text{softmax}((QK^\top + M)/\sqrt{d_k})V$. $M$이 attention 점수에 더해진 후 softmax 적용 시 $-\infty$가 $e^{-\infty} = 0$이 되어, 미래 위치의 가중치가 정확히 0. 결과적으로 query는 자기 위치와 과거만 본다.
    MaskDecoder
    Q19 · 개념
    Cross-Attention에는 왜 mask가 없는가?
    Cross-Attention에서 K·V는 인코더의 최종 출력 — 입력 시퀀스 전체를 본 결과. 디코더가 이걸 참조할 때 “미래”라는 개념이 없다(인코더 입력은 이미 모두 정해진 정적 자료). 따라서 디코더가 인코더 출력의 어떤 위치든 자유롭게 보아도 무방.
    Cross-AttnMask
    Q20 · 개념
    Teacher Forcing이란 무엇이고, 어떤 단점(exposure bias)이 있는가?
    Teacher Forcing: 학습 시 디코더 입력으로 “정답 시퀀스”를 한 칸 밀어 사용. 모든 위치의 예측이 병렬 계산 가능. Exposure Bias: 학습 시 디코더는 항상 “깨끗한 정답”만 봤기에, 추론 시 자기 출력이 입력으로 들어가는 상황에서 잘못된 과거를 처리하는 법을 못 배움. 오차가 누적될 수 있음.
    학습Teacher Forcing
    Q21 · 개념
    자기회귀(autoregressive) 디코딩이란?
    추론 시 디코더가 “자기가 만든 출력 토큰”을 다음 step의 입력으로 다시 사용해 한 토큰씩 시퀀스를 생성하는 방식. $\hat{y}_1$ 생성 → 입력 $[\langle s\rangle, \hat{y}_1]$ → $\hat{y}_2$ 생성 → ... → EOS 또는 최대 길이까지. 학습 시 병렬 처리와 달리 추론은 토큰 수만큼의 step 필요.
    추론Autoregressive
    Q22 · 구현
    KV Cache가 왜 자기회귀 추론에서 필수인가?
    Naive 구현은 위치 $i$의 출력을 만들 때 매번 위치 1부터 $i-1$까지의 K, V를 다시 계산함. KV Cache는 이전 위치들의 K, V를 메모리에 저장하고 재사용 — 새 토큰의 K, V만 추가 계산. 결과적으로 위치당 비용을 일정하게 유지($O(i^2) \to O(i)$). 모든 자기회귀 LLM(GPT, Llama 등)에 필수.
    KV Cache추론 가속
    Q23 · 전략
    Greedy decoding, Beam Search, Sampling의 차이를 한 줄씩 설명하라.
    Greedy: 매 step 최대 확률 토큰 하나 선택. 빠르지만 최적 시퀀스 보장 X. Beam Search: 상위 $k$개 후보 시퀀스 유지하며 확장, 마지막에 점수 최고 선택. 번역·요약 등 정답 정해진 과제. Sampling: 분포에서 확률적으로 토큰 추출. temperature/top-k/top-p로 조절. 창의적 생성용.
    디코딩전략
    Q24 · 개념
    Transformer 학습률 warmup이 왜 필요한가?
    학습 초기 가중치가 랜덤이라 layer 출력 스케일 불안정. 큰 학습률로 시작하면 첫 step에서 발산 가능. Warmup으로 작은 학습률에서 시작해 점진적으로 늘려, 가중치 안정 후 본격 학습. Post-LN 구조에서 특히 중요. 원 논문 스케줄: $lr \propto d_{model}^{-0.5} \min(t^{-0.5}, t \cdot \text{warmup}^{-1.5})$.
    학습Warmup
    Q25 · 개념
    Pre-LN과 Post-LN의 차이는?
    Post-LN (원 논문): $X' = \text{LN}(X + \text{Sublayer}(X))$. Pre-LN (후속 모델 대부분): $X' = X + \text{Sublayer}(\text{LN}(X))$. Pre-LN은 잔차 경로가 LN을 거치지 않아 그래디언트가 더 깨끗하게 흐르고 학습이 더 안정. Warmup 필요성도 감소. GPT-2, GPT-3, 최신 LLM 대부분 Pre-LN.

    Q26 · 차원
    시퀀스 길이 $N$, 모델 차원 $d$일 때 self-attention 한 layer의 시간 복잡도와 메모리 복잡도는?
    시간: $QK^\top$ 계산이 $O(N^2 d)$, softmax·$V$ 곱이 $O(N^2 d)$ → 합 $O(N^2 d)$. 메모리: attention 점수 행렬 $N \times N$이 $O(N^2)$. 시퀀스 길이가 길어지면 메모리가 제곱으로 증가 — 이게 long-context LLM의 핵심 병목. 해결책은 Flash Attention, sparse/linear attention 등.

    Q27 · 종합
    Vaswani et al. 2017 "Attention Is All You Need" 논문의 핵심 기여 3가지를 적어라.
    (1) RNN·CNN을 완전히 버리고 attention만으로 sequence-to-sequence 모델을 구성한 첫 사례. 병렬화 가능. (2) Multi-Head Attention 도입 — 같은 비용으로 여러 종류 관계 학습. (3) Sin·Cos Positional Encoding 도입 — 결정론적 함수로 위치 정보 주입, 길이 일반화. WMT 영어-독일어/영어-프랑스어에서 당시 SOTA 달성하고 학습 시간 대폭 단축.

    시험 직전 체크리스트

    다음 항목을 한 줄로 설명할 수 있으면 시험 준비 완료다.

    • RNN의 두 한계 (병렬 불가, 장거리 의존 약화) → 한 문장씩.
    • Attention 공식 $\text{softmax}(QK^\top/\sqrt{d_k})V$ → 단계별 의미.
    • $\sqrt{d_k}$로 나누는 이유 → 분산·softmax·vanishing gradient.
    • Q, K, V의 의미와 역할 → 도서관 비유로.
    • Self-Attention vs Cross-Attention → 어디서 Q, K, V 가져오는지.
    • Multi-Head 핵심 → 왜 여러 헤드, 차원 쪼개기, $W^O$ 역할.
    • $h, d_k, d_{model}$ 관계 → $d_k = d_{model}/h$.
    • Positional Encoding 공식과 “차원마다 다른 주기”의 의미.
    • PE 더하기 vs 이어붙이기 → 왜 더해도 되는지.
    • Encoder 블록 구조: MHA + FFN + Add&Norm 2회.
    • Decoder 블록 구조: Masked MHA + Cross-Attn + FFN.
    • Causal mask 행렬 $M$ → $-\infty$로 softmax 후 0.
    • 잔차 연결의 두 가지 효과 → gradient 흐름, 항등 함수 시작.
    • LayerNorm의 정의와 BatchNorm과의 차이.
    • Teacher Forcing → 정답 한 칸 밀어 입력.
    • Exposure bias → 학습과 추론 분포 mismatch.
    • 자기회귀 디코딩 → 자기 출력을 입력으로.
    • KV Cache → 위치당 비용 일정.
    • Greedy/Beam/Sampling 차이.
    • Self-attention 복잡도 $O(N^2 d)$ → long context 병목.

    마지막 한마디

    Transformer는 한 번에 이해하기 어렵지만, 부품 단위로 쪼개 보면 의외로 “단순한 발상의 누적”이다. RNN의 두 한계 → 모든 토큰이 모든 토큰을 보자 → 그러려면 Q·K·V로 역할 분리 → softmax로 분포 → 분산 안정 위해 $\sqrt{d_k}$ → 여러 관계 동시에 위해 multi-head → 순서 정보 위해 PE → 깊이 쌓기 위해 잔차·LN → 출력 생성 위해 masked self-attn + cross-attn → 학습은 teacher forcing 병렬, 추론은 자기회귀 직렬. 시험에서 어떤 문제가 나와도 이 흐름 위 어딘가에 있다. 다시 한 번 처음부터 따라가 보고, 막히는 부분의 sub-chapter로 돌아가 보자.
