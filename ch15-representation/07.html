Sub 07 — 분포가 바뀌면 무엇이 무너지는가

    도메인 적응 — 분포 변화에 어떻게 대응하나

    학습 분포와 테스트 분포가 다르면 모델은 무너진다. 그러나 두 분포가 “어떤 의미로” 다른지에 따라 대처법은 갈린다. 라벨 변화, 입력 변화, 둘 다의 변화 — 도메인 적응은 그 갈래마다 다른 처방을 가진다.

    지금까지의 전이학습은 “라벨이 다른 두 과제 사이에서 표상을 옮긴다”는 그림이었다. 그러나 현실에서는 라벨 집합이 같지만 분포 자체가 다른 경우가 훨씬 흔하다. 한국에서 학습된 자율주행 모델이 인도에서 동작해야 한다. 낮 사진으로 학습된 객체 검출기가 밤 사진에도 동작해야 한다. 영어로 학습된 감정 분류기가 한국어에도 작동해야 한다. 이 모든 사례에서 “할 일은 같은데 데이터의 모습이 달라졌다.” 이 상황을 다루는 분야가 도메인 적응(domain adaptation)이다.

    세 종류의 분포 변화 — 공변량 변동, 라벨 변동, 개념 변동

    책과 통계학 문헌은 분포 변화를 세 가지로 갈라 분석한다. 각각이 다른 처방을 요구한다.

    (1) 공변량 변동(covariate shift). 입력 분포 $p(x)$만 바뀌고, $p(y \mid x)$는 같다. 예: 같은 카메라로 찍은 사진이지만 한쪽은 한국, 다른 쪽은 인도. 객체와 라벨 사이의 관계는 같다(사람은 어디서 보든 사람이다). 입력의 분포만 바뀌었다. 처방: 입력 표상을 두 도메인에서 비슷하게 만들어 “도메인 불변(invariant)”인 좌표를 학습.

    (2) 라벨 변동(label shift). $p(y)$만 바뀌고, $p(x \mid y)$는 같다. 예: 의료 데이터에서 학습 분포는 환자 50% 정상 50%, 배포 분포는 환자 5% 정상 95%. 같은 환자 한 명의 “모습”은 같지만, 빈도가 다르다. 처방: 빈도 보정(prior correction) — 베이즈 규칙으로 $p(y \mid x)$를 새 $p(y)$에 맞춰 다시 계산.

    (3) 개념 변동(concept drift). $p(y \mid x)$ 자체가 바뀐다. 같은 입력이라도 정답이 시간에 따라 변한다. 예: 사기 거래 탐지 — 사기 패턴이 새로 출현. 처방: 지속적 재학습(online learning), 새 데이터로 가중치를 끊임없이 갱신.

    여행지에서 길 찾기의 세 가지 다른 어려움. 한국에서 운전을 잘하던 사람이 인도에 가면 세 가지 다른 어려움이 동시에 닥친다. (1) 도로의 모습이 다르다(공변량 변동) — 같은 차량 행동 규칙이지만 풍경이 다르다. (2) 차량 비율이 다르다(라벨 변동) — 한국에서는 승용차가 많지만 인도에서는 오토릭샤가 많다. 같은 “오토릭샤”라도 빈도가 다르니 의사결정의 기본값이 달라진다. (3) 운전 규칙 자체가 다르다(개념 변동) — 좌측통행이라 같은 입력이 정반대 행동을 요구한다. 각 어려움은 다른 학습 처방을 요구한다.

    표상 학습 관점의 도메인 적응

    책이 강조하는 핵심은 “표상 학습이 가장 잘 다루는 것은 공변량 변동”이라는 점이다. 도메인 불변 표상(domain-invariant representation)을 학습하면 입력 분포의 차이를 가운데 층에서 흡수할 수 있다. 그러면 위쪽 분류 헤드는 두 도메인에서 같은 표상을 보게 되므로 자연스럽게 둘 다 잘 풀린다.

    도메인 불변 표상을 학습하는 대표 기법은 도메인 적대 학습(domain-adversarial training, DANN)이다. 표상 위에 “이 표상이 어느 도메인 출신인지를 맞히는” 분류기를 하나 더 두고, 표상은 그 분류기를 속이려고(즉, 도메인을 구분 못 하게) 학습한다. GAN의 발상과 같다 — 두 신호 사이의 적대 게임이 표상을 “도메인 정보가 없는” 좌표로 밀어붙인다.

    위젯 07도메인 적응 전후 — 같은 표상 공간에서 두 도메인이 정렬되는 모습

    적응 전 — 두 도메인이 분리됨

    적응 후 — 라벨에만 따라 분리

    적응 전에는 표상이 도메인(원본·대상)을 강하게 분리한다 — 분류기가 도메인을 라벨로 착각할 위험. 적응 후에는 도메인 신호가 사라지고 라벨 신호만 남는다 — 한 분류기가 두 도메인에서 같은 결정 경계를 사용할 수 있다.

    색 = 라벨(빨강/파랑), 모양 = 도메인(원·삼각형). 적응의 목표는 모양 구분은 흐리게, 색 구분은 또렷하게 만드는 것이다.

    라벨 없는 대상 도메인 — 의사라벨링

    현실 적응 시나리오에서 가장 흔한 설정은 “원본 도메인에 라벨이 있고, 대상 도메인에는 라벨이 없다(unsupervised domain adaptation)”이다. 이 경우 도메인 적대 학습 외에 또 한 가지 흔히 쓰이는 처방은 의사라벨링(pseudo-labeling)이다.

    의사라벨링의 절차는 단순하다. (1) 먼저 원본 도메인 라벨로 모델을 학습한다. (2) 그 모델로 대상 도메인 데이터에 예측을 돌려, 신뢰도(예: softmax 확률 > 0.9)가 높은 것만 “의사 라벨”로 채택한다. (3) 원본 라벨 + 의사 라벨을 합쳐 모델을 다시 학습한다. 이 절차를 반복하면 모델이 점차 대상 도메인에 적응한다.

    위험은 명확하다 — 잘못 붙인 의사 라벨이 모델을 잘못된 방향으로 굳힌다(confirmation bias). 이를 완화하기 위해 신뢰도 기준을 매우 높게 잡거나, 일관성 정칙화(같은 입력의 작은 변형이 같은 라벨을 받도록)와 결합하는 것이 보통이다. 반지도 학습(12절)과 같은 발상을 공유한다.

    “같은 과제, 다른 분포”라는 미묘한 위치

    도메인 적응은 전이학습의 형제이지만 분명히 다르다. 전이학습은 “라벨이 다른 두 과제”이고, 도메인 적응은 “같은 라벨, 다른 분포”다. 이 차이가 처방을 갈라 놓는다. 전이학습은 분류 헤드를 갈아 끼우는 것이 자연스러운 첫걸음이지만, 도메인 적응은 분류 헤드를 그대로 두고 표상 자체를 두 분포에서 정렬하는 것이 자연스러운 첫걸음이다.

    실전에서는 두 문제가 종종 섞인다. 예: ImageNet으로 사전훈련된 모델을 의료 X-ray의 폐렴 분류에 옮긴다. 이때 (1) 자연 이미지 → X-ray는 도메인 변화, (2) 1,000개 카테고리 → 2개 카테고리(폐렴/정상)는 과제 변화. 둘 다 일어난다. 절차도 두 가지를 함께 적용한다 — 헤드 교체(전이) + 미세조정 + 적응 정칙화.

    핵심 어휘 정리

    도메인 적응 (domain adaptation)같은 과제, 다른 분포 사이에서 모델을 적응시키는 학습.
    공변량 변동 (covariate shift)$p(x)$만 바뀌고 $p(y \mid x)$는 같음. 가장 다루기 쉬움.
    라벨 변동 (label shift)$p(y)$만 바뀜. 베이즈 보정으로 해결.
    개념 변동 (concept drift)$p(y \mid x)$ 자체가 바뀜. 지속적 재학습 필요.
    도메인 적대 학습 (DANN)표상이 도메인 정보를 잃도록 적대 게임으로 학습.
    의사라벨링 (pseudo-labeling)높은 신뢰도 예측을 라벨로 채택해 자기학습.
